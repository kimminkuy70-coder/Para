## Camtek AOI Manager v14.1.4 — 필터 개수 · 업데이트 알림 정리

- Defect 분석(대규모) 5-1 의 Lot 제외 · 첫번째 분류 · 재분류 개수가 지금 필터를 따릅니다.
- 업데이트 알림 창에 바뀐 점을 항목마다 한 줄로 보여 줍니다.

### 자세히

- 필터: Lot · Slot 고르기, Lot 제외, 분류 체크, Recipe, Contrast · Area · Width · Length 범위에 맞는 Defect 만 셉니다. 자기 묶음의 체크는 셈에서 빼므로, 끈 항목도 자기 개수가 보이고 다시 켤 수 있습니다. 0개인 항목도 칸에 남습니다.
- 알림: 이 노트 맨 위 목록만 한 줄씩(최대 8줄) 보입니다. 이 판부터 적용되므로, 이번 v14.1.4 알림은 지금 쓰는 판의 방식(노트 전체)으로 보일 수 있습니다.

### 업데이트

- v14.1.1 이후 판에서는 프로그램 시작 때 뜨는 업데이트 알림으로 받으십시오.
- v13 판에서는 v13.0.3 을 거쳐 업데이트 알림으로 받거나, 아래 설치 zip 을 같은 폴더에 풀어 덮어쓰십시오.

### 처음 설치

1. 아래 `Camtek_AOI_manager_v14.1.4_install.zip` 을 받으십시오.
2. 프로그램을 종료하십시오(알림 영역 아이콘이 있으면 [종료]).
3. `%LOCALAPPDATA%\CamtekAOI\app` 폴더에 zip 을 풀어 덮어쓰십시오(처음이면 폴더를 만들고 그 안에).
4. `Camtek_AOI_manager.bat` 을 더블클릭하거나 바탕화면 바로가기로 실행하십시오.

자세한 안내: 저장소 `docs/설치_v13.md`(v14 도 같은 방식)
