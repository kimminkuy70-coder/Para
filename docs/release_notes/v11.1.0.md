# Camtek AOI Manager v11.1.0

**Batch Report 분석** 탭이 새 화면으로 바뀌었습니다. 검토하신 Batch Report 프로토타입 화면을 실제 앱에 옮겼습니다.

## Batch Report 분석 — 큰 탭 2개
- **가동률 조사 및 분석**: 호기(박스 격자)와 기간(모든 기간 · 최근 30/90일)을 고르고 [조사 시작]을 누르면, 아래 세 화면이 같은 조사 결과를 씁니다.
  - **Lot 추적**: 누르는 지표 5개(Lot Scan 완료 · Batch Report · 재스캔으로 완료 · Pass하지 못한 Lot · 중복 Scan), 기간별 Lot Scan 막대,
    Lot 단위 Scan List, Lot Scan Error 요약, 점검 스캔 목록. Lot 을 누르면 큰 창에서 **Lot 이력 상세**(시간순 그래프 · 문장 요약 ·
    Batch Report 이력 · Lot × wafer 오류 지도)와 **Lot · wafer 취합**(공정 단계별 Dice 합계 · Excel 저장)을 봅니다.
  - **가동률 · 원인**: 전체 호기 / 호기마다 탭, 유효 스캔 · Error·중복 스캔 · 재스캔 전 대기 · 점검 스캔 · 기타로 나눈 달력 시간,
    기간 행을 누르면 오른쪽에 상세(레시피별 점유 · Error 원문별 잃은 시간), 24시간 시간표. 자정을 넘긴 시간은 날마다 나눠 셉니다.
  - **WPH**: 정상 스캔 WPH · 실제 WPH(재스캔 포함) · 처리량 감소, 호기별 · 레시피별 표, 정상 스캔 Batch Report 분포, Lot별 실제 WPH 추이.
- **Batch Report 찾기 · 취합**: 파일 이름으로 찾아 Lot · 공정 단계별로 묶어 보여 줍니다(같은 Lot 을 이어서 스캔한 Batch Report 도 함께).
  Scanresult 경로 확인 · 복사, 원문 보기 · 원본 열기, 고른 Batch Report 취합(같은 wafer 여러 장이면 최신 스캔 자동) · Excel 저장.
- **이미 읽은 Batch Report는 다시 읽지 않기**(기본 켜짐): 끄면 고른 범위를 전부 다시 읽습니다. 호기 박스에 새로 읽은 수 · 캐시 수가 보입니다.
- 화면을 다시 열면 지난 조사 결과를 로컬 캐시만으로 먼저 보여 줍니다(장비 접근 없음).
- 호기가 아주 많으면 호기 격자 안에서 스크롤합니다.
- 종전 분석 결과 파일(분석 HTML · Excel · Lot 추적 HTML · 가동률 대시보드 · WPH)은 그대로 만들어지며 [저장된 결과 파일]에서 엽니다.

## 개발자 기능 (설정 › 정보)
- 같은 wafer 가 Pass 를 2번 이상 받았을 때 쓸 Batch Report 를 직접 고르고 저장합니다. 켜고 끄는 것만으로는 결과 숫자가 바뀌지 않고,
  저장한 선택만 Lot 취합 · 가동률 · WPH · 찾기 취합에 쓰입니다.
- 저장한 선택은 **이 PC 에만** 남습니다(PC마다 따로). 저장 안 한 선택이 있으면 끄기 전에 저장 / 버리기를 묻고, 조사 중에는 바꿀 수 없습니다.
