## Camtek AOI Manager v14.1.1 — 프로그램 시작 때 업데이트가 먼저

- **프로그램을 켜면 업데이트 확인을 가장 먼저 합니다.** 새 버전이 있으면 알림 창이 뜨고, 고를 때까지 Batch Report 지난 결과 불러오기 · 자동 분석을 시작하지 않습니다.
  - [나중에]를 누르거나, 새 버전이 없거나, 인터넷이 안 되면(최대 15초) 종전처럼 바로 이어서 불러옵니다.
- **[지금 업데이트]가 다른 작업 때문에 기다리라고 하지 않습니다.** 진행 중인 작업이 있어도 새 버전을 받습니다(받기는 준비만 하고, 적용은 프로그램을 다시 실행할 때).
- 새 버전을 받은 뒤 [지금 종료]도 진행 중인 작업 때문에 막히지 않습니다(진행 중인 작업은 멈추고 종료).

### 업데이트

- v14.0.0 · v14.1.0 에서는 프로그램의 업데이트 알림으로 받습니다. **이번 한 번은** 지금 깔린 판의 규칙이 적용되어, 시작 때 Batch Report 지난 결과 불러오기가 끝난 뒤에 [지금 업데이트]가 됩니다(또는 아래 설치 zip 덮어쓰기). 이번 판부터는 업데이트가 먼저입니다.
- v13 판에서는 v13.0.3 을 거쳐 업데이트 알림으로 받거나, 아래 설치 zip 을 같은 폴더에 풀어 덮어쓰십시오.

### 처음 설치

1. 아래 `Camtek_AOI_manager_v14.1.1_install.zip` 을 받으십시오.
2. 프로그램을 종료하십시오(알림 영역 아이콘이 있으면 [종료]).
3. `%LOCALAPPDATA%\CamtekAOI\app` 폴더에 zip 을 풀어 덮어쓰십시오(처음이면 폴더를 만들고 그 안에).
4. `Camtek_AOI_manager.bat` 을 더블클릭하거나 바탕화면 바로가기로 실행하십시오.

자세한 안내: 저장소 `docs/설치_v13.md`(v14 도 같은 방식)
