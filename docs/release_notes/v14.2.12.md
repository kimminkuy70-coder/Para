## Camtek AOI Manager v14.2.12 — 멈춘 이유 요약 필터 여러 개 고르기

- Batch Report 분석 › Lot 추적 › **멈춘 이유 요약**의 **레시피 · 호기 · Error 필터에서 여러 개를 골라 합쳐 볼 수 있습니다.**
- 필터 단추를 누르면 목록이 열립니다. 항목을 누르면 고르고, 다시 누르면 고름을 풉니다. 고른 항목은 색과 ✓ 로 표시합니다.
- 단추에는 고른 값(하나) 또는 '레시피 2개'처럼 합쳐 보는 개수가 보입니다. 아무것도 고르지 않으면 전체입니다.
- 예: 레시피 1번 · 2번을 고르면 두 레시피의 Lot을 합쳐 Error 목록과 호기별 표를 셉니다. Lot은 한 Error에 한 번만 셉니다.
- 호기별 표의 칸을 누르면 고른 레시피 전체와 그 호기의 Lot만 위 목록에 보입니다.
