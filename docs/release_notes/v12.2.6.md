# Camtek AOI Manager v12.2.6

**튜토리얼**을 새로 넣었습니다. 화면을 어둡게 하고 눌러야 할 곳을 강조 테두리로 짚은 뒤, 화살표 말풍선으로 한 단계씩 안내합니다.

## 시작하기
- **[설정]** 탭 맨 위의 **🎓 튜토리얼** 상자에서 **[초기 설정 튜토리얼]** 또는 **[기능 둘러보기]** 를 누르세요.
- [다음 →] · [이전] · [건너뛰기], 키보드 → / ← / Enter / Esc 로 움직입니다. 튜토리얼은 **안내만 하고 아무 값도 바꾸지 않습니다.**

## 초기 설정 튜토리얼 (12단계)
- **① 저장 폴더 = 공유 OneDrive 폴더**
  1. 개발자가 보낸 OneDrive 공유 링크를 Edge 로 열고 **[내 파일에 바로 가기 추가]** 를 누릅니다.
  2. 회사 노트북의 파일 탐색기 › OneDrive - 회사이름 아래에 그 폴더가 생깁니다.
  3. [📁 찾기]로 그 폴더를 고르고 [저장]을 누릅니다. 공유 문서가 처음 한 번 만들어지고, 새 버전 업데이트도 이 폴더로 받습니다.
- **② 장비 연결 — AOI 장비 호기 루트**
  1. 파일 탐색기에서 장비 폴더가 열리는지 확인합니다(예: P:\AOI-17).
  2. 호기 이름과 호기 폴더를 넣고 [추가]를 누릅니다.
  3. 표의 [인식된 폴더]에 Reports · Scanresult 가 보이면 연결된 것입니다.
- **③ 로컬 작업 폴더**(선택)와 **현재 설정** 요약을 확인하면 끝입니다.

## 기능 둘러보기 (11단계)
- Recipe 관리 · 자동 감시 · Commonality 조사 · Batch Report 분석([조사 시작], Lot 추적 · 가동률 · WPH · 레시피 비교) · Color·Gray 매칭 · Wafer Map 수정하기 · 메모를
  탭을 직접 옮겨 가며 한 줄씩 설명합니다.

## 참고
- 저장 폴더 탭 안내에 OneDrive 공유 링크 연결 방법을 한 줄 더 적었습니다.
- 그 밖의 기능 · 계산은 v12.2.5 와 같습니다.
