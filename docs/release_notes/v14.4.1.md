## AOI Manager v14.4.1 — Defect 분석 흑백 위치 · µm 표시 · 사진 크기 측정

- Defect 분석 흑백(Gray) 사진 위치를 기본 · 대규모 모드가 같은 계산으로 찾음(레시피마다 프레임 크기 · 픽셀 크기를 Slot 파일에서 읽음)
- 대규모 모드가 Color 정보 파일(ColorImageGrabingInfo.ini) 없이도 흑백 사진을 찾음
- 기본 모드 사진 새 창을 대규모 모드와 같은 창으로 바꿈
- 리뷰PC 정보에 Width · Area 의 µm 값을 괄호로 함께 표시하고, 목록 위에 'µm 환산 픽셀 : 계수' 를 표시
- [µm 로 보기] 체크로 목록 · 필터 · 정렬의 Area · Width 를 µm 또는 장비 값으로 바꿔 봄
- 픽셀 크기가 0.7708 이 아닌 레시피(x20 · x5 · 2D+3D 등)에서 틀리던 Area µm² 를 바로잡음
- '빨간 네모' 이름을 'Defect 박스' 로 바꾸고, 레시피에 따라 4배 크게 그려지던 크기를 바로잡음(흑백 GL 측정도)
- 사진 새 창의 [크기 측정 (M)] 으로 사진을 크게 확대해 직선 · 원 · 사각형의 길이와 넓이(µm · µm²)를 잼
