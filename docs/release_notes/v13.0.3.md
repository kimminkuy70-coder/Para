## Camtek AOI Manager v13.0.3 — v14 로 넘어가기 위한 업데이트

### 무엇이 바뀌나

- 프로그램이 새 판을 찾을 때 **v14 이후 판도 찾습니다.** 종전 v13 판은 v13.x.y 판만 찾아서, 새로 나온 **v14.0.0(Defect 분석 탭)** 알림이 뜨지 않았습니다.
- 그 밖의 기능은 v13.0.2 와 같습니다.

### 업데이트 순서

1. 프로그램의 업데이트 알림에서 [지금 업데이트] → 프로그램을 종료하고 다시 실행하면 v13.0.3 이 적용됩니다.
2. 다시 실행하면 **v14.0.0 알림**이 뜹니다. 한 번 더 [지금 업데이트] → 종료 후 다시 실행하면 v14.0.0 이 됩니다.
3. 설정 · 캐시 · OneDrive 공유 자료는 그대로 이어서 씁니다.

v14.0.0 에서 바뀐 것은 v14.0.0 릴리스 노트를 보십시오(Defect 분석 탭: 대규모 Defect 분석 · Color·Gray 매칭 최종 목록 CSV · 다이어그램 분석).

### 처음 설치

처음 설치한다면 v13.0.3 대신 **v14.0.0 설치 zip** 을 받으십시오.
