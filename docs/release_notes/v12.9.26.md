# Camtek AOI Manager v12.9.26

**Batch Report 찾기 · Lot 취합의 Lot 고르기를 레시피 탭으로 나눴습니다. Lot History 에서 1장만 스캔한 wafer 도 슬롯 행에 맞춰 보입니다. Lot 박스 제목을 색으로 구분했습니다.**

## Batch Report 찾기 · Lot 취합 › Lot 고르기
- 검색 결과를 같은 레시피(Job · Recipe(s))끼리 탭 하나로 묶었습니다: [전체] / 레시피마다 탭(탭 옆 숫자 = Lot 수).
- 탭 아래 **[이 레시피 탭 Lot 전체 선택]** 체크로 그 탭의 Lot 을 한 번에 고르거나 해제합니다.
- 탭 안에서도 Lot 은 시간순(첫 Batch Report 시작 시각)으로 보입니다.

## Lot History · Lot · wafer 취합
- 1장만 스캔한 Batch Report 는 표에 슬롯 정보가 없어 Wafer ID(예: `S3LQR044XMD2`)가 따로 한 줄로 보였습니다.
  이제 같은 Lot 의 다른 스캔에서 그 Wafer ID 의 슬롯(예: 2번)을 알면 그 슬롯 행에 함께 보입니다.
- 같은 Lot 의 다른 스캔에도 그 Wafer ID 가 없으면 종전처럼 Wafer ID 줄로 보입니다.

## Lot 고르기 화면 가독성
- 각 Lot 박스의 제목 줄(Lot 이름 · 레시피 · 상태 · 기간 · 호기)을 짙은 바탕 · 흰 글자로 바꿔 박스 사이를 쉽게 구분합니다.
