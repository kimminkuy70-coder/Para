# Camtek AOI Manager v12.5.14

**Batch Report 찾기 · 취합에서 Lot을 키워드로 찾고 한꺼번에 고를 수 있습니다.**

## Lot · Batch Report 고르기(3/4) — 검색 · 한꺼번에 선택
- Lot 목록 위에 **Lot 목록 키워드 검색** 칸이 생겼습니다. Lot · 레시피 · 호기 · S/M · 파일 이름으로 찾을 수 있고, 여러 단어는 모두 포함하는 Lot만 보입니다.
- **[보이는 Lot 모두 선택] · [보이는 Lot 해제] · [모두 해제]** 버튼으로 검색에 걸린 Lot을 한 번에 고르거나 풀 수 있습니다.
- Lot 머리의 체크를 **Shift+클릭**하면 직전에 누른 Lot부터 그 Lot까지 한꺼번에 선택(또는 해제)됩니다.
- `검색에 맞는 Lot n / 전체 m` 과, 검색에 안 보이지만 이미 선택한 개수가 함께 표시됩니다.

## 찾은 파일 고르기(2/4) — 목록 안 검색
- 찾은 Batch Report 목록 위에 **목록 안 검색** 칸이 생겼습니다(호기 · 파일 이름 · 날짜).
- **[보이는 것 모두 고르기] · [보이는 것 해제] · [모두 해제]**, 표 머리 체크(보이는 것 전체), **Shift+클릭 범위 고르기**를 쓸 수 있습니다.
