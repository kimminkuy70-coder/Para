# Camtek AOI Manager v10.0.0

## 새 기능: Color · Gray 매칭 (상단 탭)
별도 프로그램이던 **AOI Color-Gray Matcher v16** 을 프로그램 안으로 옮겼습니다(설치·Python·인터넷 불필요).

- **① 폴더 선택** → Lot 폴더(여러 Wafer) 또는 Wafer 폴더 하나. 하위 5단계까지, 최대 25 Wafer 를 자동으로 찾습니다
  (`ColorImageGrabingInfo.ini` · `ScanResultImageList.txt` · `frameToChuckPlane.*.ini` 가 있는 폴더).
- **② Wafer 확인** → 처리할 Wafer 선택(기본 전체).
- **③ 저장 위치** → 기본 = 로컬 작업 폴더 `ColorGray매칭\{폴더명}\{시각}`, 또는 다른 **로컬** 폴더
  (이미지 수만큼 파일이 생겨 OneDrive·네트워크·원본 폴더 안은 막습니다).
- **④ 실행 검토 → ⑤ 처리 진행**(진행률·기록·취소, 다른 탭으로 이동해도 계속) → **⑥ 완료**(Wafer별 Excel·실패 목록 열기).
- 결과는 기존과 같습니다: Wafer마다 `{Wafer}_Color_Gray_Crop.xlsx`(Color / Gray(빨간 십자 표시) / Crop 썸네일 + 좌표·매칭 정보,
  사진 열기 링크), `_crop_images\`, `_excel_thumbnails\`, 매칭 실패 시 `unmatched_or_missing.csv`.
- 원본 폴더는 **읽기만** 합니다. 이미지 처리는 프로그램 화면(WebView)에서 하므로 추가 패키지가 없습니다.
