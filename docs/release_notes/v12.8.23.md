# Camtek AOI Manager v12.8.23

**Batch Report 캐시를 OneDrive 로 주고받을 수 있게 했습니다. 개발자는 [OneDrive 에 게시]로 올리고, 사용자는 [OneDrive 에서 불러오기]로 받습니다.**

## Batch Report 캐시 OneDrive 공유
- 개발자: Batch Report 분석 › [🛠 개발자 기능] › [OneDrive 에 게시]를 누르면 이 PC 의 캐시를 zip 1개로 만들어 저장 폴더 옆 `캐시공유` 폴더에 올립니다. 최근 3개만 남깁니다.
- 사용자: Batch Report 분석 › [OneDrive 에서 불러오기]를 누르고 목록에서 캐시를 고르면, 이 PC 로 받아 이 PC 캐시로 불러옵니다. 그 뒤 [조사 시작]은 장비에서 새 Batch Report 만 읽습니다.
- 받은 zip 은 크기와 SHA-256 이 게시할 때와 같을 때만 불러옵니다. OneDrive 동기화가 덜 끝났으면 잠시 뒤 다시 누르라고 안내합니다.
- 종전의 [Batch Report 캐시 압축 파일 만들기 (zip)] 버튼은 없앴습니다. 받은 zip 을 창에 끌어 넣거나 [zip 찾기…]로 고르는 방법은 그대로 쓸 수 있습니다.

## Batch Report 자동 분석 설정 위치
- 설정 › [Batch Report 분석 주기 설정] 탭을 CAMTEK › 자동 분석 및 취합 › [Batch Report 자동 분석] 탭으로 옮겼습니다. 주기 · 실행 시각 · ▶ 즉시 실행은 이전과 같습니다.
- 새 체크박스 [자동 분석이 끝나면 Batch Report 캐시 zip 을 OneDrive 에 올리기](개발자 PC 용, 기본 꺼짐): 켜면 자동 분석과 ▶ 즉시 실행이 끝날 때마다 캐시를 자동으로 게시합니다.

## 저장 폴더 지정
- 설정 › 저장 폴더에서 `docs` 폴더 대신 그 상위 폴더(예: `…\OneDrive - 회사\0. Camtek AOI parameter 취합\`)를 고르면 그 안의 `docs` 를 찾아 씁니다. `프로그램` · `캐시공유` 폴더도 그 옆에서 찾습니다.
- 지금처럼 `docs` 폴더를 직접 골라도 그대로 동작합니다. 이미 지정한 PC 는 다시 지정하지 않아도 됩니다.

## 보안
- 캐시 zip 안에는 데이터(JSON)만 있고, 프로그램은 zip 을 풀지 않고 안의 데이터만 읽습니다. 새 프로그램 실행 · 스크립트 · 인터넷 접속은 없습니다.
- OneDrive 에는 게시 1번에 zip 1개와 정보 파일 1개만 생깁니다. 받는 PC 는 OneDrive 에 아무것도 쓰지 않습니다.
