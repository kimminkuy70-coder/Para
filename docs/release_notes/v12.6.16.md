# Camtek AOI Manager v12.6.16

**개발자가 만든 Batch Report 캐시 zip 을 다른 사용자가 화면에 끌어 넣기만 하면 바로 캐시로 불러와, 장비에서 다시 읽지 않고 가동률 · Lot 찾기를 빠르게 할 수 있습니다.**

## Batch Report 캐시 가져오기 (모든 사용자)
- Batch Report 분석 화면의 조사 범위 아래에 **Batch Report 캐시 가져오기** 영역이 생겼습니다.
- 개발자에게 받은 캐시 zip 파일을 **프로그램 창에 끌어 넣으면** 자동으로 이 PC 캐시에 합칩니다. 끌어 넣기가 어려우면 **[zip 찾기…]**로 골라도 됩니다.
- 가져온 뒤에는 [조사 시작]이 가져온 캐시를 먼저 쓰고 장비에서는 **새로 생긴 Batch Report만** 읽습니다. [Batch Report 찾기 · 취합]의 캐시 검색에도 바로 나옵니다.
- 가져온 호기는 조사 범위에 자동으로 골라 둡니다. 이 PC에 이미 있던 Batch Report는 그대로 두고, 없는 것만 더합니다.
- 호기는 **이름으로** 맞춥니다. 이 PC에 등록되지 않은 호기는 건너뛰고 알려 주므로, [설정 › AOI 장비 호기 루트]에 같은 이름으로 등록한 뒤 다시 넣으면 됩니다. PC마다 장비 폴더 경로(드라이브 문자 등)가 달라도 이 PC의 그 호기 Report 폴더로 맞춰 넣습니다.
- zip 파일은 읽기만 하고, 가져오는 동안 장비에는 접속하지 않습니다.

## 개발자 기능 — 캐시 압축 파일 만들기
- 같은 영역의 **[🛠 개발자 기능]** 버튼을 누르면 **[Batch Report 캐시 압축 파일 만들기 (zip)]**가 열립니다(지금까지 이 PC에 모인 모든 호기의 캐시를 zip 하나로, 최근 3개 보관).

## 참고
- 중복 Pass 사람 선택(개발자 기능에서 저장한 선택)은 PC마다 따로라 zip에서 가져오지 않습니다.
- 캐시 형식이 다른(다른 버전에서 만든) zip은 거절하고 안내합니다.
