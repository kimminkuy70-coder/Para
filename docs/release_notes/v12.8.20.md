# Camtek AOI Manager v12.8.20

**설정 › AOI 장비 호기 루트에서 NAS 네트워크 드라이브를 고르면, 그 바로 아래의 AOI 장비 폴더를 찾아 호기 루트를 한꺼번에 등록할 수 있습니다.**

## 네트워크 드라이브에서 호기 자동 찾기
- 설정 › AOI 장비 호기 루트 › **CAMTEK** 등록 줄 아래에 **🔎 네트워크 드라이브에서 호기 자동 찾기**가 생겼습니다. 네트워크 드라이브(예: `W:\`)를 고르고 [호기 찾기]를 누르면 바로 아래 폴더가 목록으로 나옵니다.
- 이름에 AOI 가 들어간 폴더와 메모 › 장비 IP 에 적힌 호기 이름과 같은 폴더가 미리 체크되고, 이미 등록한 호기는 고를 수 없게 표시됩니다. 확인한 뒤 [고른 n대 등록]을 누르면 폴더 이름이 호기 이름으로 등록됩니다.
- NAS 가 여러 대면 드라이브마다 한 번씩 찾아 등록합니다.
- 드라이브의 **바로 아래 폴더 목록만 한 번** 읽고 더 아래로 들어가지 않습니다. NAS 의 원본 폴더는 읽기만 하며 아무것도 만들거나 고치지 않습니다. 등록할 때는 한 대씩 등록할 때처럼 각 호기 폴더 바로 아래에서 Reports · Scanresult 폴더 이름만 확인합니다.
