# Camtek AOI Manager v12.0.2

Scanresult 를 찾을 때 **백업본까지 볼지 직접 정하는 스위치**를 넣었고, Lot 추적의 **Lot 단위 Scan List** 모양을 프로그램 테마에 맞게 새로 만들었습니다.

## Scanresult 백업본 포함 조사
- Scanresult 를 찾는 모든 기능에 같은 설정이 적용됩니다: 신규 Commonality 조사, Commonality 감시(대표 S/M 찾기 포함),
  Batch Report 찾기 · 취합의 Scanresult 경로.
- 각 화면에 **지금 조사 범위**(`원본 + 백업본` / `원본만`)가 보이고, 옆의 **[백업본 포함]** 스위치로 바로 바꿀 수 있습니다.
  한 화면에서 바꾸면 다른 화면과 설정 › AOI 장비 호기 루트에도 같이 바뀝니다. 기본값은 지금까지처럼 **백업본 포함**입니다.
- 원본 = 이름이 정확히 `Scanresult` 인 폴더, 백업본 = `Scanresult_260402` 같은 다른 이름의 Scanresult 폴더와
  설정에서 추가한 Scanresult 보관 폴더입니다.
- 조사가 끝나면 **이번에 실제로 본 폴더 목록**을 원본 · 백업본 · 추가 폴더로 구분해 보여 줍니다(Commonality 조사 2단계, 감시 대표 S/M 창).
- 신규 Commonality 조사의 Scanresult 확인도 이제 설정에서 추가한 Scanresult 보관 폴더를 함께 봅니다(스위치를 켰을 때).

## Lot 추적 — Lot 단위 Scan List
- 작동 방식(검색 · 필터 · 정렬 · Lot 창)은 그대로이고 모양만 바꿨습니다.
- 목록 카드 위 색 띠와 제목 점이 지금 보는 목록(전체 · 재스캔 완료 · Pass 못함 · 중복 Scan · Batch Report)에 따라 바뀌고, 오른쪽에 개수를 크게 보여 줍니다.
- 상태 고르기를 개수가 붙은 버튼(전체 · 한 번에 완료 · 재스캔으로 완료 · Pass하지 못한 wafer 존재)으로, 재스캔 · 호기 이동은 켜고 끄는 버튼으로 바꿨습니다.
- 표: 머리 줄 고정, 행에 마우스를 올리면 강조, Lot 과 S/M 을 한 칸에, 호기 이동은 `AOI-01 → AOI-02` 칩, 스캔 기간 두 줄,
  0 은 `—`, 주요 Error 원문은 칩 2개 + `+n`(마우스를 올리면 나머지). 키보드 Enter 로도 Lot 창이 열립니다.
