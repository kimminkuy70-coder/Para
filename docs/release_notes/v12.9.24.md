# Camtek AOI Manager v12.9.24

**KLA 자재 찾기 화면을 정리했습니다. KLA 캐시 상자를 접었다 펼 수 있습니다.**

## KLA 캐시 상자 접기 · 펼치기
- KLA › KLA 자재 찾기의 [KLA 캐시] 상자를 누르면 펼쳐지고, 다시 누르면 접힙니다. 처음에는 접혀 있습니다.
- 접혀 있어도 한 줄에 이 PC 캐시의 갱신 시각 · 장비 수 · Lot 폴더 수 · 날짜 범위를 보여 줍니다.
- 마지막으로 접었는지 폈는지를 이 PC 에 기억합니다.

## 화면 정리
- [찾을 곳] 의 선택 버튼(장비 폴더 / KLA 캐시)과 [찾을 장비] 체크 상자의 크기를 같게 맞췄습니다. 글자가 세 줄로 꺾이던 것을 한 줄로 고쳤습니다.
- Lot 키워드 칸의 설명을 입력 칸 안 예시로 옮겨, 라벨이 두 줄로 꺾이지 않습니다.
- 긴 설명 문장을 줄였습니다. 핵심만 남겼습니다.
- 결과 표의 [폴더 열기] · [경로 복사]를 같은 크기 버튼으로 맞췄습니다.
- 기능과 저장 방식은 바뀌지 않았습니다.
