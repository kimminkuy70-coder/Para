# Camtek AOI Manager v10.1.0

## Color · Gray 매칭 개선
- **저장 위치 화면 정리**: '로컬 작업 폴더(기본)' / '다른 로컬 폴더' 를 초록색 선택 버튼으로 바꾸고,
  버튼 바로 오른쪽에 저장 경로, 맨 오른쪽에 **[📁 찾아보기…]** 를 배치했습니다(고른 쪽 줄이 초록 테두리로 표시).
- **화면 상단 설명 문구**를 기능에 맞게 바꿨습니다:
  "AOI Color 이미지와 같은 위치의 Gray 스캔 이미지를 찾아 잘라 붙이고, 나란히 비교하는 Excel 을 만드세요."
- **원본 이미지 용량 한도 2.9MB → 5MB**: 5MB 까지 처리하고, 넘는 이미지는 실패 목록에 사유와 함께 남깁니다
  (큰 이미지는 나눠서 읽어 프로그램 내부 전송 한도에 걸리지 않습니다).
