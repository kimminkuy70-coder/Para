# Camtek AOI Manager v12.8.21

**Batch Report 분석 › 가동률 조사 및 분석에서 `too many values to unpack` 오류로 조사가 끝나지 않던 문제를 고쳤습니다.**

## 오류 수정
- 조사 범위에 읽지 못한 Batch Report(원본 폴더 접근 불가, 읽는 중 바뀐 파일, Batch End · Wafer 표가 없는 파일 등)가 하나라도 있으면 WPH 결과 파일을 만들다가 조사 전체가 `too many values to unpack` 오류로 멈추던 문제를 고쳤습니다. 호기와 Batch Report 가 많을수록 이런 파일이 섞이기 쉬워 자주 보였습니다.
- 이제 읽지 못한 파일은 결과의 '원본 읽기 오류' 표와 WPH 결과의 파싱오류 칸에 남기고, 나머지 Batch Report 로 조사를 끝까지 마칩니다.
