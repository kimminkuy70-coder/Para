# Camtek AOI Manager v12.9.28

**Color · Gray 매칭에서 `frameToChuckPlane.ini` 파일을 찾지 못하던 문제를 고쳤습니다.**

## Color · Gray 매칭 › 폴더 선택
- 장비 폴더의 변환 파일 `frameToChuckPlane.ini`를 찾아서 씁니다.
  - 종전에는 이름 가운데에 번호가 있는 `frameToChuckPlane.<번호>.ini` 형식만 찾았습니다. 그래서 `frameToChuckPlane.ini`가 있어도 "Wafer 폴더를 찾지 못했습니다"가 나왔습니다.
  - `frameToChuckPlane.ini`가 있으면 그 파일을 먼저 씁니다. 없으면 예전 형식 `frameToChuckPlane.<번호>.ini`를 씁니다.
- 화면 안내 문구와 "없는 파일" 진단도 `frameToChuckPlane.ini`로 표시합니다.
