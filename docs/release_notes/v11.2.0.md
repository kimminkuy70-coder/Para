# Camtek AOI Manager v11.2.0

**Batch Report 분석 › Lot 추적** 화면을 다듬고, **3D 스캔**을 2D와 따로 세도록 Lot 판정 기준(대전제)을 넓혔습니다.

## Lot 추적
- 지표(Lot Scan 완료 · Batch Report · 재스캔으로 완료 · Pass하지 못한 Lot · 중복 Scan)를 누르면 목록 위 **제목 상자**가 바뀌어
  지금 어떤 목록을 보는지 바로 알 수 있습니다.
- **기간별 Lot Scan 현황**: 막대에 마우스를 올리면 초록 · 주황 · 빨강 네모와 이름, Lot 수가 한 열로 세로 맞춰 나오고 합계도 보입니다.
  글씨가 잘리지 않게 툴팁을 다시 그렸습니다.
- 주 단위는 **WW1 ~ WW52**(ISO 주 — 월요일 시작, 해에 따라 WW53)로 쓰고, 그 아래 줄에 **(월/일~월/일)** 기간을 씁니다.
- **Lot 이력 상세 → Lot History**로 이름을 바꾸고, 세 목차(시간순 요약 · Batch Report 이력 · Lot × wafer 오류 지도)를 경계선 상자와
  제목 박스로 나눴습니다. 시간순 번호(#1, #2 …)는 실제 스캔 시각 순서입니다.
- Batch Report 목록에서 행을 누르면 뜨는 **Batch Report 원문 창**(스캔 1번의 표 그대로)과 Lot 이름을 누르면 뜨는 **Lot 창**
  (그 Lot의 모든 Batch Report를 모은 Lot History · 취합)에 무엇을 보는 창인지 제목을 달았습니다.

## 3D 스캔 (Lot 판정 기준 추가)
- S/M에 **3D**가 붙은 스캔(예: `ABC-3D`)은 **3D 스캔**입니다. 레시피는 2D와 같아 Lot 이름으로만 구분합니다.
- 같은 Lot의 2D · 3D 스캔은 서로 **재스캔 · 중복 Scan이 아니라 따로** 셉니다. 2번 스캔한 것으로 잡히던 문제를 고쳤습니다.
  - Lot History 시간순 요약 · Batch Report 이력: `처음 3D 스캔 → 5분 뒤 2D 스캔`처럼 표시
  - Lot × wafer 오류 지도 · wafer 취합: 2D와 3D를 **별도 표**로
  - 중복 Scan wafer · Lot 지표, Lot · wafer 취합(Dice 합계), Excel, 가동률 레시피 점유, WPH 레시피, Lot 추적 HTML에서도 3D를 따로 표시
  - Lot 목록에 `3D 스캔 포함` 표시, ? 판정 기준에 `3D 스캔` 항목 추가
- 같은 호기에서 이어서 스캔했는지 볼 때, 웨이퍼 표 마지막 열 **Recipe(s)**가 있는 Batch Report끼리는 Recipe(s)가 같아야 같은 스캔으로 봅니다
  (그 열이 없는 Batch Report는 종전처럼 시간 · 호기로만 판단).

## 프로그램 전체
- 새 창(대화 상자)이 열려 있으면 **그 창만 스크롤**되고 뒤에 깔린 화면은 움직이지 않습니다.
