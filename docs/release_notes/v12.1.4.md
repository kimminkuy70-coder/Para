# Camtek AOI Manager v12.1.4

Batch Report 분석의 **[조사 시작]** 이 **이미 조사한 Batch Report는 그대로 두고 새 Batch Report만 빠르게 찾아 더하도록** 바꿨습니다.
또 저장되는 **결과 HTML**에도 앱과 같은 **상위 레시피 필터**를 넣었습니다.

## 조사 — 이미 조사한 것은 두고 신규만
- 호기 폴더 목록을 **한 번만** 읽어 파일 이름 · 수정시각 · 크기가 지난번과 같은 Batch Report는 장비에 다시 묻지 않고 저장된 자료를 그대로 씁니다.
  새로 생기거나 바뀐 Batch Report만 열어 읽고 결과에 더합니다.
- 새 Batch Report가 없으면 저장된 자료 파일을 다시 쓰지 않고, 같은 앱 실행 중 두 번째 조사부터는 저장된 자료를 메모리에서 바로 씁니다.
- 호기 사이 2초 간격(장비 접속 매너)은 **앞 호기에서 Batch Report를 실제로 읽었을 때만** 둡니다. 같은 호기의 추가 폴더 사이에는 간격이 없습니다.
- **병렬 읽기는 하지 않습니다.** 지금처럼 한 폴더씩 순서대로 읽습니다.
- 새 Batch Report도 없고 조사 범위 · 옵션도 지난 조사와 같으면 결과 파일(HTML · Excel)을 다시 만들지 않고 **지난 결과 폴더를 그대로** 씁니다
  (상태 문구: '새 Batch Report가 없어 지난 결과 파일을 그대로 씁니다'). 날짜가 바뀌면 새로 만듭니다.
- 조사 중 상태 문구는 새로 읽는 파일만 보여 주고, 새 것이 없는 호기는 '새 Batch Report 없음 (캐시 n개)'으로 표시합니다.

## 결과 HTML — 상위 레시피 필터
- 저장된 **분석 HTML(BatchReport_분석.html)** 과 **가동률 대시보드**의 WPH · 생산능력 탭에 앱과 같은 **상위 레시피 필터**를 넣었습니다.
  칩을 눌러 여러 상위 레시피를 함께 고르고, **[전체 보기]** 로 풀 수 있습니다. 상위 레시피가 많으면 찾기 칸과 **[찾은 것 모두 고르기]** 가 나타납니다.
- 고른 상위 레시피로 **레시피 비교 · 호기 × 레시피 표 · 숫자 4개(정상 WPH · 실제 WPH · 처리량 감소 · 레시피 · 호기)** 가 함께 걸러집니다.
- 결과 HTML도 앱처럼 **[상위 레시피] / [하위]** 배지와 상위 레시피 묶음으로 구분해 보여 줍니다.

## 참고
- 계산식과 지표 정의는 바뀌지 않았습니다.
- 실제 장비 공유폴더에서의 속도 개선 폭은 장비 · 네트워크 환경에 따라 다릅니다.
