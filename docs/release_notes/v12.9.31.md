# Camtek AOI Manager v12.9.31

**Windows Defender 가 v12.9.30 zip 을 바이러스로 막아 받을 수 없던 문제를 고쳤습니다. 기능은 v12.9.30 과 같습니다.**

## 설치 파일 › Windows Defender 차단
- v12.9.30 zip 을 받으면 Windows Defender 가 막아 다운로드가 되지 않았습니다.
- 원인: 엔진 실행 파일(`sidecar\Camtek_AOI_engine.exe`)이 PyInstaller 기본 실행기를 그대로 썼습니다. 이 실행기는 서명 없는 프로그램 수많은 곳에서 같이 쓰여 Defender 클라우드 판정(ML)이 악성으로 잡기 쉽습니다. v12.9.29 와 v12.9.30 의 엔진 파일은 버전 정보 16 byte 만 다른데 v12.9.30 만 막혔습니다. 프로그램 코드의 문제가 아닙니다.
- 수정: 빌드할 때 PyInstaller 실행기를 소스에서 직접 만들어 씁니다. 엔진 파일이 기본 실행기와 다른 파일이 됩니다.
- 프로그램 기능 · 설정 · 저장 자료는 바뀌지 않았습니다.
- 그래도 막히면 Defender 보호 기록의 '위협 이름'과 '영향을 받는 항목' 경로를 알려 주십시오.
