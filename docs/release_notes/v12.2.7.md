# Camtek AOI Manager v12.2.7

**Batch Report 조사가 실패할 때 실제 원인을 알려 주도록** 고쳤고, 호기가 많을 때(예: 18대) 결과 파일을 만드는 단계의 **메모리 사용을 줄였습니다.**

## 조사 실패 원인 안내
- 지금까지는 조사가 어떤 이유로 실패해도 "폴더 접근과 로컬 저장 공간을 확인해 주세요" 한 문장만 나와, 폴더 설정 문제처럼 보였습니다.
- 이제 원인별로 알려 줍니다.
  - **메모리 부족**: 한 번에 조사한 호기 · 기간이 너무 많음 → 다른 프로그램을 닫고 앱을 다시 시작하거나, 호기를 나눠(예: 9대씩) 조사하세요.
  - **폴더 · 설정 문제**: 엔진이 확인한 내용(예: "기존 Report 폴더 설정을 확인하세요")을 그대로 보여 줍니다.
  - **파일 읽기 · 쓰기 오류**: Windows 오류 내용과 코드(디스크 공간 · 권한 확인).
- 실패 원인(traceback)이 **오류 로그**에도 남아 [진단 로그 묶기] 파일로 바로 확인할 수 있습니다.

## 메모리 절감
- Lot 추적 HTML 에 담는 Batch Report 원문 표를 한 장씩 압축하도록 바꿔, 18대처럼 원문이 많을 때 필요한 메모리를 크게 줄였습니다. 결과 파일의 모양 · 내용은 같습니다.

## 참고
- 그 밖의 기능 · 계산은 v12.2.6 과 같습니다.
