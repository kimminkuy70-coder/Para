## Camtek AOI Manager v14.1.2 — Defect 분석: Surface.flt 레코드 크기를 .md 에서 읽음

- **Defect 분석(대규모 · 기본)에서 Slot 이 '잘못된 Record Size' 로 모두 빠지던 문제를 고쳤습니다.** (이슈 #74)
  - 원인: 프로그램이 Surface.flt 한 Defect 의 크기를 152 byte 로 고정해 읽었습니다. 이 Lot 의 Surface.flt 는 한 Defect 가 136 byte 라서(25 Slot 모두 136 의 배수) 152 로 나누면 나머지가 남았습니다.
  - 지금: 같은 폴더(Slot → 하위 → Lot 쪽 순서)의 `Surface.flt.md` 에 적힌 레코드 크기와 필드 위치로 읽습니다. md 가 없거나 파일 크기와 맞지 않으면 종전처럼 152 byte 로 읽습니다.
  - 레코드 크기가 152 가 아니면 경고 칸에 'Surface.flt 레코드 136 byte(Surface.flt.md 기준)' 처럼 보입니다.
  - 그래도 오류가 나면 오류 글에 md 가 있었는지와 그 레코드 크기가 함께 나옵니다. 'Surface.flt.md 없음' 이면 장비 결과 폴더의 `Surface.flt.md` 를 Slot 또는 Lot 폴더에 두십시오.

### 처음 설치

1. 아래 `Camtek_AOI_manager_v14.1.2_install.zip` 을 받으십시오.
2. 프로그램을 종료하십시오(알림 영역 아이콘이 있으면 [종료]).
3. `%LOCALAPPDATA%\CamtekAOI\app` 폴더에 zip 을 풀어 덮어쓰십시오(처음이면 폴더를 만들고 그 안에).
4. `Camtek_AOI_manager.bat` 을 더블클릭하거나 바탕화면 바로가기로 실행하십시오.
