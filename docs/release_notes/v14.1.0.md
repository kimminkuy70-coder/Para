## Camtek AOI Manager v14.1.0 — Defect 분석 화면 재구성

### Defect 분석 탭

- **하위 탭 3개**: **Color·Gray 매칭** · **Defect 분석(대규모)** · **Defect 분석(기본)**. 탭을 열면 Color·Gray 매칭이 먼저 보입니다.
  - 종전 '다이어그램 분석(Step 1 ~ 4) 보이기' 체크는 없앴습니다. Step 1 ~ 4 는 **Defect 분석(기본)** 탭에 늘 있습니다.
- **Defect 분석(대규모 · 기본)이 프로그램과 같은 화면 모양**이 되었습니다.
  - 위쪽 남색 머리 · 왼쪽 막대가 없어지고, 단계(5-1 ~ 5-3, Step 1 ~ 4)는 Color·Gray 매칭과 같은 단계 표시로 나옵니다.
  - 카드 · 단추 · 입력 칸 · 표가 프로그램의 다른 탭과 같은 모양입니다. 지도 · 벤다이어그램 · 사진 색은 종전 그대로입니다.
  - 화면이 길어져도 스크롤은 프로그램 페이지 하나만 움직입니다.
- **설명글은 [? 설명 보기] 체크로** 켜고 끕니다(처음에는 꺼짐, 이 PC 에 기억). Contrast 도움말도 설명을 켜면 나옵니다. 진행 상태 · 개수 · 결과 알림은 늘 보입니다.
- **Wafer Map 샘플(기준)** 이 Defect 분석(기본) Step 2 맨 위의 강조 칸으로 올라왔습니다.
- 사진 상태 이름 **'짝 완료' → 'Color·Gray 매칭 완료'**(목록 · 숫자 카드 · 보기 고르기 · 사진 새 창 · CSV/엑셀 '상태' 값). '✖ 짝 없음' → '✖ 매칭 없음', 결과 목록 CSV 기본 이름 `Defect_매칭_…`.

분석 계산 · 필터 · 사진 짝짓기 · GL 측정 · 엑셀/CSV 저장 동작은 바뀌지 않았습니다(실자료로 확인한 HTML 동작 그대로). 원본 폴더는 읽기만 합니다.

### 업데이트

- v14.0.0 에서는 프로그램의 업데이트 알림으로 받습니다.
- v13 판에서는 v13.0.3 을 거쳐 업데이트 알림으로 받거나, 아래 설치 zip 을 같은 폴더에 풀어 덮어쓰십시오.

### 처음 설치

1. 아래 `Camtek_AOI_manager_v14.1.0_install.zip` 을 받으십시오.
2. 프로그램을 종료하십시오(알림 영역 아이콘이 있으면 [종료]).
3. `%LOCALAPPDATA%\CamtekAOI\app` 폴더에 zip 을 풀어 덮어쓰십시오(처음이면 폴더를 만들고 그 안에).
4. `Camtek_AOI_manager.bat` 을 더블클릭하거나 바탕화면 바로가기로 실행하십시오.

자세한 안내: 저장소 `docs/설치_v13.md`(v14 도 같은 방식)
