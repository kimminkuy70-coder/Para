## Camtek AOI Manager v14.3.18 — 자동 분석 호기 현황 · 호기 설정 이동

- 자동 분석 및 취합 › Batch Report 자동 분석 탭에 **자동 분석 호기 현황** 목록 추가(호기마다 ✓ 포함 / — 빠짐, 기간 · 검색어)
- **[⚙ 자동 분석 호기 설정]** 단추: Batch Report 분석 › 가동률 조사 및 분석의 호기 고르기로 바로 이동(호기를 고르고 [조사 시작]을 누르면 자동 분석 호기가 바뀜)
- Batch Report 찾기: 파일 이름을 '….html' 로 넣어도 실제 '.htm' 파일을 찾음
