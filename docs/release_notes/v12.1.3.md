# Camtek AOI Manager v12.1.3

Batch Report 분석의 **WPH · 생산능력**에서 **상위 레시피와 하위 레시피가 한눈에 구분**되게 바꾸고, **상위 레시피를 여러 개 골라** 비교할 수 있게 했습니다.

## WPH · 생산능력 — 상위 레시피 / 하위 레시피 구분
- 레시피 이름은 **상위 레시피(Job) · 하위 레시피(Recipe(s))** 입니다. 이제 화면에 두 단계를 나눠 보여 줍니다.
- **레시피 비교**: 상위 레시피마다 왼쪽에 진한 띠가 있는 **묶음 상자**로 나누고, 맨 위 줄에 **[상위 레시피]** 배지 · 이름 · 하위 레시피 수 · 호기 수 · Batch Report 수를 보여 줍니다.
  그 아래 하위 레시피 줄은 **[하위]** 배지와 함께 들여 써서 어느 상위 레시피에 속하는지 보입니다.
- **호기 × 레시피 표**: 상위 레시피 머리 줄(배지 + 요약) › 하위 레시피 합계 줄([하위] 배지) › 호기별 줄 순서로 들여 써서 구분합니다.
- 상위 레시피끼리는 die 수가 달라 생산능력을 더하지 않습니다(묶음 머리 줄에는 막대가 없습니다).

## 상위 레시피 필터 (여러 개 고르기)
- 숫자 4개 위에 **상위 레시피 필터**를 추가했습니다. 칩을 눌러 **여러 상위 레시피를 함께** 고를 수 있고, 다시 누르면 빠집니다. **[전체 보기]**로 한 번에 풀 수 있습니다.
- 아무것도 고르지 않으면 전체를 보여 줍니다. 상위 레시피가 많으면 찾기 칸과 **[찾은 것 모두 고르기]**가 나타납니다.
- 고른 상위 레시피로 **레시피 비교 · 호기 × 레시피 표 · 숫자 4개 · 기간별 추이**가 함께 걸러지고, 하위 레시피 선택 목록도 그 상위 레시피 것만 보여 줍니다.
- 상위 · 하위 레시피의 뜻과 필터 동작은 필터 옆 **?** 버튼에서 볼 수 있습니다.

## 참고
- 계산식과 지표 정의는 바뀌지 않았습니다. 저장된 결과 파일(분석 HTML / Excel)의 WPH 내용도 그대로입니다.
