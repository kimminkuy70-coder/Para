# Camtek AOI Manager v12.8.18

**Batch Report 자동 분석을 하루 중 원하는 시각(5분 단위)에 돌릴 수 있고, 꺼 둔 채로도 [▶ 즉시 실행]으로 바로 분석할 수 있습니다. 프로그램의 '감시' 표현은 모두 '분석 및 취합'으로 바뀌었습니다.**

## Batch Report 자동 분석 실행 시각
- 설정 › Batch Report 분석 주기 설정에서 분석 주기가 **하루 1회 · 2일마다 · 일주일 1회**처럼 하루 단위이면 **실행 시각 (시)** 과 **분 (5분 단위)** 을 고를 수 있습니다(예: 07:35).
- 시각을 정하면 그 시각에 분석합니다. 하루 1회 07:35라면 07:35에 분석한 뒤 다음 날 07:35에 다시 분석합니다. 그 시각에 앱이 꺼져 있었다면 앱을 켠 뒤 곧 실행합니다.
- **지정 안 함**을 고르면 지금까지처럼 마지막 실행 시각부터 주기가 지나면 실행합니다. 6시간 · 12시간 주기에는 시각 칸이 나오지 않습니다.
- [현재 설정] 표의 Batch Report 자동 분석 줄에 정한 시각이 함께 보입니다.

## [▶ 즉시 실행]
- 자동 분석을 꺼 둔 상태에서도 **[▶ 즉시 실행]** 을 누르면 지난 조사 조건(호기 · 기간 · 지표)으로 지금 한 번 분석합니다. 이미 읽은 Batch Report는 다시 읽지 않습니다.
- 버튼은 설정 › Batch Report 분석 주기 설정과 Batch Report 분석 화면(자동 분석 켜짐/꺼짐 줄)에 있습니다. 설정에서 누르면 Batch Report 분석 화면으로 이동해 진행 상황을 보여 줍니다.
- 아직 한 번도 조사하지 않았으면 먼저 [조사 시작]을 한 번 눌러 달라는 안내가 나옵니다.

## '감시' → '분석 및 취합'
- 탭 이름 **자동 감시**가 **자동 분석 및 취합**으로 바뀌었습니다. 파라미터 · Commonality 자동 분석 및 취합 화면, 알림, 작업 진행 표시, 트레이 메뉴(자동 분석 및 취합 종료), 둘러보기 안내의 문구도 모두 같이 바뀌었습니다.
- 기존 설정과 결과 파일은 그대로 이어서 씁니다(`감시설정.json`, `자동감시` 폴더 같은 파일 · 폴더 이름은 바꾸지 않았습니다).
