## Camtek AOI Manager v14.1.3 — Defect 분석(대규모): Recipe 개수가 필터를 따름

- **Defect 분석(대규모) 5-1 의 Recipe 고르기 칸 괄호 안 개수가 필터에 맞게 바뀝니다.** (이슈 #75)
  - 종전: Lot 필터를 걸어도 Recipe 마다 괄호 안 수가 등록한 전체 Defect 수 그대로였습니다.
  - 지금: Lot · Slot 고르기, Lot 제외 체크, 첫번째 분류 · 재분류 체크, Contrast · Area · Width · Length 범위에 맞는 Defect 만 셉니다.
  - Recipe 를 고른 상태에서도 다른 Recipe 의 개수가 같은 필터 기준으로 보입니다. 그래서 다른 Recipe 로 바로 바꿀 수 있습니다.
  - 고른 Recipe 가 필터 때문에 0개가 되어도 칸에 '(0)' 으로 남습니다.

### 업데이트

- v14.1.1 · v14.1.2 에서는 프로그램 시작 때 뜨는 업데이트 알림으로 받으십시오.
- v14.0.0 · v14.1.0 에서도 업데이트 알림으로 받습니다. v13 판에서는 v13.0.3 을 거쳐 업데이트 알림으로 받거나, 아래 설치 zip 을 같은 폴더에 풀어 덮어쓰십시오.

### 처음 설치

1. 아래 `Camtek_AOI_manager_v14.1.3_install.zip` 을 받으십시오.
2. 프로그램을 종료하십시오(알림 영역 아이콘이 있으면 [종료]).
3. `%LOCALAPPDATA%\CamtekAOI\app` 폴더에 zip 을 풀어 덮어쓰십시오(처음이면 폴더를 만들고 그 안에).
4. `Camtek_AOI_manager.bat` 을 더블클릭하거나 바탕화면 바로가기로 실행하십시오.

자세한 안내: 저장소 `docs/설치_v13.md`(v14 도 같은 방식)
