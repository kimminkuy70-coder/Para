## Camtek AOI Manager v13.0.0 — 실행 파일 없는 새 설치 방식

v12.9.30 ~ 32 의 설치 zip 이 Windows Defender 에 막히던 문제의 해결판입니다. 기능은 v12.9.30 과 같습니다.

- **우리가 만든 exe 가 없습니다.** python.org 의 Python(서명됨)이 프로그램 파일을 실행하고, 화면은 Edge 의 별도 창입니다.
- **업데이트** = 프로그램을 켤 때 새 버전이 있으면 알림 창 → [지금 업데이트]. GitHub 릴리스에서 받고(인터넷은 이때만), 안 되면 OneDrive 게시 폴더.
- 예전 tkinter 프로그램은 v13 에서 뺐습니다(v12 는 그대로 남아 있습니다).

### 처음 설치

1. 아래 `Camtek_AOI_manager_v13.0.0_설치.zip` 을 받으십시오.
2. `%LOCALAPPDATA%\CamtekAOI\app` 폴더를 만들고 그 안에 푸십시오(OneDrive · 바탕화면에 풀지 마십시오).
3. Win + R → 아래 한 줄 → Enter. 다음부터는 바탕화면 바로가기로 실행합니다.

```
"%LOCALAPPDATA%\CamtekAOI\app\python\pythonw.exe" "%LOCALAPPDATA%\CamtekAOI\app\Camtek_AOI_manager.pyw"
```
