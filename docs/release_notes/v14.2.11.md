## Camtek AOI Manager v14.2.11 — 멈춘 이유 요약 필터

- Batch Report 분석 › Lot 추적 › **멈춘 이유 요약**에 **레시피 · 호기 · Error 필터**를 더했습니다. 고른 값에 맞는 Lot만 셉니다.
- [호기별 표] 보기를 더했습니다. 줄 = Error 원문, 열 = 호기, 칸 = 그 호기에서 그 Error가 난 Lot 수(괄호 안 = Pass하지 못한 Lot)입니다.
- 예: 레시피 하나와 Error 하나를 고르고 [호기별 표]를 누르십시오. 그 레시피에서 호기마다 그 Error가 몇 Lot 났는지 한 줄로 보입니다.
- 표의 칸을 누르면 그 Lot들만 위 목록에 보입니다. 작업자 중단 보기도 레시피 · 호기 필터를 따릅니다.
- Error는 **Error가 난 Batch Report의 호기 · 레시피**로 셉니다(다른 호기로 옮겨 재스캔해도 처음 Error 난 호기).
