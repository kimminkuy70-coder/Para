# Camtek AOI Manager v12.1.2

Batch Report 분석의 **WPH · 생산능력**도 가동률처럼 **일 · 주 · 월별**로 볼 수 있게 했습니다.

## WPH · 생산능력 — 기간별 추이 (일 · 주 · 월)
- `가동률 조사 및 분석 › WPH · 생산능력`의 보기에 **[기간별 추이]**를 추가했습니다(레시피 비교 · 호기 × 레시피 표 옆).
- 옆의 **기간 단위 [일 | 주 | 월]**로 바꿀 수 있습니다. 주는 가동률과 같은 `WW` 번호(월요일 시작)와 날짜 범위로 보여 줍니다.
- 기간마다 **정상 WPH · 실제 WPH · 처리량 감소 · 하루 생산능력 · Pass 장수 · 하루 평균 Pass · Batch Report 수**를 표로 보여 주고,
  **그래프 값 [실제 WPH | 정상 WPH | 하루 생산능력 | Pass 장수]** 중 하나를 막대 그래프로 봅니다(왼쪽이 오래된 기간, 마우스 = 기간별 값 전체).
- 위에서 고른 **레시피 · 호기 · 조사 범위**를 그대로 따릅니다. 계산식은 지금까지와 같고 기간마다 다시 계산할 뿐입니다
  (하루 생산능력 = 호기마다 24 × 그 기간 실제 WPH 의 합, 레시피를 고르지 않으면 레시피 통합).
- 레시피를 고른 상태에서 기간 막대나 행을 누르면 **그 기간만으로 좁힌 레시피 상세 창**(WPH 분해 · 1장 처리 시간 · Lot별 실제 WPH)이 열립니다.
- 새 화면의 뜻 · 식 · 한계는 **?** 버튼(기간별 추이)에서 볼 수 있습니다.

## 참고
- 저장된 결과 파일(분석 HTML / Excel)의 WPH 내용은 이번에 바꾸지 않았습니다.
