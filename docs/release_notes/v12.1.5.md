# Camtek AOI Manager v12.1.5

Batch Report 분석(가동률 · Lot 추적 · WPH)이 저장하는 **결과 HTML 파일**에서도 **프로그램 화면과 같은 인터랙티브 그래프**를 볼 수 있게 했습니다.
마우스를 올리면 값이 표처럼 나오고, 누르면 상세 창이 열리며, 일 · 주 · 월과 보기 방식을 바꿀 수 있습니다.

## 분석 HTML · 가동률 대시보드 — 가동률
- **호기 탭**(전체 호기 / 호기별)과 숫자 4개(가동률 · Error · 중단 및 조치 · 유휴 · 달력 시간)가 고른 호기에 맞춰 바뀝니다.
- **시간 구성**: 호기별 / 기간별(일 · 주 · 월) 막대, 범례를 눌러 항목을 켜고 끌 수 있습니다. 호기 막대를 누르면 그 호기 탭, 기간 막대를 누르면 **기간 상세 창**
  (시간 구성 · 손실 이유 · 24시간 시간표)이 열립니다. 손실 이유를 누르면 그 Lot 목록이 나옵니다.
- **24시간 시간표**: 날짜(◀ ▶)를 옮겨 가며 호기별 Batch Report 막대와 조치 대기를 봅니다. 막대에 마우스를 올리면 Lot · S/M · Pass · 첫 Error 원문이 나옵니다.

## 분석 HTML · 가동률 대시보드 — WPH · 생산능력
- 프로그램처럼 **하위 레시피 · 호기 선택**, **상위 레시피 필터**, 숫자 4개(정상 WPH · 실제 WPH · 처리량 감소 · 하루 생산능력)를 씁니다.
- 보기: **레시피 비교 · 호기 × 레시피 표 · 기간별 추이**(일 · 주 · 월, 그래프 값 실제 WPH / 정상 WPH / 하루 생산능력 / Pass 장수).
- 레시피(또는 호기 막대 · 표 행)를 누르면 **레시피 상세 창** — WPH 분해, 1장 처리 시간과 정상 25매 WPH 분포, Lot별 실제 WPH 산점도.

## 분석 HTML · Lot 추적 HTML — Lot 추적
- **기간별 Lot Scan 현황** 그래프(일 · 주 · 월, 한 번에 완료 / 재스캔으로 완료 / Pass하지 못한 Lot)를 넣었습니다.
  Lot 추적 HTML 에서는 막대를 누르면 그 기간 Lot만 목록에 보입니다.
- 분석 HTML 에서 Lot 이름을 누르면 같은 폴더의 **Lot 추적 HTML 이 열리며 그 Lot의 Lot History** 가 바로 나옵니다.

## 참고
- 계산식과 지표 정의는 바뀌지 않았습니다(프로그램과 같은 식).
- 결과 HTML 에는 원본 파일 경로가 없어 Batch Report 원문 창은 프로그램에서만 엽니다. 가동률 대시보드에서는 Lot 링크가 없습니다.
- v12.1.4 는 이미 릴리즈된 버전이라 이번 변경은 v12.1.5 로 나갑니다.
