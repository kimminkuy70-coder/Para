# Camtek AOI Manager v11.0.0

v10.2.0 의 **Wafer Map 수정하기** 탭과 **Batch Report Lot 추적**을 모두 포함하고, 아래가 새로 바뀌었습니다.

## 메모 탭 통합
- 상단 탭 `특이사항` · `참고자료` · `장비 IP` 를 **`메모`** 탭 하나로 묶었습니다. 메모 탭 안의 하위 탭으로 세 문서를 오갑니다.
- 각 문서의 편집 방식과 편집 잠금(한 사람만 편집, 다른 하위 탭으로 옮기면 잠금 반납)은 그대로입니다.

## Wafer Map 수정하기
- 1단계 변환 방향 버튼(TXT → Excel / Excel → TXT)이 두 줄로 꺾이지 않고 같은 폭으로 나란히 보입니다.

## Batch Report 분석
- Lot 상태 이름을 **`Pass하지 못한 wafer 존재`** 로 바꿨습니다(종전 `Pass 못 한 웨이퍼 있음`).
- '조사 시작' 옆 **? Lot 판정 기준** 문구를 정리했습니다. 같은 Lot 을 12시간 이내에 다시 스캔한 것을
  '이어서 스캔'으로 설명하고, 같은 wafer 가 Pass 를 여러 번 받았을 때 가장 나중 Pass 를 쓴다는 설명을 보탰습니다.
