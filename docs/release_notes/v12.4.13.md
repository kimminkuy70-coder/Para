# Camtek AOI Manager v12.4.13

**Recipe 값 확인의 비고 칸에 RTP.txt 의 파라미터 설명(영어 원문 / 한글 번역)이 채워집니다.**

## Recipe 값 확인 — 비고에 RTP.txt 설명
- Recipe 업데이트(값 취합)를 하면 장비에서 함께 가져온 **RTP.txt 의 설명**을 파라미터마다 찾아 **비고 칸**에 넣습니다.
- 번역이 있으면 **`영어 원문 / 한글 번역`** 으로 함께 보여 주고, 번역이 없는 항목은 영어 원문만 넣습니다. 한글 번역은 프로그램에 들어 있는 번역표를 쓰며 인터넷에 접속하지 않습니다.
- 양식에 직접 적어 둔 비고가 있으면 그 비고를 그대로 두고, **비어 있는 비고만** 채웁니다.
- 기존 취합 파일에는 바로 나타나지 않습니다. **다음 Recipe 업데이트부터** 비고에 설명이 들어가며, Excel 내보내기에도 함께 나옵니다.
- RTP.txt 가 없거나 RTP.txt 에서 이름이 맞는 설명을 찾지 못한 항목은 비고가 비어 있습니다.
