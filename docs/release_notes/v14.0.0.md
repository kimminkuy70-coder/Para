## Camtek AOI Manager v14.0.0 — Defect 분석 탭(대규모 Defect 분석 · Color·Gray 매칭)

### Defect 분석 탭 (종전 'Color·Gray 매칭' 탭)

CAMTEK › **Defect 분석** 탭 안에 하위 탭이 생겼습니다.

- **대규모 Defect 분석** — AOI Contrast Wizard(HTML) Step 5 의 기능을 프로그램 안에서 그대로 씁니다. 5-1 Contrast · Area · 분류(첫번째 분류 · 재분류) · Recipe · Lot 필터와 정렬, 5-2 Color · Gray 사진 짝짓기, 5-3 사진 정밀 조사(흑백 GL 원 측정 · 최종 목록 선택 · 사진 포함 엑셀)를 모두 쓸 수 있습니다.
  - **폴더를 읽는 시간이 크게 줄었습니다.** 브라우저로 HTML 을 열면 폴더를 고른 뒤 브라우저가 사진까지 모든 파일을 '업로드' 목록으로 처리하느라 오래 기다렸습니다(50만 파일이면 1시간 가까이). 프로그램에서는 엔진이 네트워크 폴더를 직접 읽고, 필요한 파일(Slot 마다 약 10개)만 엽니다. 사진은 보는 Defect 의 것만 읽습니다.
  - **[원본 폴더 경로]를 적지 않아도 됩니다.** 고른 폴더의 전체 경로를 프로그램이 알아, 사진 경로 · CSV · 엑셀에 전체 경로가 바로 나옵니다.
  - Edge 가 .ini 파일을 막아 생기던 안내(빠른 폴더 읽기 막힘)가 더 이상 나오지 않습니다.
  - 사진 새 창이 막히면 같은 창 안에 전체 화면으로 띄웁니다. 머리의 '같은 창에서 보기'를 켜면 처음부터 같은 창 안에 띄웁니다.
- **Color·Gray 매칭** — 종전 기능 그대로입니다. 여기에 **최종 목록 CSV 불러오기**를 더했습니다.
  - 대규모 Defect 분석 5-3 에서 ☑ 한 Defect 를 **📄 최종 목록 CSV 저장**으로 저장하고, Color·Gray 매칭의 **📄 최종 목록 CSV 고르기**에서 그 파일을 고르면 **그 Defect 만** 추출합니다.
  - 결과 폴더에는 종전 결과 파일과 함께 **최종 목록 엑셀**이 생깁니다. 대규모 Defect 분석의 최종 목록 엑셀과 같은 열에, 사진 3장(Color · 빨간 네모 Gray Crop · 노란 상자 Gray 프레임)이 들어갑니다. 사진이 없는 줄은 '사진 없음 이유' 칸에 까닭이 적힙니다.
- **다이어그램 분석 (Step 1 ~ 4)** — 하위 탭 줄 오른쪽 '다이어그램 분석(Step 1 ~ 4) 보이기'를 켜면 나타납니다(이 PC 에 기억). 두 Step Lot 비교 · Wafer Map 분석 · Escape Defect 리뷰를 프로그램 안에서 씁니다.

원본 폴더는 읽기만 합니다. 프로그램은 고른 폴더 아래에서 파일을 나열하고 읽기만 하며, 쓰기 · 지우기 · 옮기기는 하지 않습니다. 결과는 종전처럼 로컬 디스크(또는 저장 창에서 고른 곳)에만 저장합니다.

### 업데이트

- **v13 에서 v14 로는 프로그램의 업데이트 알림이 뜨지 않습니다.** v13 판은 v13.x.y 판만 찾게 만들어져 있습니다. 아래 '처음 설치' 순서로 v14 설치 zip 을 같은 폴더에 풀어 주십시오. 설정 · 캐시 · OneDrive 공유 자료는 그대로 이어서 씁니다.
- v14 부터는 이후 판(v14.x.y, v15 …)을 프로그램의 업데이트 알림으로 받습니다.

### 처음 설치 · v13 에서 옮기기

1. 아래 `Camtek_AOI_manager_v14.0.0_install.zip` 을 받으십시오.
2. 프로그램을 종료하십시오(알림 영역 아이콘이 있으면 [종료]).
3. `%LOCALAPPDATA%\CamtekAOI\app` 폴더에 zip 을 풀어 덮어쓰십시오(처음이면 폴더를 만들고 그 안에).
4. `Camtek_AOI_manager.bat` 을 더블클릭하거나 바탕화면 바로가기로 실행하십시오.

자세한 안내: 저장소 `docs/설치_v13.md`(v14 도 같은 방식)
