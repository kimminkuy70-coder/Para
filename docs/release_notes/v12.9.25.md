# Camtek AOI Manager v12.9.25

**자동 분석에 KLA 캐시 갱신을 넣을 수 있습니다. 자동 분석의 다음 실행 날짜가 며칠 뒤로 밀리던 것을 고쳤습니다. KLA 자재 찾기 화면을 Batch Report 찾기 · 취합과 같은 모양으로 맞췄습니다.**

## 자동 분석 › KLA 탭
- CAMTEK › 자동 분석 및 취합 › [Batch Report 자동 분석] 에 탭 2개를 두었습니다: [CAMTEK · Batch Report] / [KLA · KLA 캐시].
- [KLA] 탭에서 "자동 분석에 KLA 캐시 갱신 넣기"를 켜면, 같은 주기 · 실행 시각에 KLA 캐시도 갱신합니다(KLA 자재 찾기 › 🛠 개발자 기능 › [캐시 갱신]과 같음 — 장비 폴더 이름만 읽음).
- "갱신이 끝나면 KLA 캐시 zip 을 OneDrive 에 올리기"를 켜면 갱신 뒤 캐시공유 폴더에 게시합니다(Camtek 캐시와 같은 폴더, 이름으로 구분, 최근 3개 보관).
- Batch Report 분석이 끝난 뒤 이어서 돌고, Camtek 지난 조사 조건이 없으면 KLA 만 돕니다. [▶ 즉시 실행]에도 들어갑니다.

## 자동 분석 다음 실행 날짜
- 자동 분석을 켜거나 분석 주기 · 실행 시각을 바꾸면 그때부터 다시 셉니다. 실행 시각을 정했으면 다음 실행 = 그 뒤 첫 실행 시각(오늘 또는 내일)입니다.
  (종전: 예전 마지막 실행 기록에서 세어, 오늘 켜도 다음 실행이 며칠 뒤로 나왔습니다.)
- 하루 단위 주기(하루 1회 · 2일 · 일주일)에는 연속 실패 · 일부 오류 때 실행을 미루는 배수(2 · 4 · 8배)를 쓰지 않습니다. 하루 1회가 8일 뒤로 밀리던 것을 고쳤습니다.

## KLA 자재 찾기 화면
- 찾을 장비를 Batch Report 찾기 · 취합과 같은 장비 상자 격자 · [모든 장비] 체크로 고릅니다.
- [찾을 곳] 선택 버튼 대신 **[KLA 캐시에서만 찾기]** 체크 상자를 두었습니다(Batch Report 의 [캐시에서만 찾기]와 같은 모양). 켜면 장비에 접속하지 않고 로컬 KLA 캐시에서만 찾습니다. 캐시에 든 장비를 골라 찾을 수 있습니다.
- Lot 키워드 · 시작일 · 종료일 · [검색 →] 배치를 Batch Report 찾기와 같게 맞췄습니다.
