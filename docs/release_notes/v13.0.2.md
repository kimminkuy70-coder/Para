## Camtek AOI Manager v13.0.2 — 프로그램 창 아이콘을 기존 아이콘으로

### 프로그램 아이콘 (#65)

- 프로그램 창(Edge 앱 창)의 제목 표시줄 · 작업 표시줄 아이콘이 기존에 쓰던 프로그램 아이콘(웨이퍼 · AOI 카메라 · 파라미터 슬라이더, 파랑 → 청록)으로 바뀝니다. 종전에는 기본 웹 페이지 아이콘이 보였습니다.
- 바탕화면 바로가기와 알림 영역(트레이) 아이콘은 종전과 같이 이 아이콘을 씁니다.
- 설치 zip 의 `Camtek_AOI_manager.bat` 은 Windows 가 아이콘을 바꿀 수 없는 파일입니다. 첫 실행 뒤 생기는 바탕화면 바로가기로 실행하면 이 아이콘이 보입니다.

### 업데이트

- v13.0.0 · v13.0.1 을 쓰고 있다면 프로그램의 업데이트 알림으로 v13.0.2 를 받으십시오. 알림 창에서 [지금 업데이트] → 프로그램을 종료하고 다시 실행하면 적용됩니다.

### 처음 설치

1. 아래 `Camtek_AOI_manager_v13.0.2_install.zip` 을 받으십시오.
2. `%LOCALAPPDATA%\CamtekAOI\app` 폴더를 만들고 그 안에 푸십시오.
3. `Camtek_AOI_manager.bat` 을 더블클릭하십시오.
