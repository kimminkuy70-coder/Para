# Camtek AOI Manager v10.2.0

## 새 기능: Wafer Map 수정하기 탭
- 상단에 **`Wafer Map 수정하기`** 탭을 새로 만들었습니다(외부 도구 'Wafer Map Converter v6' 이식).
  단계별 화면(변환 방향·폴더 → 파일 선택 → 저장 위치 → 실행 검토 → 처리 진행 → 완료)으로 진행합니다.
- **TXT → Excel**: Wafer Map TXT 를 색칠된 맵(`_Map_Edit.xlsx`)으로 펼칩니다. 오른쪽 범례의 Bin Code 셀을
  복사해 die 셀에 붙여넣으면 코드와 색이 함께 바뀝니다. 앞자리 0(예: `003`)은 그대로 유지됩니다.
- **Excel → TXT**: 고친 Excel 을 다시 TXT(`_Converted.txt`)로 되돌립니다.
- **원본 보존**: 원본 TXT 는 읽기만 하고 절대 바꾸지 않습니다. 손대지 않은 맵은 TXT → Excel → TXT 를 거쳐도
  **원본과 바이트가 완전히 같습니다**(인코딩·BOM·줄바꿈·끝 빈 줄까지 그대로).
- **헤더 수정 시트(`Header_Edit`)**: DEVICE·LOT·WAFER·FNLOC·BCEQU·XDIES 등 머리말 항목을
  **항목 · 원본 값 · 수정 값 · 비고(설명)** 로 보여 줍니다. 수정 값을 채운 항목만 바뀌고, 비워 두면 원본 그대로입니다.
  맵 크기(ROWCT·COLCT)는 맵과 어긋나지 않도록 수정할 수 없습니다.
- 변환할 때 **Bin Code Map / Bin Meaning Map 이미지(PNG)** 를 함께 만들고, 완료 화면에서 썸네일·확대 보기로 확인할 수 있습니다.
- 결과는 기본으로 원본 파일과 같은 폴더에 저장되며, 다른 폴더(원본 하위 구조 유지)도 고를 수 있습니다.

## Batch Report 분석
- 화면·결과 파일의 이름을 **`Batch Report`** 로 통일했습니다(결과 파일 `BatchReport_분석.html/.xlsx`).
- **Lot 추적 HTML**(`BatchReport_Lot추적.html`)을 조사 때마다 함께 만듭니다. Lot 을 고르면 묶음별 시도,
  Lot × 웨이퍼 오류 지도, Dice 합계를 볼 수 있습니다. '저장된 결과'에서 바로 열 수 있습니다.
- '조사 시작' 옆 **? 버튼**으로 Lot 판정 기준을 확인할 수 있습니다.
- 결과 표시는 해석어 대신 실제로 일어난 일 그대로(`한 번에 Pass / 재스캔 Pass / Pass 없음` 등),
  오류는 Batch Report 원문 그대로 보여 줍니다.
- 노이즈가 많던 **M09(품질 이상 후보) 지표를 없앴습니다**(기존 설정에 남아 있어도 자동으로 무시).
