# Camtek AOI Manager v12.2.5

Batch Report 분석의 **결과 HTML 디자인을 프로그램 화면과 같게** 바꾸고, **레시피 비교 모드**를 새로 넣었습니다.

## 결과 HTML — 프로그램 화면과 같은 디자인
- 분석 HTML · 가동률 대시보드 · Lot 추적 HTML · WPH 통합 HTML 이 프로그램과 같은 **상단 바 · 큰 탭 · 흰 패널 · 지표 카드 · 표 · 상태 칩**으로 바뀌었습니다.
- 조사 기간 · 호기 · Lot · Batch Report 수는 한 줄로 모으고, 긴 조사 범위는 **[조사 범위 보기]** 로 접었습니다.
- 그래프가 화면보다 넓으면 잘리지 않고 **가로 스크롤**로 볼 수 있습니다(마지막 날짜 글자도 보임).

## Lot 추적 HTML — 원문을 파일 안에
- Batch Report 마다 **[원문 보기]** 를 누르면 프로그램의 원문 창과 같은 배치(왼쪽 Batch Info · 오른쪽 wafer 결과 표)로 원문이 열립니다.
- 원문을 결과 파일 안에 담아 두어 **다른 사람 컴퓨터에서도 열립니다**(장비 폴더 링크 아님). 파일 크기는 조금 늘어납니다(예: 42MB → 46MB).

## 새 기능 — 레시피 비교
- [가동률 조사 및 분석] 아래 **[레시피 비교]** 탭: 두 그룹(A = 기존, B = 신규)에 **이름을 붙이고**, 왼쪽 레시피 목록에서 **끌어 넣거나 [A] · [B]** 를 눌러 담습니다.
  그룹마다 기간(이 날짜부터 · 까지)을 줄 수 있습니다.
- 옵션: **같은 호기끼리만**(기본) · **테스트 Lot 빼기**(기본) · 같은 wafer 짝 찾는 시간(24 · 72 · 168 · 336시간).
- 결과: ① **정상 WPH**(오류 없이 25매 모두 Pass, 주 지표) ② **실제 WPH**(오류 · 중단 시간 포함) ③ **같은 wafer 검출력** — 같은 wafer 를 두 레시피로 스캔했을 때
  누가 Bad Dice 를 더 많이 잡았는지(더 많이 / 같음 / 덜 잡음, 부호 검정 p) ④ **기준을 바꿔도 결론이 같은가** — 12가지 기준 조합의 B ÷ A.
  오류 원인별 비율(레시피 탓 / 작업자 중단)과 같은 wafer 목록(누르면 원문)도 봅니다.
- **[HTML로 저장 (원문 포함)]**: 비교 결과를 같은 디자인의 HTML 로 저장합니다. 근거가 된 Batch Report 원문이 들어 있어 다른 PC 에서도 열립니다.

## 참고
- 계산식과 기존 지표 정의는 바뀌지 않았습니다. 레시피 비교는 지금 조사 결과 안의 Batch Report 로만 계산합니다(장비 다시 읽지 않음).
- 검출력의 좋고 나쁨(결함을 더 잡은 것인지, 가성이 늘어난 것인지)은 Batch Report 만으로는 알 수 없어 리뷰 결과로 판단해야 합니다.
- 원문 창은 Edge · Chrome 에서 열립니다(오래된 브라우저에서는 안내 문구가 나옵니다).
