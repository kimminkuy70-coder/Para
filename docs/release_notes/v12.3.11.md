# Camtek AOI Manager v12.3.11

**신규 Recipe 만들기에서 양식에 넣을 하위 레시피를 고를 수 있습니다.** 같은 상위 레시피라도 호기마다 하위 레시피가 다를 때, 공통된 하위 레시피만 골라 값을 확인할 수 있습니다.

## 신규 Recipe 만들기 — 하위 레시피 선택 단계
- 단계가 4개가 되었습니다: 원본 선택 → **하위 레시피 선택** → 항목 편집 → 확정. 수집이 끝나면 하위 레시피 선택 단계로 넘어갑니다.
- 수집한 하위 레시피마다 **어느 호기에서 읽혔는지**(예: 2/3대)를 보여 주고, 일부 호기에만 있는 하위 레시피는 경고색으로 표시합니다.
- 기본은 모두 선택이며, 체크로 양식에 넣을 것만 고릅니다. 호기를 2대 이상 수집했으면 **[모든 호기에 있는 것만 고르기]** 로 공통 하위 레시피만 한 번에 고릅니다.
- 고르지 않은 하위 레시피는 항목 편집 · 확정 양식에 들어가지 않습니다. 하위 레시피별 변환계수 입력도 이 단계에서 합니다.
- Recipe 양식 편집하기 탭은 종전과 같습니다.
