# Camtek AOI Manager v12.8.22

**Batch Report 분석 › 가동률 조사 및 분석이 Batch Report 가 많을 때(호기 10대 × 호기당 5천 개 수준) 훨씬 빨리 끝나도록 고쳤습니다.**

## 속도 개선
- 호기 10대 × 호기당 Batch Report 5천 개(모두 5만 개, wafer 약 120만 장)로 시험했을 때, Batch Report 를 다 읽은 뒤 결과를 계산하고 파일을 만드는 시간이 약 9분에서 약 3분으로 줄었습니다(같은 PC 기준 약 2.8배).
  - 배치 분석 지표 계산: 약 2분 50초 → 약 1분
  - 화면용 Lot · 가동률 · WPH 계산: 약 2분 20초 → 약 40초
  - 분석 Excel · WPH 결과 파일 만들기: 약 4분 → 약 1분 40초
- 계산 결과 숫자와 결과 파일 내용 · 서식은 이전과 같습니다(같은 자료로 이전 버전과 비교해 확인).

## 참고
- Batch Report 를 장비에서 처음 읽는 시간은 그대로입니다(네트워크 속도에 따라 다름). 한 번 읽은 Batch Report 는 다음 조사부터 다시 읽지 않습니다.
- 5만 개를 한꺼번에 조사하면 메모리를 약 5GB 씁니다. PC 메모리가 8GB 이하라면 호기를 나눠 조사해 주세요.
