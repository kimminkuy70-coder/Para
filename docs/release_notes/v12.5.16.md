# Camtek AOI Manager v12.5.16

**같은 Lot이라도 레시피(RDL · PI bubble 등)가 다르면 Batch Report 찾기 · 취합과 Lot History에서 따로 나뉘어 보입니다.**

## 레시피별로 따로 묶기
- 고른 Batch Report 앞뒤 24시간을 함께 읽을 때 같은 Lot의 다른 레시피 스캔(예: RDL 뒤 PI bubble)이 들어와도, **레시피(Job · Recipe(s))가 다르면 서로 재스캔으로 보지 않고 따로 묶습니다.**
- 그동안 Recipe(s) 칸이 둘 다 `2D`이면 RDL과 PI bubble이 한 덩어리로 묶여 재스캔 · 중복 Pass · Lot 상태가 섞이던 문제를 고쳤습니다.
- **Lot History**: 시간순 그래프 · Batch Report 이력 · 오류 지도 · Lot · wafer 취합 표가 레시피 이름으로 나뉘고, 레시피가 바뀐 곳은 `레시피 바뀜`으로 표시합니다.

## Lot · Batch Report 고르기(3/4)
- 줄마다 `Lot · 레시피 · 날짜`로 보이고, **레시피별 보기** 칩으로 원하는 레시피(예: RDL)만 골라 볼 수 있습니다(여러 개 선택 가능, `레시피 전체`로 되돌림).
- 태그(`한 번에 완료` 등)는 Lot 전체가 아니라 **그 레시피 줄의 상태**로 표시됩니다.

## 참고
- 레시피가 섞여 있던 묶음에 예전에 저장한 사람 선택(중복 Pass 선택)은 묶음이 나뉘면서 적용되지 않을 수 있습니다.
