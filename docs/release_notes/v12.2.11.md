# Camtek AOI Manager v12.2.11

**Batch Report 찾기가 빨라졌습니다.** 검색하면 파일 이름 목록이 바로 나오고, 고른 것만 원문을 읽습니다. 이미 [조사 시작]으로 읽어 둔 로컬 캐시에서 먼저 찾습니다.

## Batch Report 찾기 · 취합 — 2단계 검색
- 검색하면 **파일 이름만** 보고 찾은 목록을 먼저 보여 줍니다(원문은 아직 열지 않음). 목록에서 필요한 것을 체크하고 **[고른 Batch Report 읽기 →]** 를 누르면 그것만 읽어 Lot · 공정 단계로 모읍니다.
- 단계가 4개가 되었습니다: 검색 → **찾은 파일 고르기** → Lot · Batch Report 고르기 → 취합 결과.
- 목록에는 스캔 시각 · 호기 · 파일 이름과 어디서 찾았는지(캐시 / 장비)가 보이고, [모두 고르기] · [모두 해제]가 있습니다.

## 조사 캐시에서 먼저 찾기
- [조사 시작]으로 이미 읽어 둔 **로컬 캐시에서 먼저 찾아 바로** 보여 주고(장비 접속 없음), 이어서 장비 Reports 폴더에서 캐시에 없는 새 Batch Report를 더합니다.
- **[캐시에서만 찾기]** 를 켜면 장비에 접속하지 않고 캐시에서만 찾습니다.
- 고른 Batch Report와 그 이어서 스캔이 모두 캐시에 있으면 읽을 때도 장비에 접속하지 않습니다.

## 이어서 스캔 찾는 범위 — 앞뒤 24시간
- 고른 Batch Report와 같은 호기에서 **앞뒤 24시간**(종전 13시간) 안에 스캔한 Batch Report까지 함께 읽어, 키워드에 안 걸린 이어서 스캔도 놓치지 않게 했습니다.
