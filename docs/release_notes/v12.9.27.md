# Camtek AOI Manager v12.9.27

**Color · Gray 매칭에서 네트워크 드라이브의 Wafer 폴더를 찾지 못하던 문제를 고쳤습니다.**

## Color · Gray 매칭 › 폴더 선택
- 세 파일(`ColorImageGrabingInfo.ini` · `ScanResultImageList.txt` · `frameToChuckPlane.*.ini`)이 있는데도 "Wafer 폴더를 찾지 못했습니다"가 나오던 문제를 고쳤습니다.
  - 파일을 하나씩 전체 경로로 묻지 않고 폴더 목록을 한 번 읽어 확인합니다.
  - 경로가 긴 네트워크 드라이브 · `\\서버\공유` 폴더(260자 안팎)도 Windows 확장 경로로 읽습니다.
  - 파일 이름의 대문자 · 소문자가 달라도(NAS) 같은 파일로 봅니다.
  - 네트워크 드라이브의 링크 폴더(DFS 등)도 하위 폴더로 따라 들어갑니다.
- 그래도 찾지 못하면 고른 폴더 바로 아래의 파일 수 · 폴더 수 · 없는 파일 이름 · 경로 길이를 함께 알려 줍니다.
