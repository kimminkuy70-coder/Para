# Camtek AOI Manager v12.3.12

**긴 레시피 이름이 값 확인 목록에서 잘리거나 중복으로 보이던 문제를 고쳤고, 양식 확정이 끝나면 결과 창이 뜹니다.**

## 장비 파라미터 비교(값 확인) — 레시피 목록
- 31자를 넘는 레시피 이름(예: `2D@R2-S6WC61001-00001_0851889PD-0D`)이 잘린 이름 · 중복(`…PD`, `…PD1`)으로 보이던 문제를 고쳤습니다. 이제 레시피 선택 목록이 레시피 삭제 목록과 같은 **원래 이름**으로 나옵니다.
- 같은 양식을 다시 확정하거나 값을 이어받을 때 잘린 이름의 시트가 다른 레시피처럼 쌓이던 문제도 고쳤습니다.
- 이미 중복으로 쌓인 취합 파일도 원래 이름 하나로 보이며, 다음 Recipe 업데이트 · 양식 확정 때 정리되어 저장됩니다.

## 신규 Recipe 만들기 · Recipe 양식 편집하기 — 확정 결과 창
- [양식 확정]이 끝나면 **'✅ 양식 확정 완료' 창**이 떠서 저장된 확정 양식 · 편집용 원본 · 변환계수 · 값 이어받기 결과를 바로 보여 줍니다.
- 확정한 뒤에는 버튼이 [✅ 확정 완료 · 결과 보기]로 바뀌어 같은 양식을 실수로 두 번 확정하지 않습니다. 고쳐서 다시 확정하려면 항목 편집 단계로 돌아가면 됩니다.
