# Camtek AOI Manager v12.9.32

**v12.9.30 · v12.9.31 zip 이 Windows Defender(`Trojan:Win32/Wacatac.B!ml`)에 막히던 문제를 다시 고쳤습니다. 기능은 v12.9.30 과 같습니다.**

## 설치 파일 › Windows Defender 차단
- v12.9.29 는 받아지고 v12.9.30 · v12.9.31 은 막혔습니다. `!ml` 은 Defender 의 머신러닝 추정 판정입니다.
- 비교 결과: 엔진 파일은 원인이 아니었습니다(v12.9.31 에서 바꿨지만 그대로 막힘). 앱 실행 파일(`Camtek_AOI_manager.exe`)은 안에 압축해 넣은 화면 자료만 v12.9.29 와 달랐습니다.
- 수정: 앱 실행 파일에 화면 자료를 압축하지 않고 넣습니다. 실행 파일 안의 그 부분이 압축 덩어리 대신 일반 글(화면 코드)이 됩니다.
- 프로그램 기능 · 설정 · 저장 자료는 바뀌지 않았습니다(v12.9.30 의 자동 분석 예약 시각 수정, Color · Gray 좌표 기준 포함).
- 그래도 막히면 Defender 보호 기록의 '영향을 받는 항목' 경로를 알려 주십시오.
