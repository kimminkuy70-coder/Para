# Camtek AOI Manager v12.9.32

**Windows Defender 가 v12.9.30 · v12.9.31 zip 을 `Trojan:Script/Wacatac.F!ml` 로 막던 문제를 고쳤습니다. 기능은 v12.9.31 과 같습니다.**

## 설치 파일 › Windows Defender 차단 (#58)
- v12.9.31 zip 을 받으면 Windows Defender 가 `Trojan:Script/Wacatac.F!ml`(스크립트 판정)로 막았습니다.
- 원인(가장 유력): zip 안 엔진 폴더의 `updater.pyc` 에 예전 프로그램(tkinter 판)의 업데이트용 배치 파일 문구가 글자로 들어 있었습니다. 대기 · 실행 · 자기 삭제를 하는 문구라, v12.7.16 때 같은 이름으로 막힌 배치 파일과 모양이 같습니다. 새 프로그램은 이 문구를 쓰지 않습니다.
- 수정: 그 문구를 예전 프로그램 전용 파일로 옮겨 이번 zip 에 들어가지 않게 했습니다. 엔진 설명문에 있던 같은 문구도 지웠습니다. 다시 들어오면 시험(`tests/test_sidecar_no_scripts.py`)이 실패합니다.
- 프로그램 기능 · 설정 · 저장 자료는 바뀌지 않았습니다.
- 그래도 막히면 Defender 보호 기록의 '영향을 받는 항목'(zip 안 파일 경로)을 알려 주십시오. Microsoft 오탐 신고(https://www.microsoft.com/wdsi/filesubmission)도 함께 권장합니다.
