## Camtek AOI Manager v13.0.1 — 더블클릭으로 시작(.bat) · 업데이트는 다음 실행 때 적용

### 처음 실행이 쉬워졌습니다 (#64)

- 설치 zip 에 **`Camtek_AOI_manager.bat`** 이 들어 있습니다. 푼 폴더에서 이 파일을 더블클릭하면 프로그램이 시작됩니다. Win + R 에 명령을 붙여 넣지 않아도 됩니다.
- 이 파일이 하는 일은 한 가지입니다: 같은 폴더의 `python\pythonw.exe`(python.org 서명)로 `Camtek_AOI_manager.pyw` 를 실행합니다. 회사에서 쓰는 다른 AOI 프로그램과 같은 방식입니다.
- 첫 실행 뒤에는 바탕화면 바로가기가 생깁니다. 바로가기나 .bat 으로 실행하십시오.
- 권장 위치는 `%LOCALAPPDATA%\CamtekAOI\app` 입니다. OneDrive 밖의 다른 로컬 폴더에 풀어도 동작합니다(OneDrive · Program Files · 네트워크 드라이브 · Downloads 는 피하십시오).

### 업데이트 적용 방식

- [지금 업데이트]를 누르면 새 버전을 받아 확인한 뒤 "프로그램을 종료하고 다시 실행하십시오" 창이 뜹니다. 다시 실행할 때 새 버전이 적용됩니다(프로그램이 스스로 재시작하지 않습니다).

### 처음 설치

1. 아래 `Camtek_AOI_manager_v13.0.1_install.zip` 을 받으십시오.
2. `%LOCALAPPDATA%\CamtekAOI\app` 폴더를 만들고 그 안에 푸십시오.
3. `Camtek_AOI_manager.bat` 을 더블클릭하십시오.

v13.0.0 을 이미 설치했다면 프로그램의 업데이트 알림으로 v13.0.1 을 받으면 됩니다. 이 경우 .bat 파일은 생기지 않으므로(업데이트는 프로그램 파일만 바꿉니다) 바탕화면 바로가기로 실행하십시오.
