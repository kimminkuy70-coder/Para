# Camtek AOI Manager v12.0.1

**WPH · 생산능력** 그래프를 읽기 쉽게 고치고, **저장된 결과 파일**을 v12.0.0 앱 화면과 같은 계산으로 다시 만들었습니다.
기준은 프로그램입니다 — 파일의 숫자는 앱의 `Batch Report 분석` 화면과 같은 엔진 · 같은 식으로 나옵니다.

## WPH · 생산능력
- **같은 호기는 같은 색**: 레시피 비교 막대에서 호기 색이 레시피마다 바뀌던 것을 호기마다 고정했습니다(호기 이름 순서로 색을 정함).
  아래에 호기 색 범례를 넣었고, 호기 × 레시피 표의 호기 칸에도 같은 색을 표시합니다.
- **레시피를 고르면 바뀐 것이 보이게**: 같은 Job 안에서 하위 레시피를 바꾸면 비교하는 레시피 묶음이 같아 막대가 그대로라 헷갈렸습니다.
  이제 고른 레시피 줄을 강조하고, 막대 위에 `고른 레시피: … — 정상 WPH 27.5` 또는 `정상 WPH 없음` 을 적습니다.
- 레시피마다 정상 WPH 값을 함께 보여 주고, **정상 WPH가 없는 레시피**(정상 25매 Batch Report 없음)는 `정상 WPH 없음`,
  실제 WPH 자료가 없는 레시피도 `실제 WPH 자료 없음` 행으로 남깁니다(종전에는 행이 사라졌습니다).

## 저장된 결과 파일 (Lot 추적 HTML · Excel · HTML · 가동률 대시보드)
- **분석 HTML**: 탭 4개 — Lot 추적(지표 5개 · 멈춘 이유 요약 Error / 작업자 중단 · Defect 과다 기준값), 가동률(숫자 4개 · 호기별 / 기간별
  일 · 주 · 월 시간 3칸 막대 · 시간 구성 상세 · 손실 이유 · 레시피별 웨이퍼 처리), WPH · 생산능력(정상 / 실제 WPH · 처리량 감소 ·
  레시피별 하루 생산능력 · 호기 × 레시피 표 + 합계 줄), 지표 정의(앱 ? 설명과 같은 정의).
- **가동률 대시보드**: 가동률 · WPH · 생산능력 탭(30분 자동 새로고침).
- **Excel**: 조사 정보 · 정의 / 가동률(호기별 · 일 · 주 · 월 · 날짜 × 호기) / 손실 이유 / WPH 호기 × 레시피 / 정상 25매 Batch Report /
  작업자 중단 / Lot 목록 / Batch Report 목록.
- **Lot 추적 HTML**: 앱과 같은 Lot 판정(저장한 중복 Pass 선택 반영), 앱과 같은 지표 · 멈춘 이유 요약, 작업자 중단 칸 표시, 3D 스캔 표시,
  화면 용어(공정 단계 · Batch Report · Lot History)로 통일.
- 기존의 옛 지표(M01~M11) 결과 파일은 더 이상 만들지 않습니다.

## 알아 둘 것
- 저장 파일은 조사 범위 전체(처음 ~ 마지막 Batch Report 날짜, 조사한 모든 호기) 기준입니다. 앱에서 기간 · 호기를 좁히면 그 범위의 숫자가 나옵니다.
- WPH 통합 엑셀 / HTML(`WPH_통합`)과 호기별 취합 텍스트는 이번에 바꾸지 않았습니다.
