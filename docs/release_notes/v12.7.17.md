# Camtek AOI Manager v12.7.17

**Windows Defender가 `Trojan:Script/Wacatac.F!ml`로 막던 문제를 고쳤습니다. 프로그램 안 자동 업데이트가 더 이상 배치 스크립트(.bat)를 만들어 실행하지 않습니다.**

## 원인
- 실제 악성 코드가 아니라 Defender 클라우드 ML(`!ml`)의 **오탐**입니다. v12.5.16과 비교해 배포 파일에 새로 들어간 스크립트 파일은 없습니다.
- 자동 업데이트가 Temp 폴더에 숨김 배치 스크립트(`web_update.bat`)를 만들어 실행했는데, 대기(`ping`) · 폴더 삭제 · 프로그램 실행 · **스스로 지우기**까지 하는 모양이 악성 스크립트와 비슷해 `Trojan:Script`로 판정될 수 있었습니다.

## 자동 업데이트 바꿈
- 업데이트 교체를 **스크립트 대신 새 버전 엔진 프로그램이 직접** 합니다. .bat / .cmd / .ps1 파일을 만들지 않습니다.
- 교체 방식(프로그램 종료 확인 → 새 폴더로 교체 → 이전 버전 1개 보관 → 다시 실행, 실패하면 이전 폴더로 되돌림)은 그대로입니다.
- 이 변경은 **v12.7.17이 설치된 뒤의 다음 업데이트부터** 적용됩니다. v12.7.16 이하에서 v12.7.17로 올릴 때는 zip을 직접 받아 폴더째 바꾸는 방법(직접 설치)을 권장합니다.

## 실행 파일 속성
- exe 파일 속성(자세히)에 회사 · 파일 설명 · 저작권 칸을 채웠습니다. 출처 정보가 비어 있는 서명 없는 exe를 보안 프로그램이 더 의심하는 경우를 줄이기 위함입니다.
