# Camtek AOI Manager v12.9.30

**자동 분석(Batch Report · KLA)이 예약 시각에 돕니다. Color · Gray 매칭이 wafer map 좌표 기준(좌측 하단 = 0,0)을 따릅니다.**

## 자동 분석 및 취합 › Batch Report 자동 분석 (CAMTEK · KLA)
- 예약 시각이 되어도 자동 분석이 돌지 않던 문제를 고쳤습니다.
- 원인 1: 자동 분석은 Batch Report 분석 화면 안에서 돌았습니다. 앱을 켠 뒤 그 탭을 한 번도 열지 않으면 자동 분석이 시작되지 않았습니다. 이제 자동 분석이 켜져 있으면 앱을 켤 때(또는 자동 분석을 켤 때) 그 화면을 숨긴 채로 준비합니다.
- 원인 2: 자동 분석이 한 번 실패하면 앱을 다시 켜기 전까지 자동 분석이 멈췄습니다. 이제 30분 뒤 다시 확인하고, 하루 단위 주기는 다음 예약 시각에 다시 돕니다.
- 원인 3: Batch Report 자동 분석만 켠 경우 창을 닫으면 앱이 종료되었습니다. 이제 창을 닫아도 트레이에 남아 예약 시각에 돕니다. 트레이 아이콘의 안내에 `Batch Report ✓` 가 보입니다.
- 앱을 완전히 종료하면(트레이 메뉴의 종료) 자동 분석도 돌지 않습니다.

## Color · Gray 매칭 › 좌표 기준
- Fault 좌표의 기준은 wafer map 직사각형의 좌측 하단 (0,0)입니다. 이 직사각형은 wafer map을 꽉 채우는 가상의 직사각형입니다.
- 먼저 Fault 좌표를 그대로 맞춥니다. 맞지 않는 사진이 있으면 Gray 프레임이 덮는 직사각형의 좌측 하단을 (0,0)으로 놓고 다시 맞춥니다. Y 방향이 반대인 경우도 시험합니다.
- 가장 많은 사진이 맞는 기준을 씁니다. 기준을 바꾸었으면 진행 기록에 그 기준을 보입니다.
- 매칭 실패 진단 줄에도 사용한 좌표 기준을 보입니다.
