# Camtek AOI Manager v12.8.17

**맨 위 탭이 CAMTEK · KLA · 설정 · 메모 4개로 바뀌었습니다. KLA 장비 폴더는 [설정]에서 등록하고, KLA도 백업본을 함께 찾을 수 있습니다.**

## 맨 위 탭 = CAMTEK · KLA · 설정 · 메모
- CAMTEK 탭 안에 있던 **설정**과 **메모**를 밖으로 빼서, 맨 위 탭이 **CAMTEK · KLA · 설정 · 메모**가 되었습니다.
- CAMTEK 탭에는 Recipe 관리 · 자동 감시 · Commonality 조사 · Batch Report 분석 · Color·Gray 매칭 · Wafer Map 수정하기가 있습니다.
- KLA 탭에는 KLA 자재 찾기가 있습니다. CAMTEK · KLA 탭을 오가도 각 탭에서 마지막에 보던 화면으로 돌아갑니다.

## 설정 › AOI 장비 호기 루트 = CAMTEK / KLA
- [AOI 장비 호기 루트] 안에 **CAMTEK** · **KLA** 탭이 생겼습니다.
  - **CAMTEK**: 지금까지와 같습니다(호기 루트 · 호기별 추가 폴더 · Scanresult 백업본 포함).
  - **KLA**: KLA 장비 폴더(예: `J:\2.K2`, 또는 상위 폴더 `J:\`)를 여기서 등록합니다. 이전 버전에서 등록한 폴더는 그대로 있습니다.
- KLA 자재 찾기 화면에는 등록된 장비 요약과 **[⚙ 설정 › AOI 장비 호기 루트 › KLA]** 버튼이 있습니다.
- [현재 설정] 표에 KLA 장비 폴더 줄이 추가되었습니다.

## KLA Defect 이미지 백업본 (새 기능)
- CAMTEK의 **Scanresult 백업본 포함**과 같은 기능을 KLA에도 만들었습니다. KLA는 Scanresult 폴더 없이 장비 폴더 아래 **날짜 폴더**에 Defect 이미지와 결과 파일을 저장하므로, 이름을 **Defect 이미지 백업본**으로 정했습니다.
- 설정 › AOI 장비 호기 루트 › KLA에서 장비마다 **백업 폴더**(날짜 폴더를 옮겨 둔 보관 폴더, 장비당 최대 20개)를 등록합니다.
- **[백업본 포함]** 스위치(기본 켬)를 켜면 KLA 자재 찾기가 원본 장비 폴더와 백업 폴더를 함께 찾고, 백업 폴더에서 찾은 Lot에는 **백업본** 표시를 붙입니다. 끄면 원본 장비 폴더만 찾습니다.
- 스위치는 설정과 KLA 자재 찾기 화면 둘 다에 있고, 한쪽에서 바꾸면 다른 쪽도 같이 바뀝니다.
- 백업 폴더도 폴더 이름만 보고 찾습니다. 파일은 열지 않고, 아무것도 바꾸지 않습니다.
