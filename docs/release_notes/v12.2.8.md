# Camtek AOI Manager v12.2.8

**지금까지 조사해 모은 Batch Report 데이터를 zip 파일 하나로 내보내는 기능**을 추가했습니다.

## Batch Report 캐시 내보내기
- Batch Report 분석 › 가동률 조사 및 분석 › 조사 범위 패널 아래 **[Batch Report 캐시 내보내기 (zip)]** 버튼을 누르면, 로컬 캐시에 모인 **모든 호기의 Batch Report 데이터**를 zip 파일 하나로 만듭니다.
- 저장 위치: 로컬 작업 폴더의 `배치분석\내보내기\BatchReport_캐시_날짜_시각.zip` (최근 3개만 보관).
- 끝나면 파일 경로 · 호기 수 · Batch Report 수 · 파일 크기가 표시되고, **[폴더 열기]**로 탐색기에서 zip 파일을 바로 찾을 수 있습니다.
- 장비에는 접속하지 않습니다(이미 조사한 로컬 캐시만 사용). 캐시가 없으면 먼저 [조사 시작]을 하라고 안내합니다.

## 기타
- 설정 › 정보의 **진단 로그 zip [폴더에서 보기]**도 이제 탐색기에서 파일을 선택해 보여 줍니다.

## 참고
- 그 밖의 기능 · 계산은 v12.2.7 과 같습니다.
