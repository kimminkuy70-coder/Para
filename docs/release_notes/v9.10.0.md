# Camtek AOI Manager v9.10.0

## 자동 감시 — 파라미터 자동 감시
- 감시 탭(파라미터 / Commonality)을 고르면 위쪽 메인 탭처럼 **초록색으로 표시**됩니다.
- **장비 연결 확인 단계 추가**: 호기마다 탐색기 주소(`\\IP\c$`)를 **📋 주소 복사** → `Win + R` → 붙여넣기 → 로그인하는 방법을 안내하고, **[선택 호기 연결 확인]**으로 연결 여부(✓/✗)를 바로 확인합니다.
- **장비에서 폴더 고르기**: 폴더 목록이 버튼 **바로 아래**에 열리고, **레시피 여러 개**를 골라 차례로(또는 한 번에) 지정할 수 있습니다.
- 표 열 이름을 **'실제 Job 폴더 레시피(\Job\ 아래)'**로 변경 — 장비에서 실제로 읽어 온 폴더 이름이 그대로 표시됩니다.
- **다른 호기에 같은 레시피 폴더 적용**: 기능 설명을 추가하고, 호기마다 Job 이름이 조금씩 달라도 **각 장비의 실제 폴더를 찾아** 지정합니다(같음/비슷한 이름 1개 → 지정, 여러 개·없음·미연결 → 결과표로 안내).
- 현황 표를 테두리·배경색으로 구분하고 '장비 연결' 행을 추가했습니다.

## 자동 감시 — Commonality 자동 감시
- 호기·레시피를 고르면 **선택된 항목이 실시간으로** 표시됩니다.
- 디바이스명·공정번호 옆 **? 버튼**으로 폴더 구조(레시피 제목 = 디바이스명, 그 바로 아래 폴더 = 공정번호)를 설명합니다.
- 대표 S/M 선택 목록을 **한 줄 표**로 정리했습니다(S/M · 생성 · 스캔 · 슬롯).
- 양식 지정을 다시 열면 **S/M 찾기가 끝날 때까지 이전 목록을 고를 수 없게** 했습니다.
- 하위 레시피가 여러 개면 **조사할 하위 레시피를 고르는 단계**가 추가됐습니다.
