# Camtek AOI Manager v12.9.23

**KLA 자재 찾기에 캐시를 추가했습니다. 장비에 연결하지 않은 PC 도 OneDrive 에서 KLA 캐시를 불러와 자재를 찾을 수 있습니다.**

## KLA 캐시 갱신 · OneDrive 게시 (개발자)
- KLA › KLA 자재 찾기 › [🛠 개발자 기능] › [캐시 갱신 (장비 폴더 이름 읽기)]를 누르면, 등록한 KLA 장비 폴더의 날짜 · Lot · 슬롯 폴더 이름을 이 PC 의 캐시에 모읍니다. 파일은 열지 않고, 장비에는 쓰지 않습니다.
- 두 번째 갱신부터는 최근 3일 날짜 폴더와 바뀐 날짜 폴더만 다시 읽습니다. 읽지 못한 장비는 예전 캐시를 그대로 둡니다.
- [OneDrive 에 게시]를 누르면 캐시를 zip 1개로 만들어 Camtek Batch Report 캐시와 같은 `캐시공유` 폴더에 올립니다.
- 이름으로 구분합니다: KLA = `KLA_캐시_YYYYMMDD_HHMMSS.zip` + `KLA캐시정보.json`, Camtek = `BatchReport_캐시_YYYYMMDD_HHMMSS.zip` + `캐시정보.json`. 서로의 파일은 건드리지 않습니다. 최근 3개만 남깁니다.

## KLA 캐시 불러오기 · 캐시에서 찾기 (사용자)
- KLA 자재 찾기 › [OneDrive 에서 불러오기]를 누르고 목록에서 캐시를 고른 뒤 [고른 캐시 받아서 불러오기]를 누르십시오.
- 찾을 곳을 [KLA 캐시]로 고르고 [캐시에서 찾기]를 누르면, 장비에 연결하지 않고 캐시에서 Lot 폴더를 찾습니다. 결과에 캐시 갱신 시각을 표시합니다. 그 뒤에 스캔한 자재는 캐시에 없을 수 있습니다.
- 장비 폴더를 등록하지 않은 PC 는 캐시를 불러오면 찾을 곳이 자동으로 [KLA 캐시]가 됩니다.
- 받은 zip 은 크기와 SHA-256 이 게시할 때와 같을 때만 불러옵니다. OneDrive 에는 아무것도 쓰지 않습니다.

## 보안
- KLA 캐시 zip 안에는 폴더 이름 목록(JSON)만 있습니다. 새 프로그램 실행 · 스크립트 · 인터넷 접속은 없습니다.
