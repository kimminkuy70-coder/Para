# Camtek AOI Manager v12.8.19

**설정 › AOI 장비 호기 루트에서 호기를 등록할 때, 메모 › 장비 IP 에 적어 둔 호기를 목록에서 골라 이름을 채울 수 있습니다.**

## 메모(장비 IP)에서 호기 고르기
- 설정 › AOI 장비 호기 루트 › **CAMTEK** · **KLA** 등록 줄 맨 앞에 **메모(장비 IP)에서 고르기** 목록이 생겼습니다. 고르면 호기(장비) 이름 칸이 채워지고, 호기 폴더는 지금처럼 직접 지정한 뒤 [추가]를 누릅니다.
- CAMTEK 탭에는 장비종류가 Camtek 인 호기, KLA 탭에는 KLA 인 호기가 먼저 나오고, 장비종류를 비워 둔 호기는 양쪽에 모두 나옵니다. 이미 등록한 호기는 목록에서 빠집니다.
- 메모 › 장비 IP 를 고치면 설정 화면을 다시 열 때 목록에 반영됩니다. 이름을 직접 타이핑하는 방법도 그대로 쓸 수 있습니다.
