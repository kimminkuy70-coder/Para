## Camtek AOI Manager v14.1.5 — Defect 분석 보기 켜고 끄기 · 분류 이름 · 필터 정리

- 사진 새 창(크게 보기)에서 흑백 사진의 Defect 빨간 네모를 켜고 끌 수 있습니다.
- 5-3 흑백 GL 측정을 테두리 박스로 묶고, 측정 원을 켜고 끌 수 있습니다.
- '첫번째 분류'는 '장비 스캔 분류', '재분류'는 '리뷰 결과'로 이름을 바꿨습니다.
- 5-1 필터를 항목마다 한 줄씩(제목 · 내용) 정리했습니다.

### 자세히

- 빨간 네모: 새 창 위 [🟥 빨간 네모] 체크 또는 B 키. Gray Crop · Gray 프레임의 빨간 네모만 빠지고(노란 Crop 상자 · 측정 원은 그대로), 확대 · 보는 곳은 그대로입니다. 이 PC 에 기억합니다. 5-3 칸 · 격자 · 최종 목록 엑셀 사진에는 늘 빨간 네모가 있습니다.
- 측정 원: 5-3 [흑백 GL (원) 측정] 박스의 [⭕ 측정 원 보기]. 끄면 5-3 사진 · 격자 · 새 창 · 최종 목록 엑셀 사진에서 하늘색 점선 원이 빠집니다. GL 값과 측정은 바뀌지 않습니다. 이 PC 에 기억합니다.
- 이름: 목록 열 · 정보 칸 · 필터 · 목록/결과 CSV(`장비스캔분류` · `리뷰결과`) · 최종 목록 CSV · 엑셀 열이 모두 새 이름입니다. Color·Gray 매칭의 [최종 목록 CSV 고르기]는 예전 판이 저장한 CSV(옛 열 이름)도 그대로 읽습니다.
- 필터: Lot · Slot / Lot 제외 / 장비 스캔 분류 / 리뷰 결과 / 값 범위(Contrast · Area · Width · Length 한 줄) / Recipe / 정렬이 줄마다 나뉩니다. 분류 · Lot 칸은 같은 너비로 줄을 맞추고 개수는 오른쪽에 보입니다.

### 업데이트

- v14.1.1 이후 판에서는 프로그램 시작 때 뜨는 업데이트 알림으로 받으십시오.
- v13 판에서는 v13.0.3 을 거쳐 업데이트 알림으로 받거나, 아래 설치 zip 을 같은 폴더에 풀어 덮어쓰십시오.

### 처음 설치

1. 아래 `Camtek_AOI_manager_v14.1.5_install.zip` 을 받으십시오.
2. 프로그램을 종료하십시오(알림 영역 아이콘이 있으면 [종료]).
3. `%LOCALAPPDATA%\CamtekAOI\app` 폴더에 zip 을 풀어 덮어쓰십시오(처음이면 폴더를 만들고 그 안에).
4. `Camtek_AOI_manager.bat` 을 더블클릭하거나 바탕화면 바로가기로 실행하십시오.
