# Camtek AOI Manager v12.5.13

**Batch Report 찾기 · 취합 결과에 Lot별 Yield 탭이 생겼습니다.**

## Batch Report 찾기 · 취합 — Lot별 Yield 탭
- 취합 결과(4/4) 위에 탭 **[Lot 취합 · wafer] / [Lot별 Yield]** 가 있습니다.
- **Lot별 Yield** 탭은 Lot · 레시피마다 **Yield · 스캔된 Defect 수(Faults) · Good Die · Reject Die** 를 한 줄로 보여 줍니다(Pass wafer 기준, Yield = Good ÷ Scanned).
- **레시피 버튼**으로 원하는 레시피만 고르고(여러 개 가능, 안 고르면 전체), **키워드 검색**(Lot · 레시피 · 호기)으로 줄을 거를 수 있습니다.
- Lot을 체크하면 표 아래에 **선택 합계**와 **선택 Lot 평균**이 나옵니다. 맨 위 체크 칸으로 **보이는 Lot 전체 선택**이 됩니다.
- 같은 wafer를 여러 번 스캔했으면 종전 전제대로 **하나로 합칩니다**(최신 스캔 — Pass가 있으면 가장 나중 Pass).

## 같은 Lot이라도 레시피별로 따로 취합
- 같은 Lot 이름이라도 **레시피(상위 레시피 Job)가 다르면 따로** 취합합니다. 예를 들어 PI · RDL 을 이어서 스캔해도 Yield 가 레시피마다 따로 나옵니다.
- Lot 취합 표 · wafer 제목 · Excel 의 공정 단계 칸에 `레시피(Job) · Recipe(s)` 가 표시됩니다.
