# Camtek AOI Manager v12.5.15

**Batch Report 찾기 · 취합의 Yield · Good Die가 최종 선정된 wafer로만 계산되고, 태그별로 Lot을 나눠 볼 수 있습니다.**

## 취합 계산 — 최종 선정 wafer만
- 같은 Lot · 레시피를 며칠 뒤나 다른 호기에서 다시 스캔해도 **한 Lot으로 모아** wafer마다 최종 선정(가장 나중 Pass) 하나만 계산합니다. 정상이면 Lot 하나 = wafer 25장입니다.
- 그동안 다시 스캔한 Batch Report가 따로 취합되어 같은 wafer가 두 번 들어가던 문제를 고쳐, **Lot별 Yield · Good/Reject Die · Defect · 선택 합계/평균**이 더 이상 부풀지 않습니다.
- Lot 이름 옆 기간은 첫 스캔 날 ~ 마지막 스캔 날로 표시되고, Excel 저장의 기간 · 호기 열도 같은 기준입니다.

## 태그별 보기
- **Lot · Batch Report 고르기(3/4)**: `한 번에 완료` · `재스캔으로 완료` · `Pass하지 못한 wafer 존재` 태그 칩으로 그 태그의 Lot만 볼 수 있습니다(여러 개 선택 가능, `태그 전체`로 되돌림).
- **취합 결과(4/4)**: Lot 취합 표 · wafer 표 · Lot별 Yield 탭에 **태그 칸**이 생기고, 같은 태그 칩으로 걸러 볼 수 있습니다. 결과의 태그는 이번 취합의 최종 선정 wafer 기준입니다.
