# Camtek AOI Manager v12.9.33

**설치 zip 을 올리기 전에 Windows Defender 로 검사합니다. 기능은 v12.9.30 과 같습니다.**

## 설치 파일 › Windows Defender 차단 조사 결과
- v12.9.29 · 30 · 31 · 32 zip 을 최신 정의의 Windows Defender 로 직접 검사했습니다(실시간 보호 · 클라우드 보호 켬, 브라우저 다운로드 검사 경로 포함, 클라우드 차단 수준 기본 · 높음 · 매우 높음 · 무관용).
- 결과: 네 버전 모두 '위협 없음'입니다. zip 안의 파일 619개 어디에도 감지되는 것이 없습니다.
- 따라서 파일 내용이 원인이 아닙니다. 차단은 받는 PC 쪽 판정(그 PC 의 Defender 정의 버전, 회사 보안 정책, 새 파일에 대한 클라우드 평판 판정)에서 나옵니다. v12.9.31 · v12.9.32 에서 파일을 바꿔도 그대로였던 이유입니다.

## 이번 버전에서 바뀐 것
- 릴리스 빌드가 올릴 zip 을 Windows Defender 로 검사하고, 감지되면 릴리스를 멈춥니다. 검사 결과는 빌드 기록에 남습니다.
- 프로그램 기능 · 설정 · 저장 자료는 바뀌지 않았습니다.

## 그래도 막히면
- Windows 보안 › 바이러스 및 위협 방지 › '보호 업데이트 확인'으로 정의를 최신으로 올린 뒤 다시 받아 보십시오.
- 회사 노트북이면 회사 보안 정책이 새 실행 파일을 막는 것일 수 있습니다. IT 담당에게 이 zip 의 허용을 요청하십시오.
- Microsoft 오탐 신고: https://www.microsoft.com/wdsi/filesubmission 에 zip 을 올리면 판정이 풀립니다.
