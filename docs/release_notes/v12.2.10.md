# Camtek AOI Manager v12.2.10

**Batch Report 찾기에서 Scanresult 폴더를 바로 열 수 있게** 했고, **초기 설정 튜토리얼에 장비 1회 로그인 단계**를 추가했습니다.

## Batch Report 찾기 · 취합 — Scanresult 폴더 열기
- 2단계(Batch Report 고르기)의 **Scanresult 경로** 옆에 **[폴더 열기]** 버튼이 생겼습니다. 누르면 그 Scanresult 폴더가 탐색기로 바로 열립니다(경로 복사는 그대로).
- 등록한 호기 폴더 아래 `Scanresult*` 폴더와 설정에서 추가한 Scanresult 보관 폴더 안의 폴더만 열 수 있습니다. 장비 폴더는 읽기만 합니다.

## 초기 설정 튜토리얼 — 장비마다 IP 폴더에 1회 로그인
- '② 장비 연결' 다음에 **"먼저 장비마다 IP 폴더에 1회 로그인 (가장 중요)"** 단계를 넣었습니다: [메모] › 장비 IP 에서 IP 확인 → 탐색기 주소창(또는 Win+R)에 `\\장비IP` → 아이디 · 암호 입력 + [내 자격 증명 기억] → 모든 호기 1회씩.
- 이 연결이 있어야 쓸 수 있는 기능(Recipe 관리 · 자동 감시 · Commonality 조사 · Batch Report 분석 · 찾기 · Color·Gray 매칭)을 함께 안내합니다.
- 튜토리얼 첫 화면에 **저장 폴더**와 **장비 연결**을 가장 중요한 단계로 표시했습니다.

## 참고
- Batch Report 찾기를 더 빠르게 하는 방법은 이슈 #18 에 제안으로 정리했습니다(이번 버전에는 적용하지 않음).
