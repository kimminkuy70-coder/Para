# Camtek AOI Manager v9.10.2

## 시작 속도 개선 (첫 실행 5~10분 → 대폭 단축 예상)
- **원인**: 진단 로그 분석 결과, 설정 읽기 자체는 0.01초였고 **엔진 모듈 로딩이 5~10분** 걸렸습니다.
  엔진이 모듈을 실행파일(exe) 안에 묶어 두고 **모듈을 읽을 때마다 exe 를 다시 열었는데**,
  보안 프로그램이 서명 없는 exe 를 열 때마다 검사해 모듈 하나에 1~10초씩 걸렸습니다
  (검사 기록이 남아 있을 때만 빨랐고, 업데이트 직후·백신 정의 갱신 후에는 매번 느림).
- **수정**: 모듈을 exe 밖의 개별 파일(`sidecar\_internal\*.pyc`)로 두도록 빌드 방식을 바꿨습니다.
  exe 는 시작할 때 한 번만 열립니다.
- **시작 중 진행 표시**: 엔진이 준비되는 동안 진행 상황 창에 `엔진 준비 중 — 모듈 N개 불러옴 · T초 경과`가 표시됩니다
  (예전에는 '기존 설정 읽기 N초'만 보였습니다).
- **진단 로그 보완**: '프로세스 생성 → Python 시작' 시간이 '측정 불가'로 나오던 문제를 고쳤습니다.
