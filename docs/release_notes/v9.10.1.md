# Camtek AOI Manager v9.10.1

## 진단 로그 (느림 원인 찾기)
- 프로그램 시작·**기존 설정 읽기** 시간이 PC마다·실행마다 들쭉날쭉한 원인을 찾기 위해 **상세 진단 로그**를 자동으로 남깁니다
  (로컬 작업 폴더 `Logs/상세_진단_로그.txt`, OneDrive 아님 · 5MB 넘으면 회전).
- 기록 항목: 실행파일 풀기·백신 검사(프로세스 생성 → Python 시작) · 느린 모듈 로딩(30ms 이상) · 설정 파일/로컬 폴더 확인 시간 ·
  화면 요청을 받은 시각·대기·처리 시간·단계 · 화면 쪽 타임라인(화면 로딩, 엔진 연결, 요청 보냄/응답) · 부팅 후 경과시간·메모리.
  파일 내용·비밀번호는 기록하지 않습니다.
- **[설정 › 정보 › 진단 로그 묶기 (zip)]** 버튼으로 로그 전체를 zip 하나로 만들어 전달할 수 있습니다.
