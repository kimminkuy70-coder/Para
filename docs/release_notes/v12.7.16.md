# Camtek AOI Manager v12.7.16

**맨 위에 CAMTEK / KLA 탭이 생겼습니다. KLA 탭의 [KLA 자재 찾기]에서 Lot 이름만 넣으면 KLA 장비에서 스캔한 폴더를 빠르게 찾아 바로 열 수 있습니다.**

## CAMTEK / KLA 탭
- 기능 탭 위에 **CAMTEK** · **KLA** 탭이 생겼습니다.
- 지금까지 쓰던 기능(설정 · Recipe 관리 · 자동 감시 · Commonality 조사 · Batch Report 분석 · Color·Gray 매칭 · Wafer Map 수정하기 · 메모)은 모두 **CAMTEK** 탭에 있습니다.
- **KLA** 탭에는 KLA 장비용 기능이 들어갑니다. 탭을 오가도 각 탭에서 마지막에 보던 화면으로 돌아갑니다.

## KLA 자재 찾기 (새 기능)
- 처음 한 번 **[KLA 장비 폴더]**에 장비 폴더를 등록합니다(예: `J:\2.K2`). 장비 폴더들을 담은 상위 폴더(예: `J:\`)를 등록하면 그 아래 장비 폴더를 모두 찾습니다.
- **Lot 키워드**를 넣고 [찾기]를 누르면 `장비\날짜\Lot\스캔 시각_슬롯` 폴더 중 Lot 이름이 맞는 것만 목록으로 보여 줍니다.
  - 여러 단어를 넣으면 모두 들어 있는 Lot만 찾습니다(대소문자 무시).
  - 기간 · 찾을 장비를 고를 수 있고, 기간을 좁힐수록 빨라집니다.
- 결과 표: 장비 · 날짜 · Lot · 슬롯 번호 · 경로. **[폴더 열기]**로 바로 열고 **[경로 복사]**로 경로를 복사합니다. 행을 누르면 슬롯 폴더(스캔 시각 · 슬롯)가 펼쳐집니다.
- 폴더 이름만 보고 찾습니다. 장비 폴더의 파일은 열지 않고, 아무것도 바꾸지 않습니다.

## Batch Report 캐시 공유 (v12.6.16 내용 포함)
- v12.6.16은 빌드 오류로 배포되지 않아, 그 내용이 이번 버전에 함께 들어 있습니다.
- Batch Report 분석 화면에서 개발자에게 받은 캐시 zip을 **프로그램 창에 끌어 넣으면** 이 PC 캐시로 불러옵니다([zip 찾기…]로 골라도 됩니다). 그 뒤 [조사 시작] · 찾기는 장비에서 새로 생긴 Batch Report만 읽습니다.
- **[🛠 개발자 기능]** 버튼 안에서 **[Batch Report 캐시 압축 파일 만들기 (zip)]**를 할 수 있습니다.
- 호기는 이름으로 맞추고, 이 PC에 등록되지 않은 호기는 건너뛰고 알려 줍니다. 이 PC에 있던 Batch Report는 그대로 두고 없는 것만 더합니다.
