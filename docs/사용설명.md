# 사용 설명서

## 1. 처음 준비 (관리자 1회)

1. **빌드 PC에서** `build_exe.bat` 실행 → `dist\PI_Param_Manager.exe` 생성
   (또는 Python 설치 PC라면 `run_dev.bat` 으로 바로 실행 가능)
2. 프로그램 실행 → **파일 > 기존 엑셀(.xlsm) 가져오기**
   - 원본: 기존 `Camtek_..._VBA.xlsm`
   - 저장 위치: **OneDrive 동기화 폴더** 안에 `PI_ALL_관리.xlsx` 등으로 저장
3. 이 `.xlsx` 가 앞으로 모두가 공유하는 **공용 파일**입니다.
4. `PI_Param_Manager.exe` 를 각 담당자 PC(또는 OneDrive 폴더)에 배포

## 2. 매일 사용

1. `PI_Param_Manager.exe` 더블클릭 (마지막으로 연 파일이 자동으로 열림)
2. **파라미터 편집** 탭에서 셀을 **더블클릭** → 값 입력 → Enter
3. 좌상단 **[저장]** (또는 Ctrl+S)
   - 변경 내용이 **변경 이력**에 자동 기록됩니다
   - 저장 시 디스크의 최신본을 다시 읽어 **내가 바꾼 셀만 병합**합니다

## 3. 화면 구성

| 탭 | 용도 |
|----|------|
| **파라미터 편집** | PI_ALL 그리드. 메타(PI/Recipe/Zone/Alg/Parameter/초기추천값/비고) + 호기 13개 값 편집 |
| **호기 비교 / 누락** | 파라미터별 호기 간 값 차이(빨강)·누락 호기(노랑)·공통(초록) 강조 |
| **변경 이력** | 자동 기록된 변경 로그. 검색어/PI/호기로 필터 |

## 4. 동시 편집 규칙 (중요)

- 누군가 편집 중이면 다른 사람이 열 때 **"OOO님 편집 중"** 안내가 뜹니다.
  - **읽기 전용**으로 보거나, 무시하고 편집할 수 있습니다(무시 시 충돌 위험).
- 서로 **다른 행**을 고친 두 사람의 저장은 **자동 병합**되어 둘 다 보존됩니다.
- 같은 셀을 동시에 고치면 **나중에 저장한 값**이 남습니다(이력에는 둘 다 기록).
- OneDrive **충돌본**(예: `파일명-PC이름.xlsx`)이 보이면 프로그램이 경고합니다 → 내용 확인 후 정리하세요.

> 팁: 동시 편집 빈도를 낮추려면 "편집할 때만 열고, 끝나면 닫기"를 권장합니다.
> 프로그램을 닫으면 편집 잠금이 자동 해제됩니다.

## 5. 자주 쓰는 메뉴

- **파일 > 공용 파일 열기**: OneDrive 폴더의 `.xlsx` 열기
- **파일 > 새로고침**: 다른 사람이 저장한 최신 내용 다시 읽기
- **파일 > 다른 이름으로 내보내기**: 백업/보고용 사본 저장
- **도움말 > 호기 IP 보기**: 호기별 IP 매핑(관련 자료) 확인

## 6. 파라미터 불러오기(통합) — 수집 → 취사선택 → 양식/값갱신

**파일 > 파라미터 불러오기(통합)** 하나로 예전의 '폴더 분석→취사선택'과
'값 갱신' 과정을 모두 진행합니다. 파싱 기준은 장비의
`GlobalRTP.ini / OpticPreset.ini / Zones/*.ini` 입니다(RTP.txt 미사용).

1. **① 수집** — `장비에서 수집…` 버튼: 장비 IP 여러 개 입력 → Job/Setup/Recipe
   폴더를 목록에서 클릭 선택 → 복사 목록 확인 후 로컬로 복사(원본은 읽기만).
   첫 장비에서 고른 선택은 다음 장비에 자동 적용됩니다.
   이미 파일을 받아뒀다면 `로컬 폴더` 경로 지정 후 `분석`만 눌러도 됩니다.
   - **접속 전 필수**: 수집할 장비마다 **탐색기에서 Win+R → `\\장비IP\c$` 로 한 번
     로그인**해 두어야 합니다(프로그램은 비밀번호를 입력받지 않습니다 — net use
     접속 기능은 삭제됨). 한 번도 연결 안 한 장비는 '접속 실패/폴더 없음'이 납니다.
2. **② 취사선택** — 위=기존 양식 항목(기본 선택), 아래=새로 불러온 항목.
   체크·이름·비고를 화면에서 바로 수정합니다(엑셀 수동 편집 불필요).
   분석 직후 전체 파싱본이 `initial/레벨/호기/일시/01_초안….xlsx` 로 자동 저장됩니다.
3. **③-A 양식 만들기** — 선택 항목만으로 PI/RDL 공용 양식(.xlsx) 생성
   (`…_PI.xlsx` / `…_RDL.xlsx` 분리). 확정본이 `final/…/02_확정….xlsx` 로도 저장.
4. **③-B 값 갱신** — 열려 있는 공용 파일의 구조는 그대로 두고 호기 값만 갱신.
   적용 전에 **바뀔 셀 목록을 미리 보여주고**, 진행 시 공용 파일을
   `백업/` 폴더에 자동 백업한 뒤 적용합니다. 적용 후 저장 버튼으로 기록하세요.

## 8. 화면 구성 개편(AOI 스펙) — 값 확인·양식 만들기·값 업데이트·이력

상단 탭이 **파라미터 값 확인 / 양식 만들기 / 특이사항 / 참고자료** 로 바뀌었습니다.

### 8.1 파라미터 값 확인(구 '파라미터')
- 호기별 값을 **보기 전용**으로 확인합니다(값 직접 수정 기능은 없앴습니다 —
  값은 아래 '값 업데이트'로만 채웁니다). 이름/추천값/비고/색 편집은 그대로입니다.
- 상단 액션 바
  - **📂 값 파일 열기**: 취합/양식 `.xlsx`를 화면으로 불러오기(PI/RDL 자동 판별).
  - **🔄 파라미터 값 업데이트**: 여러 장비에서 값을 읽어 레시피별 취합 파일을 만듭니다.
  - **🕑 파라미터 이력 확인**: 두 버전(이전/최신) 비교 → 변경내역 엑셀.
  - **⋯ 더보기**: 기존 열기/가져오기/다운로드/내보내기/통합 마법사(레거시).

### 8.2 양식 만들기 탭
1. **① 레시피 선택** — PI(PI2/PI3/PI4) 또는 RDL(RDL1~RDL4).
2. **② 불러오기 방식**
   - **장비/로컬에서 신규**: 파싱 → `01_초안` 엑셀 생성 → **실제 Excel로 열림**.
     '사용' 열과 '최종 Parameter'(장비 화면 이름)를 편집·저장한 뒤 프로그램의
     **[편집 완료 → 양식 생성]** 을 누르면 final(양식)이 만들어집니다.
     편집 전 **원형 초안**은 같은 폴더에 따로 보존됩니다.
   - **기존 저장 양식 열기**: 파일 선택 → 저장된 **버전 선택창**에서 원하는 버전 열기.
   - 이미 있는 양식에 저장 시 **덮어쓰기 / 새 버전** 을 고릅니다(이전 버전 보존).

#### 기존 양식 수정하기 — 뺐던 파라미터 다시 넣기
확정 양식에는 **체크해서 살린 항목만** 들어 있습니다. 그래서 예전에는 기존 양식을
열면 파라미터를 빼는 것만 되고, 처음에 체크 안 한 항목은 목록에 아예 없었습니다.

이제는 회차 폴더의 **원본**(`양식/{레시피}/{생성시간}/관련파일/…_원본_….xlsx` —
그 회차에서 읽은 **전체** 파라미터 목록)을 기준으로 엽니다. 지금 쓰는 항목은 체크된
채로, 빠져 있던 항목은 체크 해제 상태로 함께 보이므로 **다시 넣을 수 있습니다.**
사람이 바꾼 파라미터 이름·변환방식은 그대로 유지됩니다(이름이 아니라 설정키로
맞추기 때문).

레시피/버전 선택창에 상태가 표시됩니다.
- `✔ 항목 추가 가능` — 원본이 있습니다.
- `⚠ 원본 없음` — 예전에 **화면 편집기에서 바로 확정**한 회차입니다.

버전을 고르면 **무엇을 기준으로 열지** 묻습니다.

| 선택 | 언제 쓰나 |
|---|---|
| **저장된 원본으로 열기** (원본 있을 때 기본) | 평소. 빠릅니다 |
| **🖥 장비에서 다시 읽어 합치기** | 장비 설정이 바뀌었거나, **프로그램 업데이트로 파라미터 인식 규칙이 바뀐 뒤** |
| **📁 로컬에서 다시 읽어 합치기** | 위와 같되 이미 받아 둔 로컬 폴더에서 |
| **확정본만으로 열기** | 항목을 빼기만 할 때 |

원본이 없는 회차에서는 첫 줄이 **'같은 레시피의 다른 회차 원본 쓰기'** 로 바뀝니다.

'다시 읽어 합치기'를 고르면 장비에서 읽은 전체 파라미터가 후보가 되고, **지금
양식이 쓰는 항목은 자동으로 체크된 채로** 열립니다(설정키로 맞추므로 이름을 바꿔
둔 항목도 유지). 양식을 처음부터 다시 만드는 것과 달리 선택이 보존됩니다.

> **왜 다시 읽기가 필요한가**: 저장된 원본은 그 회차에 읽은 **스냅샷**입니다.
> 프로그램이 업데이트되어 파라미터 인식 규칙이 바뀌어도 스냅샷에는 반영되지
> 않습니다. 다만 **값**은 다시 읽지 않아도 됩니다 — '파라미터 값 업데이트'는
> 매번 장비를 새로 읽으므로 항상 최신 규칙이 적용됩니다. 다시 읽기가 필요한 건
> **양식에 어떤 항목이 들어 있는지(목록 구성)** 를 최신으로 맞출 때입니다.

> 지금부터 만드는 양식은 엑셀을 거치든 화면에서 바로 확정하든 **항상 원본이
> 저장**되므로, `⚠ 원본 없음` 안내가 뜨지 않습니다.

#### 레시피 삭제 (🗑 레시피 삭제)
더 쓰지 않는 레시피를 목록에서 없앱니다. 값 확인 화면의 레시피 카드를 우클릭해도
같은 창이 뜹니다.

**지웁니다**
- `양식/{레시피}/` 폴더 전체(모든 버전 + 관련파일) — 저장폴더에서 사라집니다.
- **최신** 취합본의 그 레시피 시트 → 값 확인 화면에서 카드가 없어집니다.
- 자동 감시 대상에서 제외(호기별 Job 폴더 지정도 함께 정리). 그대로 두면 무인
  회차가 없어진 폴더를 계속 찾다 실패 기록만 쌓입니다.

**그대로 둡니다**
- 과거 취합본 — '이력 확인'의 비교 대상이라 손대지 않습니다.
- `변환계수.xlsx` — 호기+MAG 기준이라 다른 레시피도 함께 씁니다.
- 변경보고서 등 과거 기록.

**되돌리는 법** — 양식 폴더는 지우는 게 아니라 내 PC의
`CamtekAOI\삭제보관\{레시피}_{시각}\` 으로 **옮깁니다.** (공유 폴더에 백업을 만들면
지운 파일이 그대로 다시 동기화되므로 일부러 내 PC에 둡니다.)

1. 삭제 완료 창의 **[📂 보관 폴더 열기]** 를 누릅니다.
   (창을 이미 닫았으면 위 경로를 탐색기 주소창에 붙여 넣으세요.)
2. 그 폴더를 통째로 저장폴더의 `양식\` 아래로 옮깁니다.
3. 폴더 이름을 원래 레시피 이름으로 바꿉니다 — 뒤의 `_{시각}` 부분을 지웁니다.
4. 프로그램에서 **⋯파일 > 다시 읽기** 를 누르면 목록에 그대로 돌아옵니다.

취합본의 값은 다음 '파라미터 값 업데이트' 때 다시 채워집니다.

> 같은 안내가 **삭제 확인창(지우기 전)과 완료창(지운 뒤)** 양쪽에 표시되므로,
> 미리 읽어 보고 결정할 수 있습니다.

**안전장치**: 삭제 전에 버전 수·파일 수·용량을 보여 주고, **레시피 이름을 그대로
입력해야** 삭제 버튼이 켜집니다. 다른 사람이 그 레시피 양식을 만드는 중이거나
엑셀로 그 폴더의 파일을 열어 두었으면 삭제가 막힙니다.

### 8.3 파라미터 값 업데이트
- 기준 **양식 파일** + 여러 장비(IP 수집 또는 로컬 폴더).
- **어떤 레시피(PI#/RDL#)** 를 취합할지 선택하는 알림창이 뜹니다.
- 양식의 파라미터와 장비 실제 파일이 **안 맞으면** 어떤 항목이 불일치인지 알리고,
  **[불일치]** 로 표기한 채 파일을 만들지 물어봅니다.
- 결과는 **레시피마다 각각**, **항상 새 버전**(`취합/버전/…`)으로 저장되고
  '현재본'이 갱신됩니다. 값 확인은 엑셀이 아니라 **프로그램 화면**으로 봅니다.
  - 이름 매칭은 표시 이름이 아니라 **원본 설정키(_EXTRACT_MAP)** 기준이라,
    사람이 파라미터 이름을 바꿔도 값이 정확히 채워집니다.

### 8.4 파라미터 이력 확인
- 이전/최신 취합 엑셀 2개를 고르면 값 변경·행 추가/삭제를 계산해
  **변경내역 엑셀**을 만듭니다. **비고(메모)** 열에 특이사항을 적을 수 있습니다.

### 8.5 자동 감시 (🔔 버튼)
정해진 주기마다 알아서 값을 수집·비교하고, 달라진 파라미터가 있을 때만 알려 줍니다.

설정창은 위에서부터 이렇게 씁니다.

1. **켜기/끄기** — 맨 위 큰 버튼. 초록 '● 켜짐'이면 감시 중입니다.
2. **주기** — 30분 / 1 / 2 / 4 / 6 / 8 / 12 / 24시간 중에서 고릅니다(기본 6시간).
   **실행 시간대**는
   - `0시 ~ 0시` = 제한 없음(저장하면 바로 첫 회차)
   - `9시 ~ 9시` 처럼 **시작과 끝을 같게** 하면 = **매일 9시에 시작**
     (첫 회차가 다음 9시, 이후 주기마다 반복)
   - `9시 ~ 18시` = 그 시간대에만 실행(장비 가동 피크 회피용)
   고른 내용이 무슨 뜻인지 콤보 아래에 한 줄로 표시됩니다.
3. **감시할 장비와 레시피** — 표에서 장비를 체크하고, 장비마다
   - `레시피…` 로 **그 장비에서 감시할 레시피**를 고르고
   - `📁 폴더…` 로 **그 장비의 Job 폴더**를 지정합니다(장비를 훑어 목록에서 선택).
   장비마다 감시할 레시피가 달라도 됩니다. **폴더 지정은 필수**입니다 — 지정하지
   않으면 프로그램이 이름을 유추하다 엉뚱한 폴더를 읽을 수 있어서, 미지정이 있으면
   저장이 막힙니다. 행 오른쪽에 `폴더 3/3 ✓` 처럼 현황이 보입니다.
4. **장비 접속 (탐색기 세션만)**
   - net use 접속 기능은 **삭제**되었습니다. 프로그램은 비밀번호를 입력받지 않고
     ID·비밀번호 칸도 없습니다.
   - 무인 감시할 장비마다 **탐색기에서 Win+R → `\\장비IP\c$` 로 미리 한 번
     로그인**해 두세요('내 자격 증명 기억' 체크). 한 번도 연결 안 한 장비는 그
     회차에서 건너뜁니다.

`▶ 즉시 확인` 은 주기를 기다리지 않고 지금 1회 돌립니다(변경이 없어도 결과를 알려 줌).
`연결 점검` 은 체크한 장비에 접근이 되는지 미리 확인합니다.
감시를 켠 채 창을 닫으면(X) 종료되지 않고 **알림영역 아이콘으로 내려가** 계속 감시합니다
(아이콘 우클릭 → 자동 감시 종료).

### 8.6 장비 접속 (탐색기 세션 사용)
장비 접속은 **탐색기(Win+R)로 미리 연결한 세션만** 사용합니다. 프로그램은 계정
정보를 다루지 않습니다(2026-09, net use 접속 삭제 — 보안 소프트웨어가 관리공유
로그온을 트로이/측면이동으로 오탐하던 문제를 없애기 위함).
- **접속 방법**: 수집·감시할 장비마다 Win+R → `\\장비IP\c$` 입력 → 처음이면 ID·
  비밀번호를 넣어 로그인('내 자격 증명 기억' 체크). 그 뒤 프로그램에서 그 호기를
  체크해 수집/감시합니다.
- **비밀번호는 프로그램 어디에도 저장·입력하지 않습니다.** `장비 IP 주소.xlsx` 의
  구 '접속ID' 열은 더 이상 읽지 않습니다(장비종류 열만 사용).
- 접속 오류 조치는 수집창의 **'❓ 접속이 안 될 때 / 접속 방법'** 도움말을 참고하세요.

> 오래 걸리는 동작(파싱·취합·양식 생성·이력 비교)은 **‘로딩 중’ 창**이 뜨고
> 백그라운드로 처리되어 화면이 멈추지 않습니다.

## 10. WPH 조사 (batch report → WPH 분석)

장비가 스캔할 때마다 Report 폴더(예: `P:\AOI-21\Reports`)에 쌓는 **batch report**
를 recipe 기준으로 취합해 **WPH(시간당 웨이퍼 수)** 를 분석합니다. 상단 **'WPH 조사'**
탭에서 사용합니다. 원본 리포트는 **읽기만** 하고, 결과는 **로컬 폴더**에만 저장됩니다.

1. **호기 선택 + Report 폴더 지정**: 조사할 호기를 체크하고, 각 호기의 Report 폴더를
   **'📁 폴더 지정…'** 으로 한 번 지정합니다(배치 리포트가 바로 들어 있는 폴더).
   - Report 폴더가 장비/네트워크 드라이브면 **탐색기에서 미리 연결(로그인)** 해 두세요.
2. **recipe 검색**: recipe 이름 앞부분까지만 입력하고 **'🔍 검색'** 을 누르면 그
   접두에 맞는 리포트 개수가 표시됩니다. 1개 이상인 호기만 조사 대상이 됩니다.
3. **유효 Lot 매수**: 통계·WPH에 쓸 full-lot 매수(기본 25)를 확인합니다. recipe·제품에
   따라 다르면 값을 바꾸세요.
4. **'▶ 조사 시작'**: 로컬 `WPH조사/조사_{시각}/` 폴더 하나에
   **취합 텍스트는 호기별(.txt)**, **WPH 분석 엑셀은 모든 선택 호기를 합친 통합 1개
   (.xlsx)** 로 만들어집니다. 완료 후 폴더를 열 수 있습니다.

> 엑셀은 입력(A:E)만 채우면 WPH·통계·이상치·그래프·대시보드가 **수식으로 자동 계산**
> 됩니다. **Actual WPH = Wafers Scanned × 3,600 ÷ Batch sec**. 통합 엑셀은 **U열=호기**
> 로 행을 구분하고(호기 열로 필터·피벗하면 호기별로도 볼 수 있음), **V열=batch report
> 생성일자(Batch End)** 입니다. 통계·WPH는 전체 호기 합산입니다.

## 9. 실행 오류 대처

### 9.1 "Failed to load Python DLL … python311.dll / LoadLibrary: 지정된 모듈을 찾을 수 없습니다"

단일 파일(exe)은 실행할 때마다 자기 안의 파이썬 DLL을 임시 폴더
(`…\AppData\Local\Temp\_MEIxxxxxx`)에 풀고 그것을 불러옵니다. 그 사이에 DLL이
사라지면 위 오류가 납니다. 원인은 대부분 다음 셋입니다.

1. **백신/보안 정책이 임시 폴더에 풀린 DLL을 차단·격리** (가장 흔함)
2. **임시 폴더가 정리되거나 세션별로 바뀜** — 경로에 `\Temp\1\` 처럼 숫자 폴더가
   보이면 세션별 임시 폴더를 쓰는 PC입니다
3. **exe 파일이 깨짐** — OneDrive 동기화가 덜 끝난 상태로 복사한 경우

**조치**

- **v3.0.1 이상으로 다시 배포받으세요.** 이 버전부터는 `%TEMP%` 가 아니라
  `%LOCALAPPDATA%\CamtekAOI\runtime` 에 풀도록 빌드합니다(`build_exe.bat` 의
  `--runtime-tmpdir`). 위 1·2번 원인이 사라집니다.
- 그래도 안 되면 **파일 크기 확인**: OneDrive `프로그램` 폴더의 원본과 내 PC의
  exe 크기가 같아야 합니다. 다르면 동기화가 끝난 뒤(구름 아이콘 → 체크 표시)
  다시 복사하세요.
- 백신 격리 기록이 있으면 관리자에게 **`%LOCALAPPDATA%\CamtekAOI` 예외 등록**을
  요청하세요.
- 특정 PC에서만 계속 실패하면, 빌드 PC에서 `build_exe.bat onedir` 로 만든
  **폴더 형태**(`dist\PI_Param_Manager\`)를 통째로 복사해 그 안의 exe를 실행합니다.
  이 형태는 임시 폴더에 아무것도 풀지 않아 같은 오류가 생기지 않습니다.
  단 **폴더째** 써야 하며, OneDrive에 exe 하나만 올리면 안 됩니다
  (프로그램이 게시할 때 자동으로 막습니다).
