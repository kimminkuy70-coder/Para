# 사용 설명서

## 1. 처음 준비 (관리자 1회)

1. **빌드 PC에서** `build_exe.bat` 실행 → `dist\PI_Param_Manager.exe` 생성
   (또는 Python 설치 PC라면 `run_dev.bat` 으로 바로 실행 가능)
2. 프로그램 실행 → **파일 > 기존 엑셀(.xlsm) 가져오기**
   - 원본: 기존 `Camtek_..._VBA.xlsm`
   - 저장 위치: **OneDrive 동기화 폴더** 안에 `PI_ALL_관리.xlsx` 등으로 저장
3. 이 `.xlsx` 가 앞으로 모두가 공유하는 **공용 파일**입니다.
4. `PI_Param_Manager.exe` 를 각 담당자 PC(또는 OneDrive 폴더)에 배포

## 2. 매일 사용

1. `PI_Param_Manager.exe` 더블클릭 (마지막으로 연 파일이 자동으로 열림)
2. **파라미터 편집** 탭에서 셀을 **더블클릭** → 값 입력 → Enter
3. 좌상단 **[저장]** (또는 Ctrl+S)
   - 변경 내용이 **변경 이력**에 자동 기록됩니다
   - 저장 시 디스크의 최신본을 다시 읽어 **내가 바꾼 셀만 병합**합니다

## 3. 화면 구성

| 탭 | 용도 |
|----|------|
| **파라미터 편집** | PI_ALL 그리드. 메타(PI/Recipe/Zone/Alg/Parameter/초기추천값/비고) + 호기 13개 값 편집 |
| **호기 비교 / 누락** | 파라미터별 호기 간 값 차이(빨강)·누락 호기(노랑)·공통(초록) 강조 |
| **변경 이력** | 자동 기록된 변경 로그. 검색어/PI/호기로 필터 |

## 4. 동시 편집 규칙 (중요)

- 누군가 편집 중이면 다른 사람이 열 때 **"OOO님 편집 중"** 안내가 뜹니다.
  - **읽기 전용**으로 보거나, 무시하고 편집할 수 있습니다(무시 시 충돌 위험).
- 서로 **다른 행**을 고친 두 사람의 저장은 **자동 병합**되어 둘 다 보존됩니다.
- 같은 셀을 동시에 고치면 **나중에 저장한 값**이 남습니다(이력에는 둘 다 기록).
- OneDrive **충돌본**(예: `파일명-PC이름.xlsx`)이 보이면 프로그램이 경고합니다 → 내용 확인 후 정리하세요.

> 팁: 동시 편집 빈도를 낮추려면 "편집할 때만 열고, 끝나면 닫기"를 권장합니다.
> 프로그램을 닫으면 편집 잠금이 자동 해제됩니다.

## 5. 자주 쓰는 메뉴

- **파일 > 공용 파일 열기**: OneDrive 폴더의 `.xlsx` 열기
- **파일 > 새로고침**: 다른 사람이 저장한 최신 내용 다시 읽기
- **파일 > 다른 이름으로 내보내기**: 백업/보고용 사본 저장
- **도움말 > 호기 IP 보기**: 호기별 IP 매핑(관련 자료) 확인

## 6. 파라미터 불러오기(통합) — 수집 → 취사선택 → 양식/값갱신

**파일 > 파라미터 불러오기(통합)** 하나로 예전의 '폴더 분석→취사선택'과
'값 갱신' 과정을 모두 진행합니다. 파싱 기준은 장비의
`GlobalRTP.ini / OpticPreset.ini / Zones/*.ini` 입니다(RTP.txt 미사용).

1. **① 수집** — `장비에서 수집…` 버튼: 장비 IP 여러 개 입력 → Job/Setup/Recipe
   폴더를 목록에서 클릭 선택 → 복사 목록 확인 후 로컬로 복사(원본은 읽기만).
   첫 장비에서 고른 선택은 다음 장비에 자동 적용됩니다.
   이미 파일을 받아뒀다면 `로컬 폴더` 경로 지정 후 `분석`만 눌러도 됩니다.
   - 탐색기에서 이미 `\\IP\c$`에 연결했다면 `net use 접속` 체크를 끄세요.
   - 비밀번호는 저장되지 않고 이번 실행 메모리에만 사용됩니다.
2. **② 취사선택** — 위=기존 양식 항목(기본 선택), 아래=새로 불러온 항목.
   체크·이름·비고를 화면에서 바로 수정합니다(엑셀 수동 편집 불필요).
   분석 직후 전체 파싱본이 `initial/레벨/호기/일시/01_초안….xlsx` 로 자동 저장됩니다.
3. **③-A 양식 만들기** — 선택 항목만으로 PI/RDL 공용 양식(.xlsx) 생성
   (`…_PI.xlsx` / `…_RDL.xlsx` 분리). 확정본이 `final/…/02_확정….xlsx` 로도 저장.
4. **③-B 값 갱신** — 열려 있는 공용 파일의 구조는 그대로 두고 호기 값만 갱신.
   적용 전에 **바뀔 셀 목록을 미리 보여주고**, 진행 시 공용 파일을
   `백업/` 폴더에 자동 백업한 뒤 적용합니다. 적용 후 저장 버튼으로 기록하세요.

## 7. 보안 안내 (사내 설명용)

- python.org 공식 Python 기반, **아나콘다 미사용**(라이선스 과금 무관)
- 실행 중 **인터넷 통신·프록시·서버 없음**. 네트워크 접근은 사용자가 명시적으로
  실행하는 **사내 장비 공유폴더(`\\IP\c$\Job`) 읽기전용 수집**뿐이며,
  장비 1대씩 접속 후 즉시 해제하고 원본은 절대 수정하지 않습니다
- 데이터는 **사내 OneDrive 동기화 폴더의 엑셀 파일**만 사용
- 단일 실행파일(.exe), 외부 패키지는 MIT 라이선스(openpyxl, tksheet)뿐
