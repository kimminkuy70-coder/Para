# Camtek AOI Manager (웹 UI) — 설치·초기 설정·업데이트

새 웹 UI(`version_webview`)를 처음 설치하는 사람을 위한 순서입니다.
기존 tkinter 프로그램을 쓰던 PC라면 이 문서를 끝낸 뒤 **[기존 자료 연동](WEB_UI_기존자료_연동.md)** 도 읽으세요.

> 아직 Windows 실기·실장비 검증 전인 개편 버전입니다. 운영 전환 전에 담당자가 한 대에서 먼저 확인하세요.

---

## 1. 준비물

| 항목 | 확인 방법 |
|---|---|
| Windows 10/11 | — |
| **WebView2 런타임** | 보통 기본 설치돼 있습니다. 앱 창이 하얗게만 뜨면 Microsoft 'WebView2 Runtime'을 설치하세요 |
| 설치 파일(폴더) | GitHub Actions 아티팩트 `Camtek_AOI_manager_v<버전>` zip, 또는 OneDrive `프로그램\Camtek_AOI_manager_web_v<버전>.zip` |
| 저장폴더 | 팀이 공유하는 OneDrive 폴더(기존 프로그램과 같은 곳) |
| 장비 접속 | 장비에서 수집할 PC라면 탐색기(Win+R)로 `\\장비IP\c$` 를 한 번 열어 연결해 둘 것(비밀번호를 프로그램에 넣지 않습니다) |

Rust·Node·Python 설치는 **필요 없습니다**(빌드된 폴더만 씁니다).

## 2. 설치 — 폴더를 통째로, 로컬에

1. zip 을 풉니다. 안에 `Camtek_AOI_manager.exe`, `sidecar\`, `package-manifest.json`, 문서가 있습니다.
2. **폴더 통째로** 아래 같은 위치에 둡니다.
   - 권장: `C:\Users\<내 계정>\Camtek_AOI_manager\`
   - 폴더 이름은 무엇이든 되지만 **한 번 정하면 그대로** 두세요(업데이트가 같은 경로에 새 버전을 넣습니다).
3. 두면 **안 되는** 곳
   - **OneDrive 폴더 안**: 파일 수백 개가 전원에게 동기화됩니다(보안 경고 사고와 같은 유형). 자동 업데이트도 거부됩니다.
   - **`C:\Program Files`**: 쓰기 권한이 없어 자동 업데이트가 실패합니다.
4. `Camtek_AOI_manager.exe` 바탕화면 바로가기를 만듭니다. exe 만 따로 복사하면 안 됩니다 — `sidecar\`(분석 엔진)가 옆에 있어야 합니다.
5. 처음 실행하면 서명되지 않은 exe 라 SmartScreen 경고가 뜰 수 있습니다(추가 정보 → 실행).

> **기존 프로그램과 동시에 켤 수 없습니다.** 둘이 같은 실행 잠금을 씁니다. 웹 앱 상단에
> "기존 프로그램이 켜져 있어…" 알림이 뜨면 기존 프로그램(트레이 아이콘 포함)을 종료하고 **[다시 연결]** 을 누르세요.

## 3. 첫 실행 — [설정] 탭 순서

앱은 기존 프로그램과 **같은 설정 파일**(`%USERPROFILE%\.pi_param_manager.json`)을 씁니다.
기존 프로그램을 이 PC에서 쓰고 있었다면 대부분 이미 채워져 있습니다 — 확인만 하세요.

| 순서 | 설정 탭 | 할 일 | 비고 |
|---|---|---|---|
| ① | **저장폴더** | 팀 공유 OneDrive 폴더 지정 | 처음이면 `장비 IP 주소 / 참고자료 / 특이사항.xlsx` 가 자동 생성됩니다 |
| ② | **로컬 작업 폴더** | 이 PC의 로컬 폴더 확인·변경 | 수집 임시본·로그·배치/Commonality 결과가 쌓입니다. OneDrive·네트워크·앱 설치 폴더 안은 불가. 설정이 없으면 `%LOCALAPPDATA%\CamtekAOI` 를 씁니다 |
| ③ | [장비 IP] 탭 | 호기·IP·장비종류 입력 | 값 업데이트·양식 만들기의 호기 목록이 이 문서 기준입니다 |
| ④ | **배치 Report 폴더** | 호기별 batch report 폴더(예 `P:\AOI-21\Reports`) | 배치 리포트 분석용 |
| ⑤ | **배치 자동·추가 폴더** | 필요하면 하루 1회 자동 갱신 · 백업 Report 폴더 | 기본 꺼짐 |
| ⑥ | **Scanresult 루트** | 호기별 Scanresult 상위 폴더(예 `W:\AOI-9`) | Commonality 조사용 |
| ⑦ | **정보** | 버전·오류 로그 폴더 확인 | 문제 생기면 로그 폴더 파일을 담당자에게 |

값 업데이트에서 "로컬 복사본"을 쓰려면 **[값 업데이트] 탭**에서 로컬 상위 폴더(그 아래 호기 이름 폴더가 있는 곳)를 한 번 지정합니다.

## 5. 업데이트

### 사용자

- 앱을 켜면 1~2초 뒤 게시 폴더를 확인해 새 버전이 있으면 **상단 초록 띠**가 뜹니다.
  - **지금 업데이트** — 게시본을 로컬에 받아 검증(크기·SHA-256·파일별 해시)한 뒤 앱이 종료되고, 새 버전이 **같은 설치 폴더**에 들어가 자동으로 다시 열립니다(바로가기 그대로 사용).
  - **직접 설치(게시 폴더)** — 게시 폴더를 엽니다. 자동 교체가 막히는 PC(백신 등)는 zip 을 직접 받아 2장처럼 교체하세요.
  - **이 버전 건너뛰기** — 이 버전 알림을 끕니다. [설정 › 정보 › 업데이트 확인]으로 언제든 다시 설치할 수 있습니다.
- 작업(배치 조사·수집 등)이 도는 중에는 [지금 업데이트]가 눌리지 않습니다.
- **되돌리기**: 교체 직전 버전이 설치 폴더 옆 `<설치폴더>.prev` 로 1개 보관됩니다. 앱을 끄고
  `<설치폴더>` 를 지운 뒤 `.prev` 의 이름을 `<설치폴더>` 로 바꾸면 이전 버전입니다.
- 업데이트 후에도 버전이 그대로면 다음 실행 때 "지난 업데이트가 적용되지 않았습니다" 알림이 뜹니다 → 직접 설치하세요.

### 개발자(게시)

1. GitHub Actions **Build Windows Desktop (Tauri)** 로 빌드 → 아티팩트 zip 을 **로컬에** 풉니다.
   (`python tools\build_desktop.py <버전>` 결과 폴더도 됩니다.) 폴더 안에 `package-manifest.json` 이 있어야 합니다.
2. 웹 앱 **[설정 › 정보 › 개발자: 새 버전 게시]** → 패키지 폴더 선택 → 변경 내용 입력 → **게시**.
   - 모든 파일을 manifest 로 검증하고, 버전도 그 파일에서 읽습니다(따로 입력하지 않음).
   - OneDrive 게시 폴더(저장폴더 **옆** `프로그램\`)에 **zip 1개**(`Camtek_AOI_manager_web_v<버전>.zip`)와 `버전정보_web.json` 이 생깁니다. 최신 2개 zip 만 남깁니다.
   - 기존 tkinter 프로그램의 `버전정보.json`·exe 는 건드리지 않습니다(서로 다른 게시물).
3. 같은 버전을 다른 내용으로 다시 게시하면 거부됩니다 — 버전을 올려 다시 빌드하세요.

## 6. 문제 해결

| 증상 | 조치 |
|---|---|
| 창이 하얗게만 뜸 | WebView2 런타임 설치 |
| "분석 엔진을 시작하지 못했습니다" | `sidecar\` 폴더가 exe 옆에 있는지 확인(폴더째 두었는지) |
| "기존 프로그램이 켜져 있어…" | 기존 프로그램·트레이 아이콘 종료 → [다시 연결] |
| 화면에 데이터가 없음 | [설정]에서 저장폴더·Report 폴더·Scanresult 루트 확인 |
| 장비 수집 실패 | 탐색기로 `\\장비IP\c$` 를 먼저 열어 연결했는지 확인 |
| "권한이 없습니다" 알림 | 다른 사람이 Excel 로 열어 두었거나 OneDrive 동기화 중 — 잠시 후 다시 |
| 업데이트 후 옛 버전 그대로 | [직접 설치(게시 폴더)]로 zip 을 받아 2장처럼 교체 |
