# Para (Camtek AOI 파라미터 관리) — IT/보안 검토 자료

사내 배포 전에 보안팀·IT부서에 설명하기 위한 문서. **프로그램이 무엇을 하고,
무엇을 하지 않는지**를 모니터링 관점에서 정리했다.

## 1. 한 줄 요약

AOI 장비의 레시피 설정파일(.ini)을 **읽기 전용**으로 모아 엑셀로 비교·관리하는
사내 데스크톱 프로그램. 인터넷 통신 없음, 원본 수정 없음, 개인정보 취급 없음.

## 2. 프로그램이 접근하는 곳 (전부)

| 대상 | 방식 | 빈도 |
|---|---|---|
| OneDrive 동기화 폴더(팀 공유) | 엑셀 파일 읽기/쓰기 | 사람이 저장할 때 + 감시 회차에 변경이 있을 때 |
| AOI 장비 `\\{IP}\c$\Job` 하위 | **읽기·복사만** | 사람이 실행할 때 + 자동 감시 주기(기본 6시간) |
| 로컬 `%LOCALAPPDATA%\CamtekAOI` (또는 지정 폴더) | 임시파일·로그·캐시 | 작업 중 |

**하지 않는 것**: 인터넷 연결, 외부 전송, 메일/브라우저 접근, 레지스트리 변경,
서비스·스케줄러 등록, 다른 사용자 폴더 접근, 장비 원본 파일의 수정·삭제·이동.

## 3. 모니터링에 보일 수 있는 동작과 설계상 억제 장치

### 3.1 관리공유(`c$`) 접근 — 가장 눈에 띄는 항목

레시피 파일이 장비 `C:\Job` 아래에 있어 관리공유로 읽는다. 사람이 탐색기로
여는 것과 동일한 접근이며, 다음을 지킨다.

- **읽기·복사만.** 쓰기 대상이 UNC 경로면 코드가 예외를 던져 원천 차단
  (`collector._assert_local_write_target`, `tests/test_collector_safety.py`).
- **`\Job` 하위 2단계까지만** 탐색. `c$` 전역 재귀 탐색을 하지 않는다.
- **장비 1대씩 순차** 접속, 끝나면 즉시 `net use /delete`.
- **장비 사이 2초, 파일 복사 사이 0.1초 간격** — 여러 대를 몇 초 안에 훑는
  '측면 이동 스캔' 패턴이 되지 않게 한다(`HOST_GAP_SEC`, `COPY_DELAY_SEC`).
- 자동 감시 기본 주기는 **6시간**(하루 4회). 회차당 장비 1대에서 읽는 파일은
  레시피 폴더의 `GlobalRTP.ini`·`OpticPreset.ini`·`RTP.txt`·`Zones\*.ini`.

### 3.2 인증 — 실패 로그온을 만들지 않는다

- 기본 접속 방식은 **`net use` 없이 기존 탐색기 세션 사용**(비밀번호 불필요).
- `net use` 방식을 고른 경우에도 **비밀번호는 메모리에만** 두고 디스크에 저장하지
  않는다. 앱을 다시 켜면 사라진다.
- **접속 정보가 없으면 `net use` 를 시도조차 하지 않는다.** 빈 비밀번호로
  접속을 시도해 장비마다 로그온 실패(4625)를 쌓지 않는다 — 무차별 대입 오탐과
  공용 계정 잠금을 둘 다 막기 위한 규칙이다(`tests/test_network_manners.py`).

### 3.3 연결 점검(TCP 445)

자동 감시를 켤 때 사람이 누르는 '연결 점검'에서만, 선택한 장비에 한해
TCP 445 도달 여부를 확인한다. **호스트 사이 0.4초 간격**을 둬 수평 포트 스캔
패턴이 되지 않게 한다(`watcher.PROBE_GAP_SEC`).

### 3.4 OneDrive 쓰기량

2026-08 'Unusual High-Volume Directory Access' 경고 이후 전면 재정비했다.
**공유 폴더에는 결과 엑셀만** 남기고, 임시파일·수집 원본·조사 산출물·로그는
전부 로컬에 둔다. 회차당 공유 폴더에 생기는 파일은 **0~1개**(변경이 없으면 0개).
규칙은 `tests/test_onedrive_writes.py` 로 고정되어 회귀를 막는다.

### 3.5 실행파일 자동 업데이트

새 버전은 **OneDrive 공유 폴더**를 통해 배포한다(인터넷 다운로드 없음).
적용 시 사용자는 세 가지 중 고를 수 있다.

1. **자동 교체** — 새 exe 를 로컬로 복사(SHA-256 검증) 후, 배치스크립트가
   프로그램 종료를 기다렸다 파일을 교체하고 다시 실행한다.
2. **직접 설치** — 게시 폴더만 열어 주고, 사용자가 직접 복사한다.
   *자동 교체(실행 중 exe 자기 교체)가 백신 행위기반 탐지에 걸리는 환경이면
   이 방식을 쓰면 된다. 프로그램은 아무 파일도 바꾸지 않는다.*
3. **나중에**

### 3.6 실행파일 자체

- python.org 공식 Python + PyInstaller 로 빌드한 단일 exe. **코드 서명 없음**
  → SmartScreen/Defender 가 '알 수 없는 게시자'로 경고할 수 있다(평판 부족).
- 단일 파일 실행 특성상 시작할 때 `%LOCALAPPDATA%\CamtekAOI\runtime` 에
  파이썬 런타임 DLL 을 풀고 로드한다. **`%TEMP%` 를 쓰지 않도록** 고정 폴더로
  지정해 두었으므로, 예외 등록이 필요하면 이 경로 하나만 등록하면 된다.

## 4. 예외 등록을 요청할 때 쓸 목록

| 항목 | 값 |
|---|---|
| 실행파일 | `Camtek_AOI_Parameter_manage_v{버전}.exe` |
| 런타임 추출 폴더 | `%LOCALAPPDATA%\CamtekAOI\runtime` |
| 작업 폴더(임시·로그) | `%LOCALAPPDATA%\CamtekAOI` 또는 사용자가 지정한 폴더 |
| 네트워크 접근 | 사내 AOI 장비 IP, TCP 445 (SMB), 읽기 |
| 인터넷 접근 | **없음** |
