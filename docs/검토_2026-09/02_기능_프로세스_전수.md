# 보고서 2 — 전체 기능 프로세스 전수 설명 + 불필요 기능/스텝 후보

> 대상 버전: `version_v3.0`
> 목적: **모든 기능이 어떤 프로세스로 작동하는지** 세세히 기술하고, 이를 근거로
> **삭제·단순화 후보**를 표시한다(실제 삭제는 사용자 결정).

각 기능은 `[진입] → [내부 처리] → [산출물]` 순으로 기술한다. "관련 모듈/함수"는
근거 추적용이다. **정리 후보** 표시:
🗑 삭제 검토 · ✂ 단순화/통합 검토 · ✅ 유지(핵심).

---

## A. 실행 · 부트스트랩

### A-1. 프로그램 시작 (`main` → `equip_app.App.__init__` → `_startup`)
- **진입**: exe 더블클릭 또는 `run.py`.
- **처리**:
  1. 단일 인스턴스 뮤텍스 획득(`singleinst`) — 이미 떠 있으면 기존 창 복원 후 종료.
  2. 자동 업데이트 조용히 확인(0.5초 후, `_check_update_prompt`).
  3. 저장 폴더 확인/지정 → 로컬 작업 폴더 설정 → 참고자료 로드 → 최신 취합 로드 → 렌더.
- **산출물**: config 저장, 화면 렌더.
- 정리: ✅ 유지. 단 **매 실행 "저장 폴더 그대로?" 모달**은 ✂ (상태바+버튼으로 대체 검토).

### A-2. 저장 폴더 / 로컬 작업 폴더 설정 (`_choose_save_dir`, `_setup_local_dir`)
- 저장 폴더 = OneDrive 공유(결과물). 로컬 = OneDrive 밖(임시·로그·캐시·Commonality).
- OneDrive 안에 로컬 폴더를 잡으려 하면 경고 + 안전 위치로 대체.
- 정리: ✅ 유지(보안상 필수 분리). ✂ 두 폴더 설정을 1개 마법사 단계로 묶기.

## B. 파라미터 값 확인 탭 (읽기 전용)

### B-1. 호기 격자 → 레시피/변형 선택 → 값 표 (`_screen_machines`/`_screen_recipe_pick`/`_screen_equipment`)
- **진입**: 첫 탭. **처리**: 최신 취합 엑셀(`collate.load_as_repo`) 자동 로드(멀티시트 병합, 읽기 전용).
- 호기 선택 → 레시피/변형 → 호기별 값 표 + 우측 비교 시트 + 색 규칙(이탈/누락/공통).
- **산출물**: 화면 표시만(파일 안 씀).
- 정리: ✅ 유지(핵심 조회).

### B-2. 액션바
- **값 업데이트** → 섹션 D. **이력 확인** → 섹션 E. **최신 취합 새로고침** → 재로드.
- **⋯파일**: 저장 폴더 변경 / 다시 읽기 / 로컬 폴더 / 접속자 보기 / 프로그램 정보 /
  업데이트 확인 / 새 버전 배포 / 장비 다운로드.
- 정리: 값 확인 화면에 **쓰기 동작(값 업데이트)** 이 섞인 것은 ✂ (읽기/쓰기 경계 분리 권고).

## C. 양식 만들기 탭

### C-1. 신규 양식 (`_form_new` → 수집 → `formbuilder.build_initial_workbook` → Excel 편집 → `build_final_from_initial` → `_form_finalize`)
- **진입**: 레시피 선택 → "장비/로컬에서 신규".
- **처리**:
  1. 장비/로컬에서 `GlobalRTP.ini + OpticPreset.ini + Zones/*.ini`(+ `ActiveScenarioOptics.ini`,
     `ManReClassify.ini`) 파싱(`ini_parser`) → 전체 후보 목록.
  2. `01_초안` 엑셀 생성 → **실제 Excel로 열림** → '사용'/'최종 Parameter' 편집.
  3. **변형별 계수 확정**(`_ask_scales` + `coef_detector` 추천) → `변환계수.xlsx` 반영(사람 확정 시만).
  4. `[편집 완료]` → 확정 양식 + `관련파일/`(원본·수정본) + `_EXTRACT_MAP` 숨김시트.
- **산출물**: `양식/{레시피}/{시간}/{레시피}_{호기}호기_참조_{시간}.xlsx`(+관련파일).
- 정리: ✅ 유지(핵심). **Excel 왕복**은 ✂ (화면 편집기 우선, Excel은 고급 옵션).

### C-2. 기존 양식 수정 (`_load_previous_form` → `_ask_edit_source` → `_recollect_for_edit`)
- 회차의 `_원본_` 후보로 편집기를 열어 **뺐던 항목 복원 가능**.
- "무엇을 기준으로 열지" 4택: 저장된 원본 / 🖥 장비 다시 읽기 / 📁 로컬 다시 읽기 / 확정본만.
- 매칭은 **설정키**(이름 아님) → 사람이 바꾼 이름 유지.
- 정리: ✅ 유지(중요 기능). 단 4택 UI는 ✂ (기본값 강조 + 나머지 접기).

### C-3. 레시피 삭제 (`_delete_recipe_dialog`/`_delete_recipe_run`)
- 양식 폴더를 **로컬 `삭제보관/`으로 이동**(되돌리기), 최신 취합 시트 제거, 감시설정 정리.
- 안전장치: 미리보기 · 이름 직접 입력 · Excel 점유 시 거부 · 삭제 전후 되돌리기 안내.
- 정리: ✅ 유지(모범적 설계).

## D. 값 업데이트 (`_update_values_dialog` → `_update_collate_flow` → `collate.build_collation`)

- **진입**: 값 확인/양식 탭에서 실행.
- **처리(순서)**:
  1. 레시피 선택 알림.
  2. **IP↔호기 매칭창**(IP로 새 열 만들지 않음).
  3. **하위 레시피(변형) 이름 매칭 확인창**(`collate.variant_match_table`).
  4. 장비/로컬 수집 → 설정키 매칭 취합, **직전 취합본 이어받기**, 불일치 검출.
- **산출물**: `파라미터 값 취합/파라미터 값 취합_{시간}.xlsx`(레시피별 시트, 전체 호기 열).
- 정리: ✅ 유지(핵심). **IP↔호기 매칭 스텝(D-2)** 은 장비 IP가 이미 공유파일에 있으므로
  대부분 자동 확정 가능 → ✂ (불일치가 있을 때만 창 노출).

## F. 자동 감시 (장비) — `watcher.py` + `_watch_*`
- **진입**: 🔔 자동 감시 설정창. **처리**: 주기(기본 6h)·시간대·호기별 레시피·Job 폴더(필수 지정)마다
  조용히 수집→취합→직전 비교→**변경 있을 때만** 알림 + `자동감시/변경보고서_{시간}.xlsx`.
- 전역 잠금 1개(1대 PC만 수집), 결과는 모두 공유, 트레이 상주.
- 정리: ✅ 유지(핵심 자동화). 설정창 정보량은 ✂ (섹션 접기/단계화).

## G. Commonality 자동 감시 — `cmwatcher.py`
- 새 S/M 폴더 감지 → 계획 추가 → 안전복사 → 저장 양식으로 값 조사 → 결과 누적(전부 로컬).
- 장비 감시와 **파일·잠금 분리**, 트레이 상주 공동 판단.
- 정리: ✅ 유지하되 **복잡도 매우 높음**. 두 감시(장비/Commonality)의 개념·설정·트레이 툴팁이
  이원화 → ✂ 장기적으로 "자동 감시" 하나의 우산 아래 하위 모드로 통합 검토.

## H. Commonality 조사(수동) — `commonality.py` + `_cm_*`
- 7단계 파이프라인(호기 선택 → Lot 계획 → 폴더 확인 → 안전복사 → 양식 → 값 조사 → 비교/뷰어).
- 디바이스별/레시피별 분리, 느슨 매칭, 대표 S/M, 이탈 색칠.
- 정리: ✅ 유지(전문가 기능). UX는 보고서 1 참조.
