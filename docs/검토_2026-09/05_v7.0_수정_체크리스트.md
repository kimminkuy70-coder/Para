# v7.0 수정 계획 · 체크리스트

> 브랜치: `version_v7.0` (기반 `version_v3.0`)
> 원칙: 기존 기능/안전장치 유지, **텍스트·명칭·안내·레이아웃 중심 개선**. GUI는

## 항목 1 — 화면 크기에 맞는 반응형 UX (글자 잘림 전수조사) ⬜
- **증상**: 고정 픽셀 폭/단일 라벨로 인해 긴 텍스트가 잘림.
- **조사 대상(전수)**:
  - `_big_button`(레시피/카드, 고정 250×96, `wraplength` 없음) → 항목 4와 함께 처리
  - 탭 버튼(`padx=22`) · 상단 타이틀 · 크럼 라벨
  - 각 Toplevel 다이얼로그의 고정폭 라벨·`wraplength` 누락 지점
  - 값 표(tksheet) 열 폭, 콤보 `width=` 고정값
  - 메인 창 `geometry("1400x860")` 고정 → 소형 화면(1366×768) 대응
- **작업**:
  1. 긴 라벨에 `wraplength`/`justify` 부여, 카드/버튼은 내용 길이에 맞춘 최소폭+줄바꿈.
  2. 창 최초 크기를 화면의 일정 비율로(작은 화면이면 축소), `minsize` 유지.
  3. 잘림 후보 지점 목록을 이 문서 하단 부록 A에 표로 기록(전수 근거).

## 항목 3 — 탭 명칭 변경 + 양식 만들기 탭 중첩 ⬜
- **대상**: 탭 정의(236~248), `_set_view`/`_render`(387~), `_view_form`(2924).
- **명칭 변경**:
  - `파라미터 값 확인` → **Recipe 관리**
  - `양식 만들기` → **Recipe 양식 만들기**
  - (액션바) `파라미터 값 업데이트` → **Recipe 업데이트**
- **구조 변경**: 상단 탭에서 `양식 만들기`를 빼고, **Recipe 관리 탭 내부에 2차 탭바**
  (`Recipe 관리` | `Recipe 양식 만들기`)를 둔다.
  - 최상단 탭: **Recipe 관리 / Commonality 조사 / 특이사항 / 참고자료 / 장비 IP** (6→5)
  - Recipe 관리 내부: 값 확인 화면 + Recipe 양식 만들기 화면을 하위 탭으로.
- ⚠ **가장 구조적 변경** → 뒤로/앞으로/크럼·저장버튼 표시 로직(`_sync_nav_widgets`) 영향.

## 항목 4 — Recipe 선택 화면 가독성 (잘림/번호/글씨) ⬜
- **대상**: `_screen_recipe_pick`(577), `_big_button`(888), `_recipe_delete_menu`(646).
- **작업**:
  1. 화면 제목 "… — 레시피 선택" → **"… — Recipe 선택"**.
  2. **상위 레시피(레벨) 헤더**: 현재 작은 검은 글씨 → **번호 매기고**(`1. PI3`) **글씨 키움**
     (title급), 색 강조. 예: `1. PI3` `2. RDL4`.
  3. **하위 Recipe 카드 글자 잘림**: `_big_button` 에 `wraplength`(카드폭-여백) 적용 →
     **2~3줄 자동 줄바꿈**, 길면 폰트 한 단계 축소. **박스 크기(250×96)는 유지**.
  4. **삭제 범위 설명 추가**: 우클릭 삭제 메뉴/확인창에
     "이 삭제는 **모든 호기 공통**으로 해당 레시피 양식·최신 취합 시트를 제거합니다
     (특정 호기만 삭제가 아님)" 명시. (현행 `_delete_recipe_dialog` 동작 = 전체 공통.)

## 항목 5 — 호기 목록에 장비 종류 표시 + KLA 숨김 옵션 ⬜
- **대상**: `refdata.py`(IP_HEADERS·load_ip·save), `_screen_machines`(462), `_view_ip`.
- **작업**:
  1. `refdata.IP_HEADERS` 에 **`장비종류` 열 추가** → `["호기","IP","장비종류","접속ID"]`.
     - 하위호환: 구 파일(열 없음)은 로드 시 빈 값 처리, 저장 시 자연 추가.
     - 값 예: `Camtek` / `KLA`. 미지정은 빈칸(기본 표시).
  2. **장비 IP 탭**(`_view_ip`)에 장비종류 열 편집 가능하게(콤보 Camtek/KLA).
  3. **호기 선택 화면**에 체크박스 **"KLA 장비 숨기기"**(기본 켬) 추가 → 체크 시
     장비종류=KLA 호기는 격자에서 제외. 상태는 config(`hide_kla`)에 저장.
  4. 격자 카드에 장비종류 배지(작게) 표시.
  - 참고: K1~K6 이 KLA 인 것은 데이터(엑셀 장비종류 열)로 관리(하드코딩 안 함).

## 항목 6 — 이력 확인 → Recipe 날짜별 비교 (드래그·순차 다중비교) ⬜
- **대상**: `_history_dialog`(6006), `_show_diff_window`(6038), `history.py`.
- **작업**:
  1. 명칭: `파라미터 이력 확인` → **Recipe 날짜별 비교**.
  2. UX: **좌측 = 취합/버전 목록**, **우측 = 비교 대상 슬롯(2개+)**. 좌→우 **드래그**로 추가.
     (드래그 미지원 환경 대비 '▶ 추가' 버튼 병행.)
  3. **순차 다중 비교**: 우측에 N개를 순서대로 넣으면 (1↔2), (2↔3) … 연쇄 비교 결과를
     탭/구간으로 표시. `history.diff_files` 를 쌍마다 호출.
- ⚠ tkinter 순수 드래그는 구현 부담 → 리스트 간 드래그(간이) + 버튼 병행으로 안전 구현.
