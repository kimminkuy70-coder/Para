# 보안·라이선스 검토 결과

> 결론: 아나콘다 같은 유료/보안 함정을 모두 회피했으며, 실행 중 회사 외부망·프록시를 일절 사용하지 않습니다.

## 1. 아나콘다 경고 재발 방지

- 아나콘다는 **직원 200명 이상 조직에 유료 라이선스 의무**(개인당 월 약 $50). → 회사가 경고받은 원인.
- 본 프로그램은 **아나콘다/Miniconda/conda 를 전혀 사용하지 않습니다.**
- 대신 **python.org 공식 Python**(PSF License, 상업 사용 무료) 사용 → 과금 대상 아님.

## 2. 사용 패키지 라이선스·비용

| 구성요소 | 출처 | 라이선스 | 비용 | 비고 |
|---|---|---|---|---|
| Python(본체) | python.org | PSF | 무료 | 아나콘다와 무관 |
| openpyxl | PyPI | MIT | 무료 | 유일한 필수 외부 패키지 |
| tkinter | 표준 내장 | PSF | 무료 | 별도 설치 없음 |
| http/json/sqlite 등 | 표준 내장 | PSF | 무료 | 별도 설치 없음 |
| PyInstaller(빌드용) | PyPI | GPL + 상업 예외 | 무료 | 상업/사내 .exe 배포 합법, 소스공개 의무 없음 |

→ **과금 요소 없음.** 외부 패키지를 openpyxl 1개로 최소화하여 보안 검토 표면을 줄였습니다.

## 3. 보안(외부망·프록시) 검토

| 항목 | 본 프로그램 | 판정 |
|---|---|---|
| 실행 중 인터넷 접속 | 없음 | ✅ |
| 프록시 사용 | 없음 | ✅ |
| 네트워크 포트 개방 | 없음 (tkinter 네이티브, 소켓 미사용) | ✅ |
| 데이터 전송처 | 로컬 OneDrive 동기화 폴더 파일만 | ✅ |
| 외부 서버/클라우드 | 없음 (자체 서버도 없음) | ✅ |
| 텔레메트리 | 없음 | ✅ |

→ **완전 오프라인 동작.** 외부망·프록시 정책에 저촉될 동작 없음.

### 유일하게 네트워크가 필요한 시점 = 빌드/설치 단계뿐
- openpyxl·PyInstaller 최초 다운로드(PyPI). **빌드 PC 1대에서만, 1회.**
- 배포된 `.exe` 실행 PC는 **네트워크 불필요.**
- 사내망이 PyPI 를 막으면 회사 승인 내부 미러를 사용.

## 4. IT/보안팀 설명 문구

- python.org 공식 Python 기반, 아나콘다 미사용(라이선스 무관)
- 외부 통신·프록시 없음, 완전 오프라인 실행
- 데이터는 사내 OneDrive 동기화 폴더의 엑셀 파일만 사용
- 단일 실행파일(.exe), 외부 패키지는 MIT 라이선스 openpyxl 1개뿐
