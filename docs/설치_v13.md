# Camtek AOI Manager v13 — 설치 · 업데이트 안내

v13 부터는 **우리가 만든 실행 파일(exe)이 없습니다.** python.org 의 Python(Python Software Foundation 서명)이
프로그램 글 파일(.py)을 그대로 실행하고, 화면은 이미 PC 에 있는 Microsoft Edge 의 별도 창으로 보입니다.
v12 zip 이 Windows Defender 에 막히던 원인(서명 없는 새 exe)이 없어졌습니다.

## 처음 설치 (한 번)

1. GitHub 릴리스 페이지에서 `Camtek_AOI_manager_v13.x.y_install.zip` 을 받으십시오.
   (https://github.com/kimminkuy70-coder/Para/releases)
2. 탐색기 주소창에 `%LOCALAPPDATA%\CamtekAOI` 를 입력하고 Enter 를 누르십시오. 그 안에 `app` 폴더를 만드십시오.
3. 받은 zip 을 `%LOCALAPPDATA%\CamtekAOI\app` 에 푸십시오(권장 위치).
   `app` 바로 아래에 `python` 폴더, `app` 폴더, `Camtek_AOI_manager.pyw`, `Camtek_AOI_manager.bat` 이 보여야 합니다.
   - 다른 로컬 폴더(예: `C:\CamtekAOI`)에 풀어도 동작합니다.
   - OneDrive 폴더에는 풀지 마십시오. 프로그램이 실행을 거부합니다(동기화 경고 방지). 바탕화면 · 문서 폴더가 OneDrive 로 옮겨진 PC 는 그 폴더도 해당합니다.
   - Program Files(쓰기 권한 없음 — 업데이트 불가) · 네트워크 드라이브 · Downloads 폴더에는 풀지 마십시오.
4. 푼 폴더의 **`Camtek_AOI_manager.bat`** 을 더블클릭하십시오.
   이 파일의 실행 명령은 한 줄입니다: 같은 폴더의 `python\pythonw.exe` 로 `Camtek_AOI_manager.pyw` 를 실행합니다.

   ```
   @echo off
   start "" "%~dp0python\pythonw.exe" "%~dp0Camtek_AOI_manager.pyw"
   ```

5. 프로그램 창이 열리고, 바탕화면에 **Camtek AOI Manager** 바로가기가 생깁니다. 다음부터는 바로가기나 `Camtek_AOI_manager.bat` 으로 실행하십시오.

관리자 권한, Python 설치, Git 설치는 필요 없습니다. 설정 · 캐시 · OneDrive 공유 자료는 v12 것을 그대로 씁니다
(v12 프로그램이 켜져 있으면 v13 은 시작하지 않습니다 — v12 를 먼저 끄십시오).

## 업데이트

- 프로그램을 켤 때 새 버전이 있으면 **알림 창**이 뜹니다. **[지금 업데이트]** 를 누르십시오.
  프로그램이 새 파일을 받아 확인한 뒤 **"프로그램을 종료하고 다시 실행하십시오"** 창을 띄웁니다. [지금 종료] → 바탕화면 바로가기로 다시 실행하면 새 버전이 적용됩니다.
  ([나중에]를 누르면 지금 버전으로 계속 쓰고, 다음에 실행할 때 적용됩니다.)
- [나중에] 를 누르면 다음에 켤 때 다시 알려 줍니다. 설정 › 정보 › [업데이트 확인] 으로도 확인할 수 있습니다.
- 받는 곳: GitHub 의 이 프로그램 릴리스(인터넷은 이때만 씁니다). GitHub 에 연결되지 않는 PC 는
  OneDrive 의 `프로그램` 폴더(개발자가 게시한 것)를 봅니다.
- 받은 파일에 실행 파일(exe · dll · bat 등)이 있으면 적용하지 않습니다.

## 막혔을 때

| 증상 | 할 일 |
|---|---|
| 4번(.bat 더블클릭)에서 아무 창도 안 뜸 | 1~2분 기다리십시오(첫 실행은 보안 검사로 느릴 수 있음). 그래도 안 되면 `%LOCALAPPDATA%\CamtekAOI\Logs` 의 파일을 담당자에게 보내십시오. |
| "프로그램 폴더가 OneDrive 안에 있습니다" | 3번 위치(`%LOCALAPPDATA%\CamtekAOI\app`)에 다시 푸십시오. |
| .bat 더블클릭이 회사 정책으로 막힘 | Win + R 에 `"<설치 폴더>\python\pythonw.exe" "<설치 폴더>\Camtek_AOI_manager.pyw"` 를 붙여 넣고 Enter (.bat 과 같은 일) |
| "이미 실행 중입니다" | 작업 표시줄 알림 영역의 아이콘에서 여십시오. v12 프로그램이 켜져 있으면 끄십시오. |
| 업데이트가 안 됨(GitHub 연결 실패) | 개발자에게 OneDrive 게시를 요청하십시오(설정 › 정보 › 개발자: OneDrive 에 새 버전 게시). |
| 바탕화면 바로가기가 사라짐 | `Camtek_AOI_manager.bat` 으로 실행하면 새로 만들어집니다. |
