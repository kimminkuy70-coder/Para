# 3차 재설계 — 저장 폴더 기준 구조 (진행/인수인계)

> 기존 "열어둔 파일 옆에 폴더 생성" 모델을 폐기하고, **저장 폴더 1곳**을 기준으로
> 재구성한다. 세션이 끊겨도 이 문서로 이어받을 것. 브랜치:
> `claude/program-dev-prompt-file-f2oept`.

## 0. 사용자 확정(2026-07) — 재질문 금지

- 첫 실행 시 **저장 폴더 지정**(config 1회). 이후 그 폴더 기준.
- 참고자료/특이사항은 **독립 엑셀 파일**(`참고자료.xlsx`/`특이사항.xlsx`). 없으면
  경로 지정 or 빈 양식 생성.
- **호기 목록 = 참고자료 기준**(고정 34호기 폐기). 호기 추가=이름+IP→참고자료 기록.
- 값 확인 값 출처 = **최신 취합 파일 자동**(a).
- 취합 누적 정책 = **직전 취합본에서 이어받기**(a). 이번 수집 호기만 갱신, 나머지 유지.
- 참고자료 형식 = **표 [호기, IP, 비고]**(a).
- 기존 '공용 파일' 방식 기능 = **전부 삭제**(a): 공용/값 파일 열기·xlsm 가져오기·통합
  마법사·내보내기·새로고침·레거시 app.py·파일 내 잠금/이력/특이사항/참고자료 시트 모델.
- 파일명 "참조"는 예시대로 **리터럴 라벨** 유지.

## 1. 폴더/파일 구조

```
{저장폴더}/
├─ 참고자료.xlsx        시트 "참고자료", 헤더 [호기, IP, 비고]
├─ 특이사항.xlsx        시트 "특이사항", 헤더 = engine.SPECIAL_HEADERS
├─ 양식/
│   └─ {레시피}/                     예: PI3, RDL4, 커스텀
│       └─ {생성시간}/               YYYYMMDD_HHMMSS
│           ├─ {레시피}_{호기}호기_참조_{생성시간}.xlsx   확정 양식
│           └─ 관련파일/
│               ├─ (원본 ini … 기존 네이밍 유지)
│               ├─ {레시피}_원본_{호기}호기_참조_{생성시간}.xlsx   편집 전 원본
│               └─ {레시피}_수정본_{호기}호기_참조_{생성시간}.xlsx 편집 초안
└─ 파라미터 값 취합/
    └─ 파라미터 값 취합_{생성시간}.xlsx   시트=레시피별, 열=참고자료 전체 호기
```

- "이전 버전 불러오기" = `양식/{레시피}/` 아래 `{생성시간}` 폴더 목록에서 선택 →
  그 폴더의 확정 양식(.xlsx) 로드. (구 '기존 저장 양식 열기(버전)' 대체·개명)

## 2. 모듈 (헤드리스 우선, 테스트)

- [x] `refdata.py` — 참고자료/특이사항 표준 파일 I/O. `REF_HEADERS=[호기,IP,비고]`,
      load/save/create_blank, `machines()`, `ip_for()`, `add_machine()`.
- [x] `workdirs.py` (재작성) — 저장폴더 기준 경로 규칙 + 버전(생성시간) 목록.
- [x] `collate.py` (재작성) — 최신 양식(레시피별)+파싱+전체 호기 → 레시피별 시트 취합,
      **직전 취합본 이어받기**. `collate_io` 로 저장/로드(멀티시트).
- [x] `history.py` (수정) — 취합 파일 2개 멀티시트 diff → 변경 목록(창 표시용) + 엑셀.
- `formbuilder.py` — 거의 유지(초안/최종, 계수 저장).

## 3. GUI (정적검증만; Windows 실기 필요)

- [ ] 첫 실행 마법사: 저장폴더 지정 → 참고자료/특이사항 로드/생성.
- [ ] 호기 그리드 = 참고자료 기반. 호기 추가=이름+IP→참고자료.
- [ ] 특이사항/참고자료 탭 = 독립 파일 편집·저장.
- [ ] 양식 만들기 = 새 경로(양식/{레시피}/{시간}/…). 확정본+관련파일(원본/수정본/ini).
- [ ] "이전 버전 불러오기"(개명) = 생성시간 폴더 선택.
- [ ] 값 확인 = 최신 취합 자동 로드(멀티시트 병합).
- [ ] 값 업데이트 = IP↔호기 매칭 → 취합(누적) → `파라미터 값 취합_{시간}.xlsx`.
- [ ] 이력 확인 = 취합 폴더 파일 2개 선택 → 다른 부분만 새 창 표.
- [ ] 기존 기능 전부 삭제(⋯더보기/공용파일/마법사/내보내기/새로고침), run.py 유지.
