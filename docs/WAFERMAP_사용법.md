# Wafer Map 변환 — 사용법

Wafer Map TXT 를 Excel 로 펼쳐 Bin Code 를 고치고, 원본 그대로 다시 TXT 로 되돌리는 프로그램입니다.

## 1. 설치

1. Release 페이지에서 `Camtek_AOI_WaferMap_v{버전}.zip` 을 받습니다.
2. zip 파일 **오른쪽 클릭 › 속성 › (아래쪽) 차단 해제** 가 보이면 체크하고 확인을 누릅니다.
3. **고정된 내 PC 폴더**에 압축을 풉니다. 예: `C:\AOI_Tools\Camtek_AOI_WaferMap\`
   - **다운로드 폴더 · 바탕화면 · OneDrive 폴더에서 바로 실행하지 마세요.** 보안 모니터링은 '다운로드 폴더에서 실행된
     서명 없는 프로그램'을 위험 신호로 봅니다. 동기화 폴더에서는 실행 중 파일이 바뀔 수 있습니다.
4. `Camtek_AOI_WaferMap.exe` 를 실행합니다(바로가기는 이 파일로 만드세요).
   - 같은 폴더의 `sidecar\` 폴더(변환 엔진)를 옮기거나 지우면 실행되지 않습니다. 폴더째로 두세요.
   - 관리자 권한은 필요 없습니다. Windows 10/11 에 기본으로 있는 WebView2 런타임을 씁니다.

## 2. 쓰는 법 (6단계)

| 단계 | 할 일 |
|---|---|
| 1. 변환 방향 · 폴더 | **TXT → Excel**(맵을 열어 수정) 또는 **Excel → TXT**(수정한 맵을 되돌림)을 고르고, Lot/폴더를 지정해 [파일 찾기]. 하위 폴더까지 찾습니다. |
| 2. 파일 선택 | 변환할 파일을 고릅니다(기본 전체). 읽기 오류가 난 파일은 회색. |
| 3. 저장 위치 | 기본은 **원본 파일과 같은 폴더**. 다른 폴더를 고르면 원본의 하위 폴더 구조를 그대로 만듭니다. |
| 4. 실행 검토 | 방향 · 파일 수 · 결과 위치를 확인하고 [▶ 변환 시작]. |
| 5. 처리 진행 | 파일마다 차례로 변환합니다. [작업 취소] = 지금 파일까지 저장하고 멈춤. |
| 6. 완료 | 결과 파일 · 맵 이미지(Bin Code / Bin Meaning PNG)를 열거나 폴더에서 봅니다. |

- **TXT → Excel** 결과: `{원본}_Map_Edit.xlsx` + `{원본}_Map_Edit_BinCode_Map.png` · `_BinMeaning_Map.png`.
  Excel 의 `Map_Edit` 시트에서 **색칠된 die 칸(Bin Code)만** 고치세요. `___`(웨이퍼 바깥)와 맵 크기는 건드리지 않습니다.
- 헤더(DEVICE · LOT · WAFER 등)를 바꿔야 할 때만 `Header_Edit` 시트의 **수정 값** 칸을 채웁니다. 비워 두면 원본 그대로입니다.
  맵 크기(ROWCT · COLCT)는 바꿀 수 없습니다.
- **Excel → TXT** 결과: `{원본}_Converted.txt`. 손대지 않은 맵은 원본 TXT 와 **바이트까지 같습니다**
  (인코딩 · BOM · 줄바꿈 · 앞자리 0 · 끝 빈 줄 보존).
- 장비 공유 폴더의 맵은 탐색기(Win+R → `\\IP\c$`)로 먼저 연결해 두어야 보입니다. 프로그램은 접속 정보를 다루지 않습니다.

## 3. 안전 · 보안

- **원본은 읽기만** 합니다. 변환은 늘 새 파일을 만들며 원본 TXT/Excel 을 고치거나 지우지 않습니다.
- **인터넷을 쓰지 않습니다.** 네트워크 포트도 열지 않습니다(화면 ↔ 엔진은 프로그램 내부 표준 입출력으로만 통신).
- **자동 업데이트가 없습니다.** 새 버전은 새 zip 을 받아 폴더를 바꾸면 됩니다(배치 스크립트로 몰래 파일을 바꾸는 동작 없음).
- 엔진은 `sidecar\Camtek_AOI_WaferMap_engine.exe` 입니다(`pythonw.exe` 를 따로 실행하지 않음). 결과를 [열기]할 때는
  이번 변환의 결과 폴더 안의 `.xlsx` · `.txt` · `.png` 와 폴더만 엽니다.
- 압축을 푼 폴더의 `SHA256SUMS.txt` 에 모든 파일의 SHA-256 값이 있습니다. 보안 담당자에게 허용 목록 등록을 요청할 때 함께 전달하세요.

## 4. 문제가 생기면

- 화면 아래에 **오류 로그 폴더**가 보입니다(`%LOCALAPPDATA%\CamtekAOI_WaferMap\Logs`). `오류_로그.txt` · `상세_진단_로그.txt` 를 담당자에게 전달하세요.
- '이미 켜져 있습니다' → 먼저 켜 둔 창을 쓰거나 닫은 뒤 [다시 연결].
- 지우기: 압축을 푼 폴더를 지우고, 필요하면 `%LOCALAPPDATA%\CamtekAOI_WaferMap` 와 `%LOCALAPPDATA%\com.camtek.aoi.wafermap`(화면 캐시)도 지웁니다.
