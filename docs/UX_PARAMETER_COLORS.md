# 파라미터 화면·색상 개선 (2026-09-14)

작업 브랜치: version_new. 기준 커밋 a323f581f936aea7c22b7ac6d22397c2e20cc802.

## 사용 방법

### 실제 색상 선택 추가

- 값 확인의 색상 칸을 더블클릭하면 현재 색상 미리보기와 코드가 함께 표시된다.
  ‘색상표에서 선택’으로 원하는 색을 고르고 미리보기를 확인한 뒤 ‘적용’한다.
  직접 코드 입력 시에도 미리보기가 갱신된다. 취소는 변경하지 않는다.
- 양식 편집기에서 파라미터 셀 하나 또는 여러 셀을 선택하고 하단 ‘색상 보고 선택…’을
  누른다. 선택한 항목과 같은 Alg·원본 항목의 반복 행에 함께 적용한다.
  색상코드 셀 배경에도 실제 색을 표시한다. 양식 확정 전에는 공유 파일에 쓰지 않는다.
- 색상창은 필요할 때 하나만 생성하고 표 색은 기존 캔버스 셀 강조를 사용한다.
  행마다 버튼/위젯을 만들지 않으며 선택 적용 후 표를 한 번 갱신한다.

- 변환 계수 확인 창: 세로 스크롤바 또는 마우스 휠로 아래 변형까지 이동한다.
  확인/취소는 스크롤 목록 밖 하단에 둔다. 계수 입력칸 위 휠도 목록을 움직인다.
- 파라미터 값 확인: 왼쪽은 짙은 회색 바탕, 밝은 읽기 전용 값 칸, Alg 그룹,
  파라미터 왼쪽 색상 칸으로 구성한다. 장비의 값 조절 슬라이더는 추가하지 않는다.
  오른쪽 여러 호기 비교 열·좌우 세로 스크롤 동기화는 유지하고 회색 톤을 맞춘다.
- 왼쪽 **색상 칸 더블클릭** → #RRGGBB 입력 → 확인하면 공유 이름 파일에 저장한다.
  빈칸은 자동 색상이다. 기존 셀 우클릭 강조색은 분류 색상과 별도로 유지한다.
- 양식 만들기: 마지막 **색상코드 (#RRGGBB)** 열을 더블클릭해 수정한다.
  저장된 코드가 우선이며, 없으면 참고 화면에 따른 초기 색상을 보여준다.
  색상 버튼·행별 위젯 없이 텍스트로 편집한다. 양식 확정 시 함께 저장하며 취소 시 저장하지 않는다.
- 같은 Alg·원본 항목이 여러 변형에 반복되면 한 행에서 바꾼 색상을 함께 적용한다.
  반복 항목에 서로 다른 색상을 입력하면 오류를 알리고 확정을 중단한다.
- 비고 더블클릭: 입력창은 클릭한 마우스 위치 대신 실제 셀의 위치·폭에 맞춘다.
  스크롤 오프셋 반영. Enter 확정, Escape 또는 포커스 이탈은 취소다.

## 저장·보안·호환성

- 장비화면이름.xlsx의 기존 Alg/원본항목/장비화면이름/사용/비고 뒤에 색상코드를 추가한다.
  색상만 변경할 때 이름·사용·비고를 유지한다. 기존 5열 파일도 읽을 수 있다.
- 색상은 (Alg, 원본항목) 기준이며 새 양식과 표시 이름 조회에 재사용된다.
  표시 이름이 모호하면 임의 원본에 저장하지 않고 양식 편집기에서 지정하도록 안내한다.
- 색상을 바꿀 때만 명시적으로 저장한다. 렌더링·스크롤·검색은 파일을 쓰지 않는다.
  저장 시 기존 소프트 락, 최신 파일 재로드, 저장 직전 변경/충돌본 검사를 사용한다.
  새 공유 임시 파일·주기적 저장·장비 쓰기·외부 통신·추가 패키지 없음.
- OneDrive 소프트 락은 PC 간 동기화 지연의 완전한 상호배제를 보장하지 않는다.
- 구버전 앱은 색상 열을 표시하지 않는다. 구버전의 이름 파일 저장 코드는 새 열을
  보존하지 않으므로, 공유 색상 사용을 시작한 뒤에는 이름/양식 편집 담당자도 새 빌드를 사용한다.
- 기본 색상은 첨부 화면을 참고한 규칙이며 장비에서 추출한 공식 메타데이터가 아니다.
  실제 장비별 차이는 사용자 지정 코드로 맞춘다.
