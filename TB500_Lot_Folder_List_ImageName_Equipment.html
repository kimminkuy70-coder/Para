판단 로직 없이 랏트 하위의 실제 폴더명을 그대로 나열하는 읽기 전용 버전입니다.

READ ONLY

1. 랏트 목록

줄바꿈, 탭, 쉼표가 자동 분리됩니다. 중복 랏트는 한 번만 조회합니다.
먼저 검색 경로를 연결하세요.

2. 검색 경로 설정

브라우저 보안상 UNC 경로를 자동 접근할 수 없습니다. Layer 아래 하위 폴더를 읽기 전용으로 조회합니다. 장비 판정이 가능한 이미지 파일명을 찾으면 해당 Layer 조회를 즉시 종료하고 다음 Layer로 넘어갑니다.
권장: Microsoft Edge. 네트워크 폴더가 선택창에 안 보이면 Windows에서 네트워크 드라이브로 매핑한 뒤 선택하세요.
