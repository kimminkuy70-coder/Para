TB500 Review

폴더 연결 (처음 1회)

1
OneDrive 캐시공유 폴더
  • 개발자가 공유한 OneDrive 폴더를 [내 파일에 바로 가기 추가]로 연결하십시오.
  • 그 안의 캐시공유 폴더를 고르십시오.
처음이면 여기를 보십시오 — OneDrive 바로 가기 만드는 순서 (그림을 누르면 크게 보입니다)
  1. 개발자가 보낸 OneDrive 공유 링크를 Microsoft Edge 로 여십시오. 폴더 이름이 0. Camtek AOI parameter 취합 인지 확인하십시오. 1
  2. 오른쪽 위의 [내 파일에 바로 가기 추가] 를 누르십시오. 2
  3. 펼쳐진 메뉴에서 [내 파일] 을 누르십시오. 3
  4. 몇 분 기다리십시오. 파일 탐색기의 OneDrive - Amkor Technology 아래에 0. Camtek AOI parameter 취합 폴더가 생깁니다.
  5. 오른쪽 [폴더 연결] 을 누르십시오. 그 폴더 안의 캐시공유 폴더를 고르십시오. 4

폴더가 안 보이면 작업 표시줄의 OneDrive 구름 아이콘을 눌러 동기화가 끝났는지 확인하십시오. 이 바로 가기는 PC 마다 한 번만 만들면 됩니다.

예C:\Users\(사번)\OneDrive - Amkor Technology\0. Camtek AOI parameter 취합\캐시공유 연결 안 됨
2
Conder Scan 폴더
  • Lot 폴더들이 바로 아래에 있는 폴더를 고르십시오.
  • 이 폴더는 읽기만 합니다.
  • 네트워크 폴더가 안 보이면 Windows 에서 네트워크 드라이브로 연결한 뒤 고르십시오.
예\\k5cifsn2\k5tsvdata$\1. Conder Scan\531. NVIDIA INT\129. 4DT-TB500-H-M1 연결 안 됨
3
내 PC 캐시 폴더
  • 캐시를 풀어 둘 내 PC 폴더를 고르십시오.
  • 이 프로그램이 만든 파일만 쓰고 지웁니다.
예문서 아래 새 폴더 TB500리뷰캐시 연결 안 됨

캐시

Camtek 캐시 (Batch Report)

없음

KLA 캐시 (KLA 자재 찾기)

없음

  • [캐시 갱신]은 동기화된 OneDrive 폴더에서 가장 최근 캐시 zip 을 읽어 내 PC 캐시 폴더에 풀어 둡니다.
  • 크기와 SHA-256 이 게시할 때와 같을 때만 씁니다.
  • 내 PC 캐시 폴더에는 최신 1개만 남깁니다.
  • 캐시를 받은 지 24시간이 지나면 위에 빨간 알림이 나옵니다.
  • 권장 브라우저: Microsoft Edge

Lot 목록

  • 줄바꿈, 탭, 쉼표로 자동으로 나눕니다.
  • 같은 Lot 은 한 번만 조회합니다.
처음 한 번 [설정] 탭에서 폴더를 연결하고 [캐시 갱신]을 누르십시오.
