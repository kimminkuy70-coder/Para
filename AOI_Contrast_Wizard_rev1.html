Step 2 · 비교 조건 설정

등록한 리스트를 Contrast AVG 오름차순으로 놓고 모든 순서쌍을 비교합니다(리스트 3개 = 3×2 = 6쌍, CA20 → CA27 과 CA27 → CA20 을 따로). 쌍 A → B 마다 A - B(A 에만 있는 Defect) = B 에서 없어진 Defect 입니다. 보기 = A ∪ B · A(전체) · B(전체) · A - B · A ∩ B · B - A.

보기 단위 Lot 별 = Lot 의 모든 Slot 을 한 wafer map 에 겹쳐 봅니다(같은 Defect 판정은 같은 Slot 끼리만). Slot 별 = 고른 Slot 1장만 봅니다.
Wafer map 계산 Die 좌표 = 좌측 하단 (0,0) 에서 오른쪽 · 위쪽으로 1씩 커지는 x, y 그래프(Col = floor(X/PitchX), Row = floor(Y/PitchY)). Die = 네 모서리가 모두 wafer 원 안인 칸, 그 Die 들의 좌측 하단 = (0,0). wafer 중심은 ProductInfo CenterX/CenterY(장비 기록)를 씁니다. 맵 파일이 없어도 됩니다.
Wafer Map 파일 (선택, 비교용) 결과 폴더 안에 RowData 줄이 있는 파일이 있으면 자동으로 계산 결과와 비교합니다.
