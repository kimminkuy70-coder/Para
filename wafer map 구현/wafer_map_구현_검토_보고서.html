5. 불충분한 자료

  1. 장비가 export 한 맵 파일이 없습니다. ScanLog.ini 에 ExportMapStarted / Ended 가 있고 converter 이름은 SINF3D 입니다. 이 결과 폴더의 export 맵 1개가 있으면 번호 원점, Row 방향, Notch, Bin 기호를 바로 맞춰 볼 수 있습니다.
  2. 불량 die 가 있는 wafer 가 없습니다. 이 Slot 은 모두 Good 입니다. 불량 die 가 있는 Slot 1장(같은 폴더 구성)이 있으면 Defect 분류 → Bin 변환(ClassificationConvertTable.ini, EquipmentClassifications.ini)을 확인할 수 있습니다.
  3. device 가 1종입니다. die 가 큰 device(30 die)라 가장자리 판정 여유가 큽니다(4 mm 이상). die 가 작은 device 1장이 있으면 가장자리 die 와 부분 die(ScanPartialDice=0) 규칙을 확인할 수 있습니다.
  4. Notch 방향 근거가 없습니다. Flat Pos=3, FlatNotchOrientation=3, ExportFlatPos=3 만 있습니다. 숫자의 뜻(0/1/2/3 = 위/오른쪽/아래/왼쪽 등)을 정할 자료가 필요합니다. 장비 화면 맵 캡처 1장이면 됩니다.
  5. 사진을 뺀 것은 문제가 없습니다. 사진 위치는 ColorImageGrabingInfo.ini, ScanResultImageList.txt 에 모두 있습니다.

6. 불안정한 부분

부분위험이유 · 대책

7. 구현안 (가장 단순)

  1. ProductInfo.ini 에서 XDieIndex, YDieIndex, Cols, Rows 를 읽습니다.
  2. s_DieLocation.dat 를 128 byte 씩 읽습니다. 앞 1/2(Recipe 1)만 씁니다. 각 x, y 로 Col, Row 를 구해 맵 die 집합을 만듭니다.
  3. Cols × Rows 칸을 그립니다. Row 0 = 아래. 집합에 있는 칸만 die 로 칠합니다. 300 mm 원은 참고선으로만 그립니다.
  4. Defect · 이미지마다 X, Y 로 Col, Row 를 구해 그 칸에 셉니다. 칸 안 점 위치 = (X − Col×PitchX, Y − Row×PitchY).
  5. 화면 번호 = 장비 Col/Row 그대로(이미지 Col, Row 와 같음). 샘플 맵 맞추기, offset, 가운데 맞춤 추정은 쓰지 않습니다.

이 방식은 계산이 나눗셈 1번이라 틀릴 곳이 적습니다. 남는 확인은 5절의 자료 2~3개입니다.

8. 다음에 받으면 좋은 자료

  1. 이 Slot 의 export 맵 파일(SINF3D) 1개.
  2. 불량 die 가 있는 Slot 결과 폴더 1개(사진 빼도 됨).
  3. die 가 작은 다른 device 결과 폴더 1개.
  4. 장비 화면의 wafer map 캡처 1장(Notch 와 Row 방향 확인).
